# 機能: 関数生成

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.spreadsheet-operator/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


ユーザーが「やりたいこと」を自然言語で伝えると、それに合った関数式（Google Sheets / Excel）を生成する。

このモードはシート書き込みを行わない。式を提示するだけ。

## 入力

1. やりたいこと（例: 「別シートから商品名で検索して在庫数を引いてくる」）
2. シート構造（列名・サンプル）
3. 対象セルの位置

不明点は1往復で聞く:

> 以下を教えていただけますか？
> - 検索元のシート名と列構成
> - 結果を表示したいセル位置
> - 検索したいキー列
> - 引いてきたい値列

## 手順

### 1. やりたいことを整理

- 検索型（VLOOKUP / INDEX-MATCH / XLOOKUP / QUERY）
- 集計型（SUMIF / SUMIFS / COUNTIF / AVERAGEIF）
- 条件分岐（IF / IFS / SWITCH）
- 文字列処理（CONCAT / TEXTJOIN / REGEX / SPLIT）
- 日付処理（DATE / EDATE / EOMONTH / NETWORKDAYS）
- 配列処理（ARRAYFORMULA / QUERY / FILTER / SORT / UNIQUE）
- 外部データ（IMPORTRANGE / IMPORTXML / IMPORTHTML）※Sheetsのみ

### 2. 複数案を提示

3案 用意する:

#### 案1: 可読性重視
- シンプルで誰でも理解できる関数
- 性能より読みやすさ

#### 案2: 堅牢性重視
- エラーハンドリング（IFERROR、IFNA）
- 空セル・型不一致に対応
- 想定外の入力でも壊れない

#### 案3: 短さ重視 or モダン
- XLOOKUP / LAMBDA / LET など最新関数
- 一行で書ける
- 新しめのSheets/Excelが必要

### 3. 各案の解説

各関数について:
- 何をしているか
- 引数の意味
- 動かないときの原因（よくある）
- 対応環境（Google Sheets / Excel / 両方）

### 4. コピペ可能な形で提示

```markdown
## 案1: 可読性重視（VLOOKUP）

```
=VLOOKUP(A2, '商品マスタ'!A:C, 3, FALSE)
```

- A2: 検索キー（このシートの商品コード）
- '商品マスタ'!A:C: 検索元の範囲
- 3: 3列目（在庫数）を返す
- FALSE: 完全一致

動かないとき: 検索キーが商品マスタの1列目にあるか確認。違う場合は INDEX-MATCH（案2）を使う。

## 案2: 堅牢性重視（INDEX-MATCH + IFERROR）
...

## 案3: モダン（XLOOKUP）
...
```

### 5. 選択後のフォロー

ユーザーがどれを選ぶかで補足:

- 複雑な式: 動作確認のテストケースを提示
- エラー時の対処法
- 派生させたいケース（「これを複数列に展開したい」等）

## 特殊ケース

### QUERY 関数（Google Sheets）

SQL 的な問い合わせが可能。強力だが初心者には難しい:

```
=QUERY('売上データ'!A:E, "SELECT B, SUM(D) WHERE C = '東京' GROUP BY B ORDER BY SUM(D) DESC")
```

解説を丁寧に（SQL構文、列参照の仕方など）。

### ARRAYFORMULA（Google Sheets）

行を追加するたびに式をコピーする手間を省く:

```
=ARRAYFORMULA(IF(A2:A="", "", B2:B * C2:C))
```

対応列の終端問題の注意事項を添える。

### LAMBDA / LET（新しめ）

環境によって使える / 使えないが分かれる:

- Google Sheets: 対応
- Excel Microsoft 365: 対応
- Excel 2021以前: 非対応

対応状況を明示してから提案。

## やってはいけないこと

- 動作保証のない関数の提示（特定のバージョンでしか動かない場合は明示）
- 動作確認なしで「これで動きます」と断言（可能性のある問題を添える）
- ユーザーのシート構造を推測で補完（必要なら聞く）

## 次のステップへの誘導

関数を提示した後:

> 動作確認してみてください。うまく動かない場合は、以下を教えていただけると原因を絞れます:
> - エラーメッセージ（#N/A, #VALUE!, #REF! 等）
> - 使っているシート環境（Google Sheets / Excel のバージョン）
> - 関数を入れたセルの内容のスクリーンショット

次に進めたいことがあれば:
- 「これを複数列に展開したい」→ 配列化
- 「このロジックをスクリプトにしたい」→ script モードへ
- 「シートを整形したい」→ operate モードへ
