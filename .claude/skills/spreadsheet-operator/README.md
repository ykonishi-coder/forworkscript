# スプレッドシート操作 (Spreadsheet Operator)

Google Sheets と Excel を 実際に操作できる サポーター。関数生成だけでなく、シートの書き込み・整形・集計までユーザー承認のもとで自動化します。

---

## プライバシー・安全性について（最初に）

- 入力した情報は Claude の学習データには使われません
- 設定・ログは あなたのPC内 にのみ保存されます
- 認証情報はスキルに保存しません（OSキーチェーン / GAS内プロパティで管理）
- すべての書き込み操作はプレビュー → 承認 → 実行 の3段階
- デフォルトでバックアップ を作成
- 外部スプレッドシートへの書き込み禁止（設定で明示的に許可したシートのみ）
- 定期実行での書き込み禁止（読み取り・レポートのみ）

---

## できること

### 関数生成
「別シートから商品名で検索して在庫数引いてきて」のような自然言語指示から、VLOOKUP / INDEX-MATCH / XLOOKUP / QUERY 等を生成。複数案（可読性 / 堅牢性 / モダン）で提示。

### シート操作（書き込み）
データ整形、重複削除、並び替え、ピボット、チャート追加などを GAS Web App 経由で実行。必ずドライラン → バックアップ → 承認 → 実行の順。

### スクリプト生成
「毎日、昨日のデータを集計してサマリシートに書き込む」のような反復タスクを GAS コードで生成。デプロイはユーザー自身が実行。

---

## セットアップ

```
スプレッドシート操作セットアップして
```

### 最初に「タイプ」を聞かれます

- A) お試し — サンプルで動作確認、PCに書き込まない
- B) 最低限（3問）— 手動コピペ前提で最小構成、迷ったらこれ
- C) しっかり — GAS Web App 連携までフル設定

---

## 連携方式の選択

### 1. 手動コピペ（★★★★★ 安心）
- 関数・スクリプトを Claude が生成 → あなたが手で貼る
- 認証設定ゼロ
- どの環境でも動く

### 2. GAS Web App 経由（★★★★☆ 推奨）
- あなたの Google アカウント内で GAS を公開
- Claude が HTTP 経由で操作
- 権限はあなたが自分で制御
- セットアップ手順: `references/gas-web-app-guide.md`

### 3. Google Sheets API 直接（★★★☆☆）
- OAuth 認証で直接 API を叩く
- やや設定が複雑

### 4. MCP 経由（利用可能なら ★★★★☆）
- MCP サーバーが利用可能なら最短
- セットアップ時にネット調査

## 使い方

### 関数を作ってほしい
```
VLOOKUP で商品コードから在庫数を引いてくる式を作って
```

### シートを操作してほしい
```
売上データの日付フォーマットを YYYY-MM-DD に統一して
```

→ ドライラン表示 → 「実行していい？」と確認 → 承認後に実行

### 自動化スクリプトを作ってほしい
```
毎朝、昨日の売上を集計してサマリシートに追記するスクリプト作って
```

→ GAS コードを生成 → 説明 → デプロイ手順を案内

## よくある質問

### Q. シートの内容が外部に漏れないか心配
- 連携なし（手動コピペ）で運用すれば、あなたが選んで貼ったデータだけが Claude に渡ります
- GAS Web App 方式なら、あなたの Google アカウント内で処理が完結（第三者にトークンを渡さない）
- 処理時にシート内容が Claude API に送られますが、学習には使われません

### Q. 勝手に書き込まれないか心配
- すべての書き込みはユーザー承認が必須 です（ドライラン → 承認 → 実行）
- デフォルトでバックアップが作成されるので、事故時は戻せます
- 定期実行では書き込みを行いません（設定で明示的に変更しない限り）

### Q. 認証情報はどこに保存される？
- スキル内には一切保存しません
- OS キーチェーン、環境変数、または GAS の `PropertiesService` で管理
- `config.yaml` には GAS Web App の URL のみ記載（URLは秘密情報ではない扱いだが、公開はしない）

### Q. 破壊的な操作（大量削除等）が心配
- 100行以上の変更は追加確認
- 列・シート全体の削除は厳重確認
- すべての操作でロールバック手順を提示

### Q. やめたくなったら、どう消せますか？
1. 設定フォルダを削除: `rm -rf ./.spreadsheet-operator/`（Windowsは `Remove-Item -Recurse -Force ./.spreadsheet-operator/`）
2. GAS Web App を無効化: `clasp undeploy {DEPLOYMENT_ID}` または GAS エディタから手動でデプロイ解除
3. これで痕跡なし
