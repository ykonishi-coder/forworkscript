# レポート作成チーム (Report Writer)

各種レポートを5役割のチームで分担制作するエージェント。秘書・MTGサポーター・スプレッドシート・原稿チェッカーと連携し、既存情報からレポートを組み立てます。

---

## プライバシーについて（最初に）

- 入力した情報は Claude の学習データには使われません
- 中間成果物・最終レポートは あなたのPC内 にのみ保存
- 外部送信なし（他者への共有はユーザーが手動で実施）
- 他エージェントとの連携時は 毎回承認 を取ります

---

## 構成（5役割チーム）

| 役割 | 担当 |
|------|------|
| 🎯 director | 要件整理・工程指揮・ユーザー窓口 |
| 🔍 researcher | 素材収集（連携 or Web検索） |
| 📐 composer | 構成設計・章立て |
| ✍️ writer | 本文執筆 |
| 🛡️ advocate | DA（品質検証・事実確認） |

---

## 対応レポート

1. 週次／日次業務報告
2. 提案書・企画書
3. 調査レポート
4. KPIレポート
5. インシデント／障害報告書
6. プロジェクト進捗レポート
7. 経営層向けサマリ
8. カスタム（上記の応用）

## セットアップ

```
レポート作成チームセットアップして
```

### 最初に「タイプ」を聞かれます

- A) お試し — サンプル案件でフロー確認、ファイル作らない
- B) 最低限（3問・約5分）— よく書くレポートタイプ / 連携したい既存エージェント / 中間承認の頻度
- C) しっかり（約15分）— 工程の取捨選択、並列実行、DA厳しさまで

## 他エージェントとの連携

セットアップで許可した場合のみ動作:

- 秘書: 過去のメールスレッドから論点・決定事項を取り込み
- MTGサポーター: 関連議事録から決定事項・To-Doを取り込み
- スプレッドシート: 数値データ・ピボット結果を取り込み
- 原稿チェッカー: 最終ドラフトの文法・ファクトを検証

連携は毎回ユーザー承認を取ります。勝手に他スキルのファイルを読みません。

## よくある質問

### Q. 「チーム」って重くないですか？
工程が分かれる分、各担当の視点で精度が上がります。軽量構成（工程を減らす）も可能です（B プランで選択）。

### Q. 他エージェントを使わず単独で使える？
使えます。セットアップで連携を無効にすれば、素材はユーザーがdirectorに直接渡します。

### Q. 1本のレポートにどれくらい時間かかる？
- 週次レポート: 3〜5分
- 提案書: 10〜15分
- 調査レポート: 20〜30分（Web検索と事実確認を含む）

設定で「軽量モード」にすると短縮できます。

### Q. 機密情報を含むレポートは大丈夫？
- ローカル保存のみ
- 外部送信なし
- Web検索時は原文を投げず、キーワードだけ抽出
- それでも不安なら連携を切って手動で素材を渡す運用が最も安心

### Q. やめたくなったら？
`rm -rf ./.report-writer/`（Windowsは `Remove-Item -Recurse -Force ./.report-writer/`） + `work/report-writer/` を削除で完全に消えます。
