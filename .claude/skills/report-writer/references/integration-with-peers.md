# 他エージェントとの連携

レポート作成チームは、同じ配布パックの他エージェントと連携して素材を取り込める。連携は毎回ユーザー承認を取る のが原則。

## 連携先と取り込む素材

### 秘書（secretary）

取り込む素材:
- 特定メールスレッドの要点
- 決定事項、合意内容
- To-Do・約束事
- 相手との文脈

連携手順:
1. researcher が director から「この議論のメールスレッドを参照してほしい」と指示を受ける
2. ユーザーに承認依頼:
   > 秘書エージェントの保存先（`./.secretary/`）から、以下の情報を取り込みます:
   > - 対象: 〇〇さんとのメールスレッド（4月の案件進行）
   > 
   > 連携してよろしいですか？
3. 承認後、researcher が secretary の保存先を参照
4. 取得情報を 02-researcher.md に記録（出典明記）
5. 処理後、取得した元データはメモリ解放

制約:
- secretary が設定されていない場合は手動モードへフォールバック
- 取り込むのは「関連する部分」のみ、全メール丸読みはしない

### MTGサポーター（meeting-supporter）

取り込む素材:
- 関連議事録の決定事項
- 議論の論点
- To-Do
- 次回議題

連携手順:
1. researcher が対象議事録を特定（日付・キーワード・参加者）
2. ユーザー承認:
   > MTGサポーターの保存先から、以下の議事録を参照します:
   > - 2026-04-15 〇〇定例
   > - 2026-04-08 〇〇プロジェクトキックオフ
   >
   > 連携してよろしいですか？
3. 承認後、該当議事録を読み込み
4. 取り込んだ内容を 02-researcher.md に記録

制約:
- `[CONFIDENTIAL]` マーカー付き議事録は、追加の承認が必要
- 議事録の内容改変は行わず、参照・引用のみ

### スプレッドシート操作（spreadsheet-operator）

取り込む素材:
- 指定シートの数値データ
- ピボット結果
- 集計値
- 時系列の推移

連携手順:
1. researcher が対象シート・範囲を特定
2. ユーザー承認:
   > スプレッドシート「{シート名}」の以下の範囲を読み取ります:
   > - シート: データ2026
   > - 範囲: A1:E100
   >
   > 連携してよろしいですか？
3. spreadsheet-operator の GAS Web App 経由、または手動コピペで取得
4. 数値を 02-researcher.md に記録（出典: {シート名} / {範囲} / {取得日時}）

制約:
- 読み取りのみ。書き込みは行わない
- 大量データ（1000行超）は集計してから取り込み

### 原稿チェッカー（text-quality-checker）

取り込む機能: 最終ドラフトの文法・ファクトチェック

連携手順:
1. writer の初稿完成後、advocate のレビュー前に呼び出す（オプション）
2. または advocate のレビュー後、writer の修正版に対して呼び出す
3. ユーザー承認:
   > 原稿チェッカーで 04-writer.md の校正をかけますか？
   > - 誤字脱字・文法チェック
   > - ファクトチェック（Web検索で裏取り）
4. 承認後、text-quality-checker のチェック機能を実行
5. チェック結果を advocate に渡して最終レビューで統合

制約:
- 自動修正はしない（チェック結果のみ反映）
- advocate のレビューに置き換えるのではなく、補完として使う

## 連携を使わない運用

「連携しない」と設定した場合、または連携がエラーで動かない場合:

1. director がユーザーに素材を直接依頼:
   > 今回は連携を使わないので、以下の素材をご用意いただけますか？
   > - 対象メールの本文（コピペ）
   > - 関連議事録（ファイル or コピペ）
   > - 参照すべき数値データ
2. ユーザーから受け取った素材を researcher に渡す
3. 以降は通常フロー

## 連携時のプライバシー配慮

### 他スキルの設定ファイル読み取り

- 読み取るのは 指定されたファイルのみ
- 例: `./.secretary/config.yaml` を読むのはNG（設定情報）、`./.secretary/meetings/*.md` の特定ファイルは指定があればOK

### 情報の最小化

- 必要な部分だけ抽出
- 全文読み込み→要約 ではなく、該当箇所だけ参照

### 機密マーカー

- `[CONFIDENTIAL]` 等のマーカー付きは追加承認
- レポート末尾に「機密ソースを含む」フラグを立てる

### 配布時の処理

- 納品物（final.md）は、連携元の機密情報をマスキング済みか確認
- ユーザーが配布前にチェックする旨を案内

## エラー時の対応

### 連携先が設定されていない
- ユーザーに手動モードへの切り替えを案内
- 「秘書エージェントを使いますか？ それともこの案件だけ手動で素材を渡しますか？」

### 連携先が動作しない
- 一時的にフォールバック（手動）
- 後で連携設定を見直すよう案内

### 権限エラー
- 認証情報の再確認を案内
- スキル側ではなく、各エージェント公式の認証フローで対応

## 連携情報の記録

連携を使った案件は、`02-researcher.md` の冒頭に記録:

```markdown
# 素材収集結果

## 連携ソース
- secretary: 有効 (2 メールスレッド参照)
- meeting-supporter: 有効 (3 議事録参照)
- spreadsheet-operator: 無効（使わず）
- text-quality-checker: 執筆後に使用予定

## プライバシー
- 機密マーカー付き素材: なし
- 個人情報を含む: あり（マスキング済み）
```

納品時に、どの情報源を使ったかが透明に分かるようにする。
