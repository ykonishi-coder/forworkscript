# 他エージェントとの連携

目標管理エージェントが、同じパックの他エージェントと連携して情報を取り込む方法。連携は毎回ユーザー承認。

## 連携先と取り込む情報

### 秘書（secretary）

取り込む情報:
- 目標関連のメールから期限・約束・進捗
- 決定事項

活用例:
- 「〇〇さんとの約束」がメールにある → 目標の「今月のアクション」に反映
- 取引先からの期限延長連絡 → 目標の期限を更新（ユーザー承認）

手順:
1. goal-tracker が秘書の保存先（`./.secretary/`）を参照
2. 関連メールスレッドから情報抽出
3. 目標ファイルとの差分を提示
4. ユーザー承認で目標ファイル更新

### MTGサポーター（meeting-supporter）

取り込む情報:
- 目標レビュー会議の議事録から進捗
- To-Do
- 次期方針

活用例:
- 四半期 OKR レビュー会議の議事録から、各 KR の最新値を取り込み
- 今期の振り返り項目として、会議での議論を反映

### スプレッドシート操作（spreadsheet-operator）

取り込む情報:
- 目標管理シートとの双方向同期
- 数値の最新値

注意: 書き込み同期は 毎回ユーザー承認。勝手にシートを更新しない。

活用例:
- KPI スプレッドシートから最新数値を取得
- 目標ファイルの進捗と、シート記録の不整合を検出
- 整合性を保つようにユーザー判断で更新

### レポート作成（report-writer）

取り込む情報:
- 目標の振り返りレポートを自動生成
- 既存レポートから目標設定の材料

活用例:
- 四半期末の振り返りを goal-tracker で整理 → report-writer で正式レポート化
- 「〇〇プロジェクト報告書」の素材として目標進捗を提供

## 連携手順

### 1. 必要性の判断

ユーザー発話や目標内容から判断:
- 「〇〇メールの件、目標に反映して」 → secretary 連携
- 「KPIシートの最新値で進捗更新」 → spreadsheet 連携

### 2. ユーザー承認

```markdown
以下のエージェントを連携させてよろしいですか？

- secretary: 「〇〇プロジェクト」スレッドの最新メールを参照
- spreadsheet-operator: 「2026 KPI」シートのB2:B12 を読み取り

読み取るだけで、書き込みは別途承認を取ります。
```

### 3. 取り込み

承認後、情報を取得。取り込んだ情報は目標ファイルに出典付きで記録。

### 4. 更新の承認

目標ファイルへの書き込み前にプレビュー:

```markdown
以下のように目標ファイルを更新します:

- KR1: 60 → 80（出典: スプシ最新値）
- 気づき欄: 「〇〇について議論（出典: 2026-04-22 会議議事録）」

この更新で進めてよろしいですか？
```

## 連携しない運用

他エージェントが設定されていない、または連携したくない場合:

- ユーザーが手動で情報を渡す
- goal-tracker 単体で完結（機能は同じ）

## プライバシー配慮

### 他スキルの設定ファイル読み取り
- 指定されたファイルのみ
- 設定本体（config.yaml）は読まない

### 情報の最小化
- 目標に関連する部分だけ
- 全データを読み込まない

### 機密情報
- プライベート目標 + 機密プロジェクトは特に厳重
- マスキング設定を遵守

## エラー時の対応

### 連携先が設定されていない
- ユーザーに手動モードへ案内:
  > 秘書エージェントが設定されていません。
  > 今回は手動で情報を貼り付けていただけますか？

### 連携先が動作しない
- 手動モードにフォールバック
- 後で連携見直しを案内

### 情報の不整合
- 複数ソースで矛盾があればユーザーに判断を仰ぐ
- 勝手にどちらかを採用しない

## 記録

連携を使った目標更新は、目標ファイルに明示的に記録:

```markdown
### 進捗ログ

#### 2026-04-22
- KR1: 60 → 80 (+20)
  - 出典: spreadsheet-operator（シート「2026 KPI」）
  - 取得日時: 2026-04-22 15:30
- 気づき: プロジェクト調整が遅れている
  - 出典: meeting-supporter（2026-04-22 定例議事録）
```

出典を常に明示することで、信頼性とトレーサビリティを確保。
