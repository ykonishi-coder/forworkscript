# 機能: 進捗記録・確認

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.goal-tracker/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


## 入力

1. 対象目標（未指定ならユーザーに選択してもらう）
2. 進捗データ（数値 / チェックリスト更新 / メモ）

## 手順

### 1. 対象目標の特定

- ユーザーが明示していれば、そのファイルを開く
- 明示されていない場合、アクティブな目標をリスト表示して選択してもらう:

```markdown
現在アクティブな目標:
1. 2026-Q2 OKR（会社）
2. 2026-04 個人SMART目標
3. プロジェクトXYZ（GTD）

どれの進捗を記録しますか？
```

### 2. 現状ヒアリング

フレームワーク別に聞き方を変える:

#### SMART
- Measurable の指標について、現状値を聞く
- マイルストーン達成状況のチェック

#### OKR
- 各 KR の現状値を聞く:
  > KR1「〇〇を100にする」の現状は？

#### KPI
- 今週・今日の数値を聞く:
  > 今週の {指標名} の実績は？

#### GTD
- ネクストアクションの完了確認
- 新たなネクストアクションの洗い出し

### 3. 前回からの変化を計算

- 前回記録との差分
- 目標達成率の変化
- 予測された進捗と実際のギャップ

### 4. 気づき・障害の記録

```markdown
### 今週の進捗メモ

良かった点:
- {進展した点}

課題:
- {うまくいっていないこと、ブロッカー}

気づき:
- {学びや発見}
```

ユーザーが話したことをそのまま記録。無理に構造化しない。

### 5. 可視化

```markdown
## 進捗状況（YYYY-MM-DD 時点）

### KR1: 〇〇を100にする
進捗: [████████░░] 80% (80/100)
前回: 60/100 → 今回: 80/100 (+20)

### KR2: △△を50にする
進捗: [██████░░░░] 60% (30/50)
前回: 25/50 → 今回: 30/50 (+5)
```

### 6. 目標ファイルを更新

該当目標ファイルの「進捗ログ」セクションに追記:

```markdown
### 進捗ログ

#### YYYY-MM-DD
- KR1: 60 → 80 (+20)
- KR2: 25 → 30 (+5)
- 気づき: {メモ}
```

### 7. ステータス判定

現状を踏まえて、ユーザーに確認:

- 順調: 予定通り or 想定以上
- 要注意: やや遅れている、挽回可能
- 危険: 大幅遅延、目標見直し必要

判定は ユーザーに確認。自動判定はしない。

```markdown
現在のペースで順調/要注意/危険、どれだと感じますか？
```

ユーザー回答を config.yaml には保存せず、目標ファイルの「ステータス」フィールドに反映。

### 8. 次のアクション確認

```markdown
今週〜来週でやりたいこと（1〜3個）:
- ...
- ...
```

ユーザー入力を受け取って目標ファイルに追記。

## 定期実行時の挙動（scheduled-run）

設定で「毎週月曜朝に進捗確認リマインド準備」が有効なら:

1. アクティブな目標を読み込む
2. 前回更新から期間が空いている目標をリストアップ
3. 「今週進捗を記録したい目標:」のファイルをログに生成:

```
{保存先}/reminders/weekly-YYYY-MM-DD.md

## 今週進捗確認が推奨される目標

- 2026-Q2 OKR（最終更新: 2週間前）
- 2026-04 個人SMART（最終更新: 1週間前）

ユーザーが「今週の進捗記録」と言ったら、これらを提示する。
```

通知は送らない。ユーザーが次回起動時に確認。

## スプレッドシート連携（該当する場合）

config で spreadsheet-operator と連携している場合:

1. 対象シートから最新数値を取得（ユーザー承認後）
2. 目標ファイルと差分を取り
3. 不整合があればユーザーに確認
4. 整合性を保ちつつ、どちらをマスターとするか明確に

## やってはいけないこと

- ユーザーが記録していない数値を勝手に補完
- 達成判定を自動でする（ユーザーが判断する素材を提供）
- 目標ファイルの過去ログを改変（追記のみ）
- プライベート目標を仕事用ダッシュボードに混ぜる

## 完了メッセージ

```markdown
## 進捗を記録しました

対象: {目標タイトル}
記録日: YYYY-MM-DD

### 変化
- KR1: 60 → 80 (+20) ↑
- KR2: 25 → 30 (+5) →

### 気づき
- {ユーザー記入内容}

### 次の予定
- 次回進捗確認: {設定された日}
- 振り返り: {期末レビュー日}

頑張ってください！
```
