# 目標管理 (Goal Tracker)

個人・チームの目標を、設定→進捗記録→振り返り→次のアクション提案まで一貫サポートするエージェント。

---

## プライバシーについて（最初に）

- 入力した情報は Claude の学習データには使われません
- 目標・進捗データは あなたのPC内 にのみ保存
- 外部送信は行いません（チーム共有はあなたが手動で）
- 強制的なリマインド・タスク追加はしません（提案まで）

---

## できること

### 目標設定
- SMART / OKR / KPI / GTD / シンプル箇条書き のフレームワークに対応
- 構造化してファイル保存

### 進捗記録
- 現状の数値・状態を記録
- 前回からの変化を可視化
- 気づき・障害をメモ

### 振り返り
- 週次・月次・四半期のレビュー支援
- 達成 / 未達成 / 部分達成 の判定サポート
- 良かった点・課題・学びを構造化
- 次期への引き継ぎ整理

### ネクストアクション提案
- 現在の目標・進捗から、優先度の高いアクション3〜5個を提案
- 強制しない、選択肢を提供

### ダッシュボード
- 全目標の達成率・ステータス一覧
- 今週のフォーカス
- 期限切れアラート

### 定期実行
- 月曜朝の週次レビュー準備
- 月初の月次ダッシュボード
- 四半期末の振り返りテンプレ

---

## セットアップ

```
目標管理セットアップして
```

### 最初に「タイプ」を聞かれます

- A) お試し — サンプルで動作確認、PCに書き込まない
- B) 最低限（3問）— フレームワーク / レビュー頻度 / 保存先
- C) しっかり — タスク管理ツール連携までフル設定

## フレームワーク対応

| フレームワーク | 向いているケース |
|--------------|---------------|
| SMART | 個人目標、プロジェクト目標 |
| OKR | 組織全体、四半期単位、チャレンジ目標 |
| KPI | 営業・マーケ等の数値管理 |
| GTD | 日々のタスク整理、プロジェクト管理 |
| シンプル箇条書き | 複雑なフレームワークが負担なとき |

混在OK（組織ではOKR、個人はSMART、等）。

## 他エージェント連携

セットアップで許可した場合のみ:

- 秘書: 目標関連のメール・約束を取り込み
- MTG: 目標レビュー会議の議事録から進捗更新
- スプレッドシート: 目標管理シートとの同期
- レポート作成: 振り返りレポートの自動生成

タスク管理ツール（Todoist / Linear / Notion 等）との連携は 都度最新のMCP/APIを調査 して提案。

## よくある質問

### Q. フレームワークよく分からない、どれがいい？
迷ったらSMARTがおすすめ。個人目標なら汎用的で使いやすい。組織全体ならOKRに挑戦する価値あり。

### Q. 目標を外部（Notion / Todoist 等）に同期したい
連携設定で対応可能。ただし書き込み系の同期は、毎回ユーザー承認 を取る設計です。勝手に書き込んでタスクが増えるような事故は起きません。

### Q. 達成できなかった目標はどうする？
自動で「未達成」と判定はしません。振り返りでユーザーが「未達成だった」「部分達成だった」を自分で判定します。

### Q. プライベートな目標と仕事の目標を分けたい
目標ファイルを別フォルダで管理できます（`goals/work/` と `goals/personal/`）。セットアップ時に指定。

### Q. 勝手にリマインドが来るのが苦手
リマインド送信は しません。定期実行でも、ログファイルに「今週の目標」を書き出すだけで、通知は送りません。

### Q. やめたくなったら？
`rm -rf ./.goal-tracker/`（Windowsは `Remove-Item -Recurse -Force ./.goal-tracker/`） で完全に消えます。
