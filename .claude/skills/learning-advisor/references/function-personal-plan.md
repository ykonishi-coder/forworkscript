# 機能: 個人学習ロードマップ

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.learning-advisor/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


## 手順

### 1. 意図確認（function-intent-check.md で実施済み）

### 2. 現状把握
- 現在のスキル
- 学習経験
- モチベーション

### 3. ゴール設定（SMART）
- Specific: 具体的に
- Measurable: 測定可能
- Achievable: 達成可能
- Relevant: 関連性
- Time-bound: 期限

### 4. ロードマップ設計

#### フェーズ分け

```markdown
## Phase 1: 基礎（1ヶ月）
- 目標: 基本概念の理解
- 教材: {書籍・動画}
- 週 X 時間

## Phase 2: 応用（2ヶ月）
- 目標: 実践できる
- 実習・プロジェクト
- アウトプット（ブログ・GitHub）

## Phase 3: 発展（3ヶ月〜）
- 目標: 人に教えられる
- 深堀り・専門化
- コミュニティ参加
```

### 5. 教材選定
`function-material-recommend.md` で最新推奨。

### 6. 習慣化の仕組み
- 学習時間の固定化
- 進捗可視化（goal-tracker 連携）
- 仲間・アカウンタビリティ

### 7. 評価指標
- アウトプット数
- 実務適用回数
- 自己評価（フィードバック）

## よくあるスキル別ロードマップ例

### プログラミング（Web 開発）

```
1. HTML / CSS（1ヶ月）
2. JavaScript（2ヶ月）
3. フレームワーク（React 等）（2ヶ月）
4. バックエンド（Node.js / Python）（2ヶ月）
5. データベース・インフラ（1ヶ月）
6. ポートフォリオ作成（継続）
```

### データ分析

```
1. Excel 応用・基本統計（1ヶ月）
2. SQL（1ヶ月）
3. Python / Pandas（2ヶ月）
4. 可視化（Matplotlib / Tableau）（1ヶ月）
5. 機械学習基礎（2ヶ月）
6. 実務プロジェクト（継続）
```

### ビジネス英語

```
1. 基礎文法・語彙（1ヶ月）
2. リスニング・発音（2ヶ月）
3. ビジネス会話（2ヶ月）
4. メール・プレゼン（1ヶ月）
5. 継続（英語環境に浸る）
```

### マーケティング

```
1. 基礎フレームワーク（1ヶ月）
2. デジタルマーケ（2ヶ月）
3. データ分析（1ヶ月）
4. 実務適用（継続）
```
