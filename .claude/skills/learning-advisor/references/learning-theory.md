# 学習理論

教育設計に使える理論・原則。

## 成人学習（アンドラゴジー）- Knowles

### 5原則
1. 自己主導的: 学習者が主体
2. 経験の活用: 既存経験を活かす
3. 学ぶ準備: 必要性を感じている
4. 問題解決志向: 実務直結
5. 内発的動機: 外圧より自発性

### 子ども（ペダゴジー）との違い
- 子ども: 教師主導・教科書中心
- 大人: 学習者主導・経験中心

## 学習科学の原則

### 1. アクティブリコール
- 読むだけより、思い出す練習
- テスト効果

### 2. 間隔反復（Spaced Repetition）
- 時間を空けて復習
- Anki 等のツール

### 3. インターリーブ学習
- 複数トピックを混ぜて学ぶ
- 転用能力向上

### 4. 精緻化（Elaboration）
- 「なぜ？」「どうやって？」を問う
- 既存知識と結びつける

### 5. 二重符号化
- 言語 + 視覚
- 図 + 説明

### 6. 具体例
- 抽象だけでなく具体例
- 複数例で一般化

### 7. メタ認知
- 自分の理解を振り返る
- 学び方を学ぶ

## ブルームのタキソノミー

認知レベルの6段階:

1. 記憶 - 覚えている
2. 理解 - 意味が分かる
3. 応用 - 使える
4. 分析 - 分解・構造化
5. 評価 - 判断できる
6. 創造 - 新しいものを作る

学習目標設定時に活用。

## コンピテンシー（できる）vs 知識（知っている）

- 知識: What を知っている
- スキル: How ができる
- 態度: Why・価値観

バランス取って設計。

## 習得の 4 段階（Noel Burch）

1. 無意識的無能: 知らないことを知らない
2. 意識的無能: 知らないことを知る（挫折ポイント）
3. 意識的有能: 考えればできる
4. 無意識的有能: 自然にできる

段階に応じた支援方法が違う。

## フィードバック

### 効果的な FB
- 即時（学習直後）
- 具体的（曖昧でない）
- 行動に焦点（人格でなく）
- 改善可能（実行可能な提案）

### SBI モデル（Situation・Behavior・Impact）
- 状況
- 行動
- 影響

## 70:20:10 の法則

学習の割合:
- 70%: 実務経験
- 20%: 他者からの学び（メンター・上司）
- 10%: 研修・座学

研修だけで能力は伸びない。実務と組み合わせる。

## 学習曲線とプラトー

- 初期: 急速に成長
- 中期: プラトー（停滞）
- 上級: ゆっくり成長

プラトー期は挫折しやすい → サポート重要。

## モチベーション（Pink "Drive"）

### 外発的動機
- 報酬・罰
- 短期的には有効

### 内発的動機
- Autonomy（自律性）
- Mastery（熟達）
- Purpose（目的）

長期継続には内発的動機が必要。

## フロー理論（Csikszentmihalyi）

学習の最適状態:
- スキル ≈ 難易度
- 目標明確
- 即時フィードバック

→ 段階的に難易度を上げる。

## 反転学習（Flipped Classroom）

- 事前: 動画・読書で基礎（インプット）
- 集合: 演習・議論（アウトプット）

## ADDIE モデル（教育設計）

1. Analysis: 分析
2. Design: 設計
3. Development: 開発
4. Implementation: 実施
5. Evaluation: 評価

反復して改善。

## カークパトリックの4段階評価

研修効果測定:

1. Reaction: 反応（満足度）
2. Learning: 学習（知識・スキル）
3. Behavior: 行動変容
4. Results: ビジネス成果

深いレベルほど測定難しいが、本質的。

## 学習スタイル（諸説あり・ただし注意）

- 視覚型 / 聴覚型 / 体験型（VAK）
- 論理型 / 直感型

注意: 学習スタイル理論は科学的根拠が弱いとする研究もある。個別最適化の1要素として参考程度に。

## 認知負荷理論

短期記憶の容量は限られる。

- 内在的負荷: 内容の難しさ
- 外在的負荷: 提示方法
- 生成的負荷: 理解への労力

→ 外在的負荷を減らし、生成的負荷を上げる。

## 実装のポイント

教育設計時は:

1. 成人学習の5原則
2. アクティブリコール + 間隔反復
3. 70:20:10
4. 内発的動機
5. 即時フィードバック
6. カークパトリック評価

これらを意識すると、科学的根拠ある教育設計ができる。
