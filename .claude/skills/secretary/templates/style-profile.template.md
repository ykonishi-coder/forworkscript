## メール文体

### 使用言語

- 主に使用: `日本語`
- 英語メールの頻度: `{低 / 中 / 高}`

### 宛名

- 社外の初対面: `{相手姓}様`
- 社外の継続取引先: `{相手姓}様`
- 社内の上司・目上: `{相手姓}さん`
- 社内の同僚: `{相手姓}さん`
- 社内の部下: `{相手姓}さん`
- 英語メール社外: `Dear {First Name},` または `Hi {First Name},`
- 英語メール社内: `Hi {First Name},`

### 書き出し

#### 社外
- 第一候補: `お世話になっております。{自社}の{自分}です。`
- 第二候補: `いつも大変お世話になっております。`
- 初回: `はじめまして。{自社}の{自分}と申します。`

#### 社内
- 第一候補: `お疲れ様です。{自分}です。`
- 第二候補: `お疲れ様です。`

#### 英語
- 第一候補: `Thanks for reaching out.`
- 第二候補: `Hope you're doing well.`

### 一人称・自称

- 社外: `私` / 組織を指すとき `弊社` または `{自社}`
- 社内: `私` / 部署を指すとき `{自部署}`
- 英語: `I` / 組織は `we` / `our team`

### 敬語レベル（0タメ / 1丁寧 / 2標準敬語 / 3格式高い）

- 社外: `2`
- 社内上司: `2`
- 社内同僚: `1`

### 段落・箇条書き

- 段落の長さ: `短め / 標準 / 長め のいずれか`
- 箇条書きの使用: `積極的に使う / 必要なときだけ / ほぼ使わない`

### 絵文字

- 社外: `使わない`
- 社内: `{使わない / カジュアルな相手のみ / よく使う}`

### 頻出表現・言い回し

<!-- 学習で抽出された、あなた特有の言い回し -->

- `（ここに学習結果が入ります）`
- `（例: 「念のためご共有まで」「取り急ぎ」など）`

### 締め句

#### 社外
- 第一候補: `引き続きよろしくお願いいたします。`
- 第二候補: `何卒よろしくお願い申し上げます。`
- 取り急ぎ: `取り急ぎご連絡まで。`

#### 社内
- 第一候補: `よろしくお願いします。`

#### 英語
- 第一候補: `Best regards,`
- 第二候補: `Thanks,`

### 件名の付け方

- 返信時: `Re: をそのまま継承`
- 新規件名の癖: `{簡潔 / 具体的 / 丁寧}`

## スケジュールの好み

### 朝のサマリ

- 受け取り時刻: `08:30`
- 詳細度: `時系列 + 相手 + 場所 + 準備物`
- 表示形式: `時系列リスト + 注目ポイント`

### 空き時間の定義

- 最小単位: `30分以上`
- ランチ時間: `12:00 - 13:00 固定希望`
- 業務時間: `09:00 - 18:00`

### 移動時間の想定

- 社外訪問（片道）: `30分`
- 予備時間: `10分`

### プライベート予定の扱い

- タイトル表示: `非表示（「プライベート」と匿名化）`

### 会議・予定タイプの呼び方

- 標準: `会議 / 打ち合わせ / MTG`
- 社外との接点: `訪問 / 商談 / 会食`
- 社内の定例: `定例 / 1on1`
