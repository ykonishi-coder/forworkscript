# 文体・好み 学習ガイド

秘書がユーザー本人の文体・予定の好みを学習し、`style-profile.md` に蓄積する手順。

## 大前提（安心事項）

- 抽出するのは「特徴」だけ。メール本文や予定の原文をそのまま保存しない
- 保存先はあなたのPC内のみ。外部サーバーには送られない
- Claude の学習データには使われない
- 固有名詞は自動でマスキング:
  - 人名 → `{相手名}`
  - 会社名 → `{会社名}`
  - 金額・日時 → `{金額}` `{日時}`
  - メールアドレス・電話番号 → `{連絡先}`
- 不安なら学習をスキップしても十分使える（デフォルトのビジネス文体で始めて後から追加可能）

## 学習の3方式

### 方式A: 連携経由で自動読み込み（優先）

- Gmail MCP / Graph API / AppleScript 等の連携がある場合
- 送信済みフォルダから自分が差出人のメールを取得
- 取得数: ウィザードで指定（10 / 30 / 50 / 100 通）

処理中の安心フォロー:

> 過去の送信メールから文体の特徴だけを抽出しています。
> メール本文そのものは保存せず、抽出が終わり次第破棄します。
> 固有名詞（名前・会社名・連絡先）は自動でマスキング済みです。

### 方式B: 貼り付け方式

- 手動コピペ連携の場合、または方式Aが使えない場合
- ユーザーに過去の送信メールを3通以上貼り付けてもらう:

> 過去にご自身が書いた送信済みメールを、3通以上コピペしてください。
>
> 以下の種類が混ざっていると、より正確に学習できます:
> - 社外の取引先向け
> - 社内の同僚・上司向け
> - カジュアルな宛先
>
> 宛先名や会社名は、気になる場合は `XXX` 等に置換してから貼ってくださって構いません。

### 方式C: スキップ

- ウィザードで「いまはスキップ」を選んだ場合
- `style-profile.md` はテンプレートのデフォルト（汎用ビジネス文体）のまま
- 後からいつでも `/secretary learn` のような依頼で学習追加可能

## 抽出観点

### メール関連

1. 宛名パターン: 「〜様」「〜さん」「〜先生」等、社外/社内の使い分け
2. 書き出し: 「お世話になっております」「お疲れ様です」「ご連絡ありがとうございます」等
3. 一人称: 「私」「当方」「弊社」「うち」
4. 締め句: 「引き続きよろしくお願いいたします」「取り急ぎご連絡まで」等
5. 敬語レベル: 0（タメ）/ 1（丁寧）/ 2（標準敬語）/ 3（格式高い）
6. 頻出表現・口癖: 「念のためご共有まで」「取り急ぎ」「ざっくり」等
7. 絵文字・記号: 使う/使わない、相手傾向
8. 改行・段落: 長め/短め、箇条書きの多用
9. 件名の付け方: Re: 継承、新件名、括弧補足など

### 予定の好み（スケジュール確認機能用）

1. 予定タイプの呼び方: 「打ち合わせ」「会議」「ミーティング」「MTG」等
2. 空き時間の最小単位: 30分以上を空きと見なす／60分以上が必要、等
3. 朝のサマリの詳細度: 時系列のみ / 相手まで / 場所まで / 準備物まで
4. ランチ時間の扱い: 固定 / 都度入れる
5. 移動時間の基準: 社外訪問時の標準移動時間
6. プライベート予定の表示可否: タイトル表示OK / 「プライベート」と匿名化

### 署名

- 氏名・役職・会社名・連絡先
- 社外用と社内用で使い分けがあれば両方記録

---

## 抽出処理の具体手順

1. 収集: 方式 A / B で本文を取得
2. マスキング: 固有名詞を汎化（正規表現 + 文脈判断）
3. 頻度集計: 各観点について出現した表現をカウント
4. 上位抽出: 各観点ごとに頻出上位3〜5個を選択
5. プロファイル更新: `style-profile.md` の該当セクションを上書き
6. 破棄: 元メール/予定の本文はメモリから解放、ファイルにも残さない

---

## 継続学習

### 手法1: ユーザーの編集差分を拾う（可能な場合）

- 下書き保存 → ユーザーが編集して送信 → 送信済みを次回取得時に検出
- 生成ドラフトと実送信版の差分を検出
- 繰り返しパターンがあればプロファイル更新提案

更新前は 必ずユーザー通知:

> 最近、「お世話になっております」→「お疲れ様です」に毎回直されています。
> プロファイルを更新しますか？

### 手法2: 明示フィードバック

- 「このドラフトの『取り急ぎ』は違和感がある」等の自由入力
- 「/secretary learn」のような呼び出しで追加の過去メールを渡す

### 手法3: 定期レビュー（月1回など）

- 過去1ヶ月の送信メールを再サンプリング
- 職場変更等で文体が変化していれば自動追従

---

## ガードレール

- 1通や2通の変な特徴を学習しない: 出現回数が少ないパターンは採用しない
- 自動更新前は必ずユーザー通知
- 履歴バックアップ: 更新時は `style-profile.md.{日付}.bak` を残す
- 誤学習の兆候除外: 絵文字のみメール、署名のみメール、自動返信などは対象外
- 予定情報の長期保存禁止: 予定は都度取得・処理後破棄

## 出力例（学習後の style-profile.md）

具体的な雛形は `templates/style-profile.template.md` 参照。

```markdown
# 文体・好みプロファイル

## メール文体

### 宛名
- 社外: 「{相手姓}様」
- 社内: 「{相手姓}さん」

### 書き出し
- 社外: 「お世話になっております。{自社名}の{自分}です。」
- 社内: 「お疲れ様です。{自分}です。」

### 締め
- 社外: 「引き続きよろしくお願いいたします。」
- 社内: 「よろしくお願いします。」

## スケジュールの好み

- 朝サマリ時刻: 08:30
- 空き時間の最小単位: 30分
- ランチ: 12:00-13:00 固定希望
- 移動時間: 社外訪問は片道30分想定
- プライベート予定: タイトル非表示で「プライベート」と表示

## 署名

（中略）

## 学習履歴

- YYYY-MM-DD: 初回学習、送信メール30通から抽出
```

## 最終確認メッセージ

学習完了時:

> 文体・好みプロファイルの作成が完了しました。
>
> 保存先: `{パス}/style-profile.md`
>
> - 個人情報（宛先名・会社名等）はマスキング済み
> - プロファイルはあなたのPC内にのみ保存
> - 中身は `style-profile.md` を開いて直接編集できます
> - 違和感がある項目はいつでも書き換えてOK
>
> 今後、秘書のドラフトやサマリがあなたらしくないと感じたら、いつでもプロファイルを更新できます。
