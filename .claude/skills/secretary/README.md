# 秘書 (Secretary)

あなたの代わりに、メール返信の下書きとスケジュール確認をしてくれるAI秘書。

---

## プライバシーについて（最初に）

- 入力した情報は Claude の学習データには使われません
- 設定ファイルは あなたのPC内 にしか保存されません
- 氏名・署名・予定情報は、秘書作業のために手元で参照するだけ
- 実送信・予定の変更は絶対にしません。下書き・提案までが上限

---

## できること

### メール返信下書き

- 受信メールを読んで、あなたの文体で返信ドラフトを3案作成
- Gmail / Outlook / Apple Mail / Thunderbird の下書きフォルダに保存、または表示のみ
- 使うほど文体が合ってくる（継続学習）

### スケジュール確認（表示系）

- 今日の予定サマリ
- 次の予定
- 空き時間検索
- 候補日提示（会議設定の叩き台）
- 所要時間見積もり・準備物の洗い出し

※予定の追加・変更・削除はしません。提案までで止めます。

### 定期実行

- 1日1回、朝に「今日の予定サマリ」と「メール返信下書き」を用意しておく運用が可能
- 頻度はカスタマイズ可能（1日2回 / 毎時 / 手動のみ）

---

## セットアップ

Claude Code で以下のように話しかけます:

```
秘書セットアップして
```

### 最初に「タイプ」を聞かれます

> A) まず何ができるか試してみたい
> B) 最低限だけ設定して、すぐ使い始めたい
> C) しっかり設定して、自分に合わせて便利に活用したい
> D) まだよく分からない / 選べない

### A) お試しモード（質問ゼロ・約3分）
- サンプルで動作確認
- PCに何も書き込まれない

### B) 最低限セットアップ（3問・約5分）
- メール/カレンダーツール / 署名 / 定期実行の有無
- 迷ったらこれがおすすめ

### C) しっかりセットアップ（約15分）
- 文体学習、ツール連携、対象絞り込みまで細かく調整

## ツール連携について

- 最小構成（連携なし） でも動きます
- セットアップ時に 最新の連携情報を調査 して提案
- 迷ったら連携なしで始めるのが最も安心

## よくある質問

### Q. 入力した情報は Claude の学習に使われますか？
いいえ、使われません。

### Q. 会社のPCで使っても大丈夫？
設定はローカル保存ですが、処理時にはメール本文や予定情報が Claude API に送られます。会社の情報セキュリティポリシーで外部送信が制限されている場合は、IT部門に確認してからご利用ください。

### Q. 勝手に送信されたり予定が変わったりしないか心配
秘書は送信機能・予定変更機能を 物理的に持っていません。下書き保存・サマリ生成までで必ず止まります。

### Q. やめたくなったら、どう消せますか？
1. 定期実行を止める: `/schedule` または `crontab -e` で該当エントリ削除
2. 設定フォルダを削除: `rm -rf ./.secretary/`（Windowsは `Remove-Item -Recurse -Force ./.secretary/`）

### Q. 文体が合わないと感じたら？
`style-profile.md` を開いて直接編集してください。次回から反映されます。

## ファイル構成

```
secretary/
├── SKILL.md                         # 起動点
├── README.md                        # このファイル
├── references/
│   ├── wizard-setup.md              # 初回セットアップ（Q0+3プラン分岐）
│   ├── function-email-reply.md      # メール返信機能
│   ├── function-schedule-check.md   # スケジュール確認機能
│   ├── tool-integrations.md         # 連携ツール（都度最新調査）
│   ├── style-learning.md            # 文体・好み学習
│   └── schedule-setup.md            # 定期実行設定
└── templates/
    ├── config.template.yaml         # 設定雛形
    └── style-profile.template.md    # 文体・好み雛形
```

セットアップ後、以下が生成されます（保存先はウィザードで選択）:

```
{保存先}/
├── config.yaml
├── style-profile.md
└── logs.txt
```
