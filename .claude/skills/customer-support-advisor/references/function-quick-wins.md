# 機能: 改善策の提案

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.customer-support-advisor/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


現状から 即効性ある改善策 を提案。

## すぐできる改善の基準

- 短期間で効果（1週間〜1ヶ月）
- 低コスト（既存ツール・無料サービス）
- すぐ実行可能（複雑な承認・学習不要）
- 効果が測定可能

## よくある改善策（Top 10）

### 1. FAQ 整備（効果大・コスト 0）

#### やること
- 過去 3ヶ月の問い合わせを分析
- 頻出 Top 10-30 をリスト化
- 標準回答を作成
- ヘルプページ or Notion / Google Docs で公開

#### 期待効果
- 問い合わせの 30-50% 削減
- 自己解決で顧客満足度向上

#### 期間
1週間

### 2. 返信テンプレート（効果中・コスト 0）

#### やること
- 頻出質問への定型返信を作成
- Gmail の「テンプレート」機能 or Snippet
- 個別カスタマイズ部分は `{}` で

#### 期待効果
- 1 件あたり対応時間 50% 削減
- 品質均一化

#### 期間
3日

### 3. 問い合わせ分類（効果中・コスト 0）

#### やること
- カテゴリ定義（技術 / 請求 / 契約 / 要望 / その他）
- ラベル or タグ付与
- 月次でデータ集計

#### 期待効果
- 傾向把握
- リソース配分最適化

#### 期間
1日（ルール定義）

### 4. 営業時間・レスポンス時間の明示（効果大・コスト 0）

#### やること
- 問い合わせフォーム横に「◯営業日以内に返信」等を記載
- 自動返信で受付確認 + 目安時間

#### 期待効果
- 顧客の不安軽減
- クレーム削減

#### 期間
1日

### 5. 問い合わせフォームの最適化（効果中・コスト 0）

#### やること
- 必須項目を絞る
- 「問い合わせ種類」プルダウン追加
- 自動振り分け

#### 期待効果
- 不完全な問い合わせ削減
- 振り分け時間短縮

#### 期間
3日

### 6. ナレッジ共有の仕組み（効果大・コスト 低）

#### やること
- Notion / Google Docs で社内ナレッジ
- 難問への解決策を共有

2週間

半日

## 優先順位の決め方

### 効果 vs 労力 マトリクス

```
効果大 × 労力小: 最優先 🌟
  - FAQ 整備
  - テンプレート作成
  - フォーム最適化
  - レスポンス時間明示

効果大 × 労力大: 計画的に
  - ナレッジ共有の仕組み
  - オンボーディング整備

効果小 × 労力小: 空き時間で
  - フィルタ設定
  - カテゴリ整理

効果小 × 労力大: 後回し
```

### 現状から最適を選ぶ

ユーザーの課題に合わせて:

| 課題 | 推奨すぐできる改善 |
|------|-----------------|
| 同じ質問が多い | FAQ 整備 + セルフサービス |
| レスポンス遅い | テンプレート + 受付自動返信 |
| 属人化 | ナレッジ共有 + エスカレフロー |
| 品質バラつき | テンプレート + 教育資料 |
| コスト高 | 自動化・FAQ |
