# 機能: 情報整理

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.research-assistant/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


収集した情報を構造化・分類する。

## 手順

### 1. 情報の分類

観点別に:
- 事実 / 意見 / 推測
- 定量 / 定性
- 現状 / 過去 / 予測
- カテゴリ別（市場・プレイヤー・トレンド・顧客）

### 2. 矛盾の解消

複数ソースで不一致がある場合:

```markdown
### 市場規模について

- ソースA（IDC 2025）: 1.5 兆円
- ソースB（矢野経済 2024）: 1.2 兆円

考察: 算出方法・対象範囲の違いが原因。
- IDC: BtoB SaaS + IaaS 含む
- 矢野: BtoB SaaS のみ

→ 採用: 目的に応じて選択。今回の調査では「BtoB SaaS」が対象なので矢野の 1.2 兆円。
```

### 3. 時系列整理

変化を追う:
```markdown
### 市場規模の推移
- 2020: 5,000 億円
- 2021: 7,000 億円
- 2022: 9,000 億円
- 2023: 1.1 兆円
- 2024: 1.2 兆円
CAGR: 24%（2020-2024）
```

### 4. 比較整理

競合・選択肢などは表で:

```markdown
| 項目 | A社 | B社 | C社 |
|------|-----|-----|-----|
| 売上 | ¥X億 | ¥Y億 | ¥Z億 |
| シェア | X% | Y% | Z% |
| 強み | ... | ... | ... |
```

### 5. 論理構造

- 主張 → 根拠 → 出典
- 論理の飛躍を避ける
- 推測と事実を明示

### 6. 重要度の判定

- 🔴 クリティカル（必須情報）
- 🟡 重要（あった方がいい）
- 🟢 参考（補足）

## 図解の提案

情報を視覚化:
- 棒グラフ・円グラフ（数字）
- ツリー（階層）
- マトリクス（比較）
- フロー図（プロセス）
- マップ（地域・関係性）

実際の作図は spreadsheet-operator や design-consultant と連携。

## 未確認事項の記録

```markdown
### 未確認
- {情報}: 「{主張}」
- 理由: 1ソースしか見つからず、クロスチェック不可
- 推奨: 追加調査 or 専門家確認
```

- 論理の飛躍
- 偏り
- 相関と因果の混同
