# 機能: レポート生成

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.research-assistant/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


整理された情報から調査レポートを作成。

## レポート構造

`templates/research-report.template.md` 参照。

### 標準構造

```markdown
# 調査レポート: {テーマ}

## エグゼクティブサマリ
（1ページで要点）

## 1. 調査目的・方法
- 目的
- 調査範囲
- 情報源
- 調査期間

## 2. 主要発見
（5-10 項目でポイント）

## 3. 背景
（文脈・業界構造）

## 4. 調査結果の詳細
### 4.1 市場規模
### 4.2 主要プレイヤー
### 4.3 トレンド
...

## 5. 分析・考察
- パターン
- 示唆
- 反対解釈

## 6. 結論・提言
- 結論
- アクション提案
- 次の調査ポイント

## 7. 付録
- 参考資料一覧
- 詳細データ
- 用語集

## 情報の鮮度
- 調査日: YYYY-MM-DD
- 主要情報の公表日

## 免責
{必要に応じて}
```

## レポートの種類別

### エグゼクティブサマリ（1ページ）
- 経営層向け
- 結論先出し
- 数字で示す

### スタンダードレポート（5-10ページ）
- 標準的なビジネスレポート
- 意思決定材料

### 詳細レポート（20-50ページ）
- 本格的な調査報告
- 付録充実

### ダッシュボード形式
- 定期更新
- 数字中心

## 出典の扱い

### インライン引用
```markdown
SaaS 市場規模は 1.2 兆円（矢野経済研究所, 2024）。
```

### 脚注形式
```markdown
SaaS 市場規模は 1.2 兆円[^1]。

[^1]: 矢野経済研究所『2024年 BtoB SaaS 市場の実態と展望』
```

### 参考文献一覧
```markdown
## 参考文献

1. 矢野経済研究所『2024年 BtoB SaaS 市場の実態と展望』, 2024年12月
2. IDC Japan "Japan SaaS Market Forecast 2025-2030", March 2025
3. 経済産業省「情報サービス産業統計」, 2024年
```

## 他エージェント連携

## DA チェック
