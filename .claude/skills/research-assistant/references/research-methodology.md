# リサーチ方法論

ディープリサーチを効果的に進めるためのガイド。

## ディープリサーチとは

単発の検索で済ませず、多段階・複数ソース で徹底的に掘り下げる調査手法。

### 単発 vs ディープ

単発（浅い）:
- 1つの検索で終わり
- トップの記事だけ読む
- 1ソースで結論

ディープ（深い）:
- 複数のキーワードで検索
- 複数のソースを比較
- 原典までたどる
- 時系列で変化を追う
- 反対意見も探す

## 5 ステップの進め方

### Step 1: 調査目的の明確化

曖昧:
> 「SaaS について調べて」

具体的:
> 「国内 BtoB SaaS 市場の規模と CAGR、主要プレイヤー上位5社のシェア、
> 今後3年間の成長予測、カスタマイゼーション可能な SaaS のトレンド」

### Step 2: 調査計画

| 観点 | 情報源候補 | 優先度 |
|------|-----------|-------|
| 市場規模 | IDC Japan, 矢野経済 | 高 |
| プレイヤー | 決算資料, 公開情報 | 高 |
| トレンド | 業界誌, 海外レポート | 中 |
| 顧客動向 | 調査会社, ユーザー調査 | 中 |

### Step 3: 情報収集

#### 検索クエリ設計

効果的なクエリ:
- キーワード + 情報源（「SaaS 市場 IDC」）
- キーワード + 年（「BtoB SaaS 2026」）
- 英語併用（「Japan SaaS market size」）
- 同義語展開（「クラウドサービス」「SaaS」「ソフトウェアサービス」）

#### 複数回検索

同じトピックを 異なるクエリ で 3-5 回検索。

#### 公式 → 専門 → 一般 の順

1. 政府統計・業界団体
2. 大手調査会社
3. 大手メディア・業界誌
4. 専門ブログ
5. 一般ブログ・SNS（参考程度）

### Step 4: 情報評価

#### 信頼度評価
詳細は `source-evaluation.md`。

#### クロスチェック
重要な主張は 必ず複数ソース で確認。

#### 鮮度
- 取得日を記録
- 古い情報は「YYYY年時点」と明示
- 法改正・市場変化で古くなる可能性

#### 偏り検出
- すべてのソースが同じ結論か
- 反対意見を探す
- 発信元の立場（製品提供企業のポジショントーク？）

### Step 5: 整理・構造化

#### フレーム
- 時系列（過去 → 現在 → 未来）
- 規模感（TAM → SAM → SOM）
- 観点別（規模 / プレイヤー / トレンド / 顧客）
- 地域別（日本 / 世界）

#### 図解
- 表・グラフ（情報源の数字を使う）
- ツリー構造
- 比較マトリクス

## よくある失敗

### 1. 1ソース依存
1つのブログや記事で結論。

→ 必ず複数ソース

### 2. 古い情報を最新と誤認
3年前の統計を「最新」扱い。

→ 取得日・公表日を確認

### 3. 確証バイアス
自分の仮説に合う情報だけ集める。

→ 意図的に反証を探す

### 4. 権威への盲信
有名メディア = 正確ではない。原典を確認。

→ 一次ソースへ遡る

### 5. 相関と因果の混同
「売上増」と「広告費増」が相関 ≠ 広告が売上を上げた。

→ 因果関係は慎重に判断

## 専門領域別のヒント

### 市場調査
- 業界団体の公式統計を最優先
- 上場企業の決算資料（EDINET）
- 調査会社レポート（有料でも概要は公開）

### 技術調査
- 公式ドキュメント
- GitHub の実装
- 学術論文（arXiv, Google Scholar）
- Stack Overflow

### 法律調査
- e-Gov 法令検索
- 裁判所ウェブサイト
- 各省庁

### 人物・企業調査
- 公開プロフィール（LinkedIn 等）
- プレスリリース
- 登記情報
- 帝国データバンク

### 学術調査
- Google Scholar
- J-STAGE
- arXiv
- PubMed（医学）

## ディープリサーチのチェックリスト

調査完了前に:

- [ ] 複数のキーワードで検索したか
- [ ] 3つ以上の信頼できるソース
- [ ] 取得日を記録
- [ ] 一次ソースまで遡った
- [ ] 反対意見・反証を探した
- [ ] 自分の仮説を疑った
- [ ] 出典を全て記録

## ネット検索の限界

ディープリサーチでも、ネット情報には限界があります:

- 有料データベースにアクセスできない（一部）
- 非公開情報は取れない（社内資料 等）
- リアルタイムデータは遅延
- 言語の壁（日本語で情報がない分野）

補完方法:
- 専門家インタビュー（人づて）
- 有料レポート購入
- 社内情報（該当組織なら）
- 現地調査

## 倫理

- 著作権を守る（引用は短く、出典明記）
- スクレイピングの利用規約遵守
- 個人情報を目的外に使わない
- 誹謗中傷・名誉毀損につながる調査はしない
