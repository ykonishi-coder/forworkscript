# 機能: 調査計画

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.research-assistant/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


調査を始める前に、何をどう調べるかを設計する。

## 手順

### 1. ヒアリング

- 目的: 何のための調査？
- 問い: 具体的に何を知りたい？
- 読者: 誰のためのレポート？
- 期限: いつまでに？
- 深度: 概要 / 標準 / 徹底

### 2. 問いの具体化

曖昧な依頼を具体的な問いに分解:

Before:
> 「SaaS 業界調べて」

After:
- SaaS 国内市場規模の推移（2020-2025）
- 主要プレイヤー上位10社のシェア・成長率
- カテゴリ別（HR, CRM, 会計, マーケ）の分布
- 今後 3 年の成長予測
- 注目のスタートアップ

### 3. 調査範囲

- 地域（日本 / グローバル）
- 期間（過去 N 年 / 最新のみ）
- 業種・カテゴリ
- 深度（数字だけ / トレンド含む / 戦略示唆まで）

### 4. 情報源の特定

カテゴリ別に事前に決める:

```markdown
| 問い | 情報源候補 | 優先度 |
|------|-----------|-------|
| 市場規模 | IDC, 矢野経済, 経産省 | ★★★★★ |
| プレイヤー | 決算資料, プレスリリース | ★★★★★ |
| トレンド | 業界誌, ブログ | ★★★★ |
| 顧客動向 | アンケート, SNS | ★★★ |
```

### 5. 検索クエリ設計

同じトピックを複数角度で:

```
SaaS 市場規模 日本 2026
SaaS market Japan 2026
BtoB SaaS 統計
クラウドサービス業界
SaaS IDC レポート
```

### 6. 時間配分

- 軽量: 30分
- 標準: 2-3 時間
- 徹底: 1 日以上

各フェーズ（収集 / 整理 / レポート）の配分。

### 7. 成果物イメージ

- レポート形式
- 分量
- 必要な図表
