# 機能: 動画台本作成

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.content-creator/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


YouTube・TikTok・Instagram Reels 等の動画台本を作成。

## ⚠️ 最初に難易度を説明

動画を希望するユーザーには、最初に難易度を正直に伝える:

```markdown
### 動画コンテンツについて

AI では 完全自動化が難しい 領域です。

#### このスキルでできること 🟢
- 企画・ネタ出し
- 台本作成（このフェーズ）
- タイトル・説明文案
- サムネイル企画（構図・コピー）
- ハッシュタグ

#### できないこと 🔴
- 実際の撮影
- 動画編集（カット・エフェクト・BGM）
- 声・音声ナレーション
- イラスト・アニメーション制作

#### 動画を始めるなら
1. 台本まで はここで作ります
2. 撮影は自分（スマホで OK）
3. 編集は:
   - CapCut: 無料・AI 機能あり・初心者向け
   - DaVinci Resolve: 無料・プロ級
   - Premiere Pro: 有料・業界標準
4. サムネイルは Canva で

#### 動画制作の時間目安（10分動画の場合）
- 企画・台本: 1時間（AI 支援）
- 撮影: 1-2時間
- 編集: 3-5時間（スキル次第）
- サムネイル: 30分
- 投稿設定: 20分
- 合計: 5-9時間

#### 始め方の現実的なアドバイス
- いきなり週3本は挫折率高い
- 月1本から始めて継続
- 文章系・SNS でファンを作ってから動画も◎
- 外注も選択肢（編集者・サムネデザイナー）

この上で、台本作成に進みますか？
```

## 台本の構造（YouTube 10-20分動画）

### 典型的な構成

```markdown
## 1. オープニング（5-15秒）

- フック（視聴者を掴む）
- タイトル / 自己紹介
- 今日の内容予告

### スクリプト例
「{フック}! こんにちは、{チャンネル名}の {名前}です。
今日は〇〇について解説します。{見るメリット}。
それでは早速行きましょう！」

## 2. 導入（30-60秒）

- 背景・文脈
- 視聴者の課題・関心ごと
- この動画で得られること

## 3. 本編（各2-5分のチャプター複数）

### Chapter 1: {タイトル}
- ポイント
- 具体例
- 図解（編集で挿入指示）

### Chapter 2: ...

### Chapter 3: ...

## 4. まとめ（30-60秒）

- 要点の繰り返し
- アクション誘発（いいね・チャンネル登録）
- 次の動画予告

## 5. エンディング（5-15秒）

- お礼
- コールトゥアクション
```

## TikTok / Reels ショート動画

### 15-60 秒

```markdown
## 構成

### 1. フック（最初の 3秒）🔥 最重要
- 驚き
- 質問
- 意外な事実

### 2. 本編（残り）
- 要点を 1-3 個
- テンポよく
- テロップ必須

### 3. クロージング（1-2秒）
- フォロー誘導
- 次回予告

## スクリプト例

[0-3秒] 「知らなきゃ損する〇〇の裏技 3選！」
[3-10秒] テロップ: 「1. {裏技1}」+ 実演
[10-20秒] テロップ: 「2. {裏技2}」+ 実演
[20-30秒] テロップ: 「3. {裏技3}」+ 実演
[30-35秒] 「フォローで続きをチェック！」
```

## 撮影指示

台本にカメラ指示・編集指示を含める:

```markdown
[カット1]
- 画面: {話者アップ / 全身 / 画面キャプチャ}
- 動き: {手振り / 静止}
- 感情: {真剣 / 笑顔}

[カット2]
- 画面変更: {スクリーンキャプチャに切り替え}
- テロップ: 「重要ポイント: {文言}」
- BGM: {明るめ / 真面目}

[カット3]
- ズームイン効果
- 効果音: {チャイム}
```

## サムネイル企画

```markdown
## サムネイル案

### 案A: 文字強調型
- 大文字: 「知らなきゃ損」
- サブ: 「〇〇のコツ3選」
- 配色: 赤 + 黄（目立つ）
- 顔写真: あり（右下）

### 案B: ビフォーアフター型
- 左: Before（悪い例）
- 右: After（良い例）
- 矢印で誘導

### 案C: 驚き表情型
- 顔写真大 + 驚き表情
- 文字: 「衝撃の事実」

### 作成ツール
- Canva（テンプレート多数）
- Photoshop / Figma
- design-consultant 連携で方向性
- image-prompt-generator で要素画像生成
```

## タイトル案

```markdown
### タイトル候補

SEO 型:
1. 「{キーワード}とは？初心者でもわかる完全ガイド」
2. 「{テーマ}の基本から応用まで徹底解説」

フック型:
3. 「知らないと損する{テーマ}の真実」
4. 「なぜ99%の人が{テーマ}で失敗するのか」

リスト型:
5. 「{テーマ}で成功する7つのコツ」
6. 「絶対やってはいけない{テーマ}の NG 集」

数字・検証型:
7. 「{手法}を30日試した結果」
8. 「{手法} vs {手法}、勝つのはどっち？」

### 推奨: 案1（SEO）+ 案3（フック）のハイブリッド
「知らないと損する{キーワード}の真実 | 初心者向け完全ガイド」
```

## 完了メッセージ

```markdown
## 動画台本 作成完了

タイトル: {タイトル}
想定時間: 10分
構成: オープニング + 3 Chapter + まとめ

### 次のステップ

1. 📹 撮影（スマホで OK）
2. ✂️ 編集
   - CapCut でシンプルに始める
   - BGM は YouTube Audio Library 等の無料素材
3. 🎨 サムネイル（Canva）
4. 📝 説明文 + タグ
5. 🚀 公開・分析

### 難易度別の推奨ステップ
- 初心者: CapCut + スマホ撮影 → まず1本投稿
- 中級: DaVinci Resolve + カメラ + マイク
- 上級: Premiere + 機材一式

焦らず、まず 1本 完成させることが重要です。
```

## やってはいけないこと

- 著作権のある音楽・画像の無断使用
- 他者のアイデア・台本のコピー
- 誤情報・根拠なき主張
- 過度に煽る表現（景表法）
- ステマ（PR 隠し）
