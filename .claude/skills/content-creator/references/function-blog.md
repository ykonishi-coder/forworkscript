# 機能: ブログ記事作成

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.content-creator/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


## 手順

### 1. ヒアリング

- テーマ・タイトル
- ターゲット読者
- 目的（認知 / リード / CV / ブランディング）
- 文字数目安（1000-5000字）
- SEO キーワード（あれば）
- プラットフォーム（WordPress / Note / etc）

### 2. 構成案

```markdown
## タイトル: {タイトル}
## メタディスクリプション: 120-160字

## 記事構成

### 導入（リード文）
- 読者の課題・関心
- この記事で得られること
- 結論のチラ見せ

### 見出し H2-1: {要点1}
- 内容・例

### 見出し H2-2: {要点2}

### 見出し H2-3: {要点3}

### まとめ
- 要点の繰り返し
- 次のアクション（CTA）

### 関連リンク
- 内部リンク
- 外部参考
```

### 3. ドラフト執筆

各セクションを執筆。

### 4. SEO 最適化

- タイトルにキーワード
- メタディスクリプション
- 見出しに関連キーワード
- 内部リンク
- 画像 alt

### 5. DA レビュー

著作権・景表法・事実確認。

### 6. 出力

`templates/blog-post.template.md` 参照。

## SEO のコツ

- 検索意図 を理解
- E-E-A-T（Experience・Expertise・Authoritativeness・Trustworthiness）
- 読者ファースト（SEO より読者）
- 独自性（AI 生成感を減らす体験談・データ）

## AI 生成感を減らす

- 具体例を増やす
- 体験談を入れる
- 独自の考察
- 箇条書きの単調さを避ける
- 「私は」「弊社は」の視点
