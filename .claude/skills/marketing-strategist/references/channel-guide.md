# マーケティングチャネル ガイド

各チャネルの特徴・向き不向き・KPI。

## SEO（Search Engine Optimization）

### 特徴
- 中長期資産
- 獲得コスト低下（自然流入）
- 成果まで時間（3-12ヶ月）

### 向いている
- BtoB の検討期間が長い商材
- 情報型コンテンツ
- 特定ニッチキーワード

### 向いていない
- 即効性が必要
- トレンド商材
- 競合が極めて強い

### 主要 KPI
- オーガニック流入
- 検索順位
- 被リンク数
- CVR

### ツール
- Google Search Console
- Ahrefs / SEMrush
- Keyword Planner

## SEM / リスティング広告

### 特徴
- 即効性
- 顕在層獲得
- 費用対効果見えやすい

### 向いている
- すぐ買いたい顧客
- キーワードが明確
- 予算確保できる

### 主要 KPI
- クリック率（CTR）
- CPC
- CVR
- CPA

### ツール
- Google Ads
- Yahoo 広告
- Microsoft Advertising

## SNS マーケティング

### X（Twitter）

### Instagram
- ビジュアル中心
- BtoC 向き

- BtoB 広告に強い
- コミュニティ機能

### LinkedIn
- BtoB 最強

- ソートリーダーシップ

### TikTok

- 動画ショート

- 動画広告
- チャンネル構築
- 情報提供 + エンタメ

### 主要 KPI
- フォロワー数・増加率
- エンゲージメント率
- インプレッション
- コンバージョン

### 特徴
- 信頼性活用

### 主要 KPI
- リーチ
- エンゲージメント
- CV

## PR / メディアリレーション

### 特徴
- 第三者視点
- 信頼性
- 長期ブランド

### 向いている
- ニュース性
- 社会性
- 上場準備

## イベント / ウェビナー

### 特徴
- 直接接触
- 商談化
- 双方向コミュニケーション

### 向いている
- BtoB（ウェビナー）
- 高単価商材
- 教育的なプロセス

## ABM（Account-Based Marketing）

### 特徴
- 少数ターゲット
- パーソナライズ
- BtoB 専用

### 向いている
- 大型案件
- 特定業界
- 決裁者複数

## チャネル選定のポイント

### 顧客がどこにいるか
- ターゲットの情報収集行動
- デバイス
- 時間帯

### ファネル段階
- 認知: SNS / ディスプレイ広告 / PR
- 検討: SEO / コンテンツ / リスティング
- 決定: ランディング / リターゲティング
- 継続: メール / コミュニティ

### 予算
- 大: 広告中心
- 中: SEO + SNS + メール
- 小: コンテンツ + オーガニック SNS

### 緊急度
- 即効: 広告
- 中期: SEO + SNS
- 長期: ブランディング

## やってはいけないこと

- 全チャネルに分散（リソース不足）
- トレンドだけで選ぶ
- ターゲット不在のチャネル
- 法令違反（ステマ・景表法）
