# 機能: 現状整理

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.marketing-strategist/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


ユーザーの現在のマーケ状況を棚卸し。

## 重要性

マーケは広いため、現状を把握してから施策を提案 しないとピントがずれる。

## ヒアリング項目

### 1. 事業概況
- 事業内容・提供価値
- 顧客層
- 売上規模・成長率
- 主要商品・サービス

### 2. 現在のマーケ活動
- どのチャネルで何をやっているか
- 月間予算
- 担当者・体制

### 3. 数値状況
- 流入数（月間）
- リード数 / CV 数
- CVR / CPA
- LTV / CAC
- チャネル別内訳

### 4. 強み・弱み
- 差別化要素
- 競合との違い
- 課題

### 5. 目標
- 短期（3-6ヶ月）
- 中期（1-2年）
- KPI

## 出力

```markdown
## マーケ現状レポート

### 事業概要
- {サマリ}

### 現在のマーケ活動
| チャネル | 活動 | 月次予算 | 主要 KPI |
|---------|-----|---------|---------|
| SEO | ブログ週2記事 | 10万（外注費） | オーガニック月1000UU |
| Meta広告 | リード獲得キャンペーン | 30万 | リード単価5000円 |
| ... | ... | ... | ... |

### 数値サマリ
- 流入: 月間 X UU
- CV: 月間 Y 件
- CVR: Z%
- CAC: ¥A
- LTV: ¥B（推定）
- LTV/CAC: C 倍

### 強み
1. ...
2. ...

### 弱み
1. ...
2. ...

### 目標
- 短期: ...
- 中期: ...

### 次のステップ
- 戦略立案
- チャネル追加検討
- KPI 改善
```

## 判定

現状レポートから:
- 🟢 健全（次は最適化）
- 🟡 改善余地大
- 🔴 根本的見直し必要
