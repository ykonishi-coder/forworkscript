# 機能: ブランディング支援

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.marketing-strategist/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


ブランドのポジショニング・メッセージ・長期戦略。

## ブランディングの要素

### 1. ブランドの核

- ミッション: 何を実現するか
- ビジョン: どんな未来を目指すか
- バリュー: 大切にする価値
- パーソナリティ: ブランドを人に例えると

### 2. ポジショニング

- 誰に対して
- どんな違いを
- どんな価値

```
{ターゲット} に対し、
{ブランド} は、
{カテゴリ} の中で、
{差別化ポイント} により、
{ベネフィット} を提供する
```

### 3. ブランドストーリー

- 起源（なぜ始まったか）
- 旅（どう成長してきたか）
- ビジョン（どこへ向かうか）

### 4. メッセージング

- ヘッドライン
- エレベーターピッチ（30秒）
- 詳細説明（1分）

### 5. ビジュアル

（design-consultant と連携）
- ロゴ
- 配色
- フォント

### 6. ボイス＆トーン

- 書き方の特徴
- 避ける表現
- 顧客への呼びかけ

## ブランドアーキテクチャ

### 単一ブランド
- 全商品が同じブランド
- 例: Apple

### マルチブランド
- 商品ごとに異なるブランド
- 例: P&G

### ブランドファミリー
- マスターブランド + サブブランド
- 例: Toyota + Lexus

## ブランド・パーソナリティ（Aaker）

5 次元:
- Sincerity（誠実）: Down-to-earth
- Excitement（刺激）: Daring, spirited
- Competence（能力）: Reliable, intelligent
- Sophistication（洗練）: Upper class
- Ruggedness（たくましさ）: Outdoorsy, tough

自ブランドがどれに近いか。

## ブランドエクイティ測定

### 認知度
- 純粋想起
- 助成想起

### 連想
- ブランドから想起されるイメージ
- NPS（推奨意向）

### 知覚品質
- 顧客が感じる品質

### ロイヤルティ
- リピート率
- 推奨率

## ブランディングの段階

### Stage 1: 立ち上げ
- ブランド定義
- ビジュアル整備
- メッセージ確立

### Stage 2: 認知拡大
- PR
- コンテンツマーケ
- SNS

### Stage 3: 浸透
- 一貫性維持
- 体験設計
- コミュニティ

### Stage 4: 深化
- ロイヤリティ向上
- アンバサダー育成
- エクイティ強化

## 他エージェント連携

- design-consultant: ビジュアルデザイン
- text-quality-checker: ブランドボイスの一貫性

ブランドガイドラインとして整理。`design-consultant/templates/brand-guideline.template.md` の構造を参考に。
