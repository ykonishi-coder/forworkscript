# マーケティング・フレームワーク集

## 戦略立案

### STP
- Segmentation: 市場細分化
- Targeting: 標的市場選定
- Positioning: 位置づけ

### 4P（マーケティングミックス）
- Product / Price / Place / Promotion

### 4C（顧客視点）
- Customer Value / Cost / Convenience / Communication

### 3C
- Company / Customer / Competitor

### SWOT / クロスSWOT
- 強み・弱み・機会・脅威

## 消費者行動

### AIDA / AIDMA / AISAS
- AIDA: Attention → Interest → Desire → Action
- AIDMA: + Memory（昔のマスマーケ）
- AISAS: + Search, Share（デジタル時代）

### 5A（Philip Kotler）
- Aware → Appeal → Ask → Act → Advocate

### カスタマージャーニー
- 認知 → 検討 → 購入 → 利用 → ロイヤル化

### ダブル・ジェパディーの法則
- 小さなブランドは「買ってくれる人が少なく、買ってくれても頻度が少ない」
- → 認知拡大が最優先

## ファネル

### 一般的な購買ファネル
```
認知 → 興味 → 検討 → 比較 → 購入 → リピート → 推奨
```

### BtoB ファネル
```
Visitor → Lead → MQL → SQL → Opportunity → Customer → Advocate
```

- MQL: Marketing Qualified Lead
- SQL: Sales Qualified Lead

### AARRR（Pirate Metrics）
- Acquisition（獲得）
- Activation（活性化）
- Retention（継続）
- Revenue（収益）
- Referral（紹介）

### HEART フレームワーク（UX）
- Happiness / Engagement / Adoption / Retention / Task success

## 差別化

### USP（Unique Selling Proposition）
独自の売り・価値提案。

### バリュープロポジションキャンバス
- 顧客セグメント
- 価値マップ
- 適合（Fit）

### ブルーオーシャン戦略
- 競合と戦わない市場
- ERRC（Eliminate / Reduce / Raise / Create）

## BtoB マーケティング

### ABM（Account-Based Marketing）
- ターゲット企業を絞って深く
- 1-to-Few / 1-to-One

### The Model（セールスとマーケの連携）
- マーケ → インサイドセールス → フィールドセールス → カスタマーサクセス

### デマンドジェネレーション
- リード獲得 → 育成（ナーチャリング） → 商談化

## 成長戦略

### アンゾフマトリクス
- 既存製品 × 既存市場: 市場浸透
- 既存製品 × 新市場: 市場開拓
- 新製品 × 既存市場: 製品開発
- 新製品 × 新市場: 多角化

### グロースハック
- 指標ドリブン
- 実験・PDCA 高速
- スケーラビリティ

## KPI

### 主要 KPI

#### トラフィック
- UU（Unique Users）
- PV（Page Views）
- セッション数

#### エンゲージメント
- 直帰率
- 平均滞在時間
- ページ/セッション

#### CV
- CVR（Conversion Rate）
- CV 数
- フォーム到達率

#### コスト
- CPC（Cost Per Click）
- CPA（Cost Per Acquisition）
- CAC（Customer Acquisition Cost）
- CPM（Cost Per Mille）

#### 収益
- LTV（Lifetime Value）
- ARPU（Average Revenue Per User）
- ROAS（Return On Ad Spend）
- ROI（Return On Investment）

#### ユニットエコノミクス
- LTV / CAC（理想: 3以上）
- Payback Period（回収期間）

#### BtoB 特有
- MQL → SQL 転換率
- SQL → 商談 転換率
- 商談 → 受注 転換率
- 平均契約額（ACV）
- チャーンレート

## コンテンツ

### コンテンツマトリクス
- 認知段階 × フォーマット
- 検討段階 × フォーマット
- 決定段階 × フォーマット
- ロイヤル段階 × フォーマット

### TOFU / MOFU / BOFU
- Top of Funnel: 認知（ブログ・SNS）
- Middle of Funnel: 検討（ホワイトペーパー・ウェビナー）
- Bottom of Funnel: 購入（ケーススタディ・デモ）

### エデュケーショナル vs エンターテイメント
- BtoB: エデュケーショナル中心
- BtoC: エンタメ比重高め

## 注意点

- フレームワークは 思考の枠組み、機械的に埋めない
- 複数組み合わせる
- 業種・規模で適用が変わる
- 最新の理論・動向もチェック
