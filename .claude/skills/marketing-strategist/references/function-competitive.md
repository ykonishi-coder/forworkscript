# 機能: 競合分析（マーケ視点）

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.marketing-strategist/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


競合企業のマーケ活動を公開情報から分析。

## 調査観点

### 1. 基本情報
- 会社概要
- 主力商品・サービス
- ターゲット
- 価格帯

### 2. ブランディング
- ブランドメッセージ
- トーン＆マナー
- ビジュアル

### 3. 主要チャネル
- Web サイト
- SNS（プラットフォーム別）
- 広告（推定）
- コンテンツマーケ
- PR・メディア掲載

### 4. コンテンツ戦略
- ブログ内容
- 投稿頻度
- トピック
- 人気記事

### 5. SNS 活動
- フォロワー数
- エンゲージメント率（推定）
- 投稿頻度
- コンテンツタイプ

### 6. SEO
- オーガニック流入規模（Ahrefs 等で推定）
- 上位キーワード
- 被リンク

### 7. 広告
- 広告ライブラリ（Meta / LinkedIn）
- 広告コピー
- 推定予算

### 8. 価格・プロモーション
- 標準価格
- キャンペーン実施状況
- 割引傾向

## 情報源

### 公開情報
- 企業公式サイト
- SNS 公式アカウント
- プレスリリース
- 決算資料（上場企業）
- 業界紙

### ツール
- Meta Ads Library（無料）
- Google Ads Transparency Center
- Ahrefs / SEMrush（SEO）
- SOCIAL INSIGHT（SNS）
- SimilarWeb（流入分析）
- Wayback Machine（過去版）

### Web サイト

- 主要流入チャネル: 検索 45% / 直接 30% / SNS 15%

- Meta 広告（Ads Library より）:
  - 配信中の広告: X本

### コンテンツ

- ...

- 競合がカバーしていない領域

- {具体的な戦略}

## やってはいけないこと

- 非公開情報の推測を断定
- 不法なスクレイピング
- 相手の機密情報を盗む
- 誹謗中傷
