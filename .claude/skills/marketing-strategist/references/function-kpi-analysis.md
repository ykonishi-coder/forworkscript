# 機能: KPI 分析・改善提案

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.marketing-strategist/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


GA4・広告管理画面・MA ツールのデータを分析し、改善提案。

## 入力

- GA4 のレポート（コピペ or スクショ読み取り）
- 広告レポート（Google Ads / Meta 等）
- MA の数値
- EC プラットフォームの売上データ

## 観点

### ファネル分析
- 各段階の転換率
- ボトルネック特定
- 改善インパクト試算

### チャネル比較
- チャネル別 CAC
- チャネル別 CV 品質
- ROI 比較

### 時系列分析
- 成長率（前月 / 前年同月）
- 季節性
- トレンド

### セグメント分析
- デバイス別
- 地域別
- 流入経路別
- 新規 vs リピート

### コンバージョン分析
- CVR の推移
- アシストコンバージョン
- 経路分析

### ユニットエコノミクス
- CAC / LTV
- Payback Period
- ROAS

## 出力

```markdown
# KPI 分析レポート

## 期間: YYYY-MM-01 〜 YYYY-MM-DD

## ハイライト
- 流入 +15%（前月比）
- CVR 2.1% → 2.5%
- CAC ¥5,000 → ¥4,500 改善 ✅
- LTV/CAC 3.2 倍（健全）

## ファネル

| 段階 | 数 | 前月比 | 転換率 |
|------|----|--------|-------|
| 流入 | 10,000 UU | +15% | - |
| リード | 500 | +20% | 5% |
| MQL | 200 | +25% | 40% |
| SQL | 50 | +10% | 25% |
| 受注 | 10 | +5% | 20% |

### 改善余地
- SQL → 受注（20%）: 業界平均 30% → インサイドセールス改善検討

## チャネル別

| チャネル | CAC | CVR | 評価 |
|---------|-----|-----|------|
| Google 広告 | ¥4,000 | 3% | ✅ 継続 |
| Meta 広告 | ¥6,000 | 2% | 🟡 改善 |
| SEO | ¥1,000 | 4% | ✅ 伸ばす |
| メール | ¥500 | 8% | ✅ 伸ばす |

### 推奨
- 🔴 Meta 広告の CAC 高すぎ、クリエイティブ A/B テスト
- 🟢 SEO と メール の比率を上げる

## 気になるポイント

### 🔴 要対応
- モバイル CVR が PC の 1/3 → モバイル最適化

### 🟡 要注意
- 直帰率 65% → 業界平均 50%、LP 改善

### 🟢 好調
- リピート率 30%、ブランド浸透

## 改善提案

### 施策A: モバイル LP 改善
- 期待効果: モバイル CVR 1% → 2%、月 50 CV 増
- 実装工数: 2週間
- 優先度: 🔴 高

### 施策B: Meta 広告クリエイティブ刷新
- 期待効果: CAC ¥6,000 → ¥4,500
- 実装工数: 1週間
- 優先度: 🟡 中

### 施策C: SEO コンテンツ拡大
- 期待効果: オーガニック流入 2倍（6ヶ月）
- 実装工数: 継続
- 優先度: 🟢 中

## DA レビュー
（advocate より）
```

## やってはいけないこと

- 数字の創作
- 断定的な予測（「この施策で必ず倍増」）
- 単一指標だけで判断
- 季節性無視
