# 機能: キャンペーン設計

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.marketing-strategist/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


特定の施策・キャンペーンを設計。

## キャンペーンの種類

- 新商品ローンチ
- 季節キャンペーン（セール等）
- リード獲得キャンペーン
- ブランド認知キャンペーン
- リテンション施策
- リファラル施策

## 設計要素

### 1. 目的・KPI
- 目的: 認知 / リード / 売上 / エンゲージメント
- 主要 KPI
- 目標値

### 2. ターゲット
- ペルソナ
- セグメント
- 規模

### 3. オファー
- 特典（割引 / 無料 / 限定 / 体験）
- メッセージ

### 4. チャネル
- 広告
- SNS
- メール
- PR
- コンテンツ

### 5. クリエイティブ
- ビジュアル方向性
- コピー
- CTA

### 6. ランディング
- LP 構成
- フォーム
- サンキューページ

### 7. 実行スケジュール

```markdown
| フェーズ | 期間 | 内容 |
|---------|-----|------|
| 準備 | W-4 〜 W-1 | LP 作成、クリエイティブ制作、広告セットアップ |
| 告知 | W-1 | ティーザー |
| 本番 | W1 〜 W4 | キャンペーン実施 |
| 分析 | W5 | 結果分析・次回改善 |
```

### 8. 予算配分

### 9. リスクと対策
- 予算オーバー
- 想定以下の反応
- 炎上リスク

### 10. 成功基準
- 最低ライン
- 目標
- ストレッチ

`templates/campaign-plan.template.md` 参照。

## DA チェック

- 法令遵守（景表法・特商法）
- 費用対効果の妥当性
- ブランド整合性
- 実行可能性
