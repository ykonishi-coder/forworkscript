# Engineer Assistant（エンジニアリング支援）

ソフトウェア開発を 要件 → 設計 → 実装レビュー → 運用 の各段階で支援。

---

## 🎯 重要な前提

このスキルは実装の全代行ではありません。

- ✅ 向いている: 相談・設計・技術選定・コードレビュー・デバッグ支援
- ❌ 向いていない: 複雑な実装の完全代行（Claude Code 本体で実装）

---

## サポートレベル（段階別）

### レベル1: 基礎 — 🌱 全員おすすめ
- 要件定義支援
- アーキテクチャ案出し
- 技術選定相談
- コード貼り付けレビュー
- デバッグ相談
- テスト戦略

連携不要、文字ベース・コード貼り付けで完結。

### レベル2: 中級
- ローカルプロジェクトファイル読み込み
- 複数ファイルに跨るレビュー
- リファクタリング提案

Claude Code 本体の標準機能 を活用。

### レベル3: 上級 — ⚠️ 上級者向け
- GitHub MCP（PR・Issue 管理）
- CI/CD 監視
- IDE 深連携

セットアップが複雑・最新情報は都度調査。

---

## 🔒 プライバシー

- Claude の学習データに使われません
- ローカル保存のみ
- マスキング機能
- 認証情報の警告（ハードコード検出）

## 提供機能

### 要件定義
ユーザーストーリー・受け入れ基準・非機能要件。

コードの匂い検出・改善案・段階的計画。

README / API Docs / ADR / 運用手順。

OWASP Top 10 観点。

## よくある質問

### Q. Claude Code 本体と何が違う？
Claude Code 本体は「実装実行」中心。このスキルは「相談・設計・レビュー」中心。補完関係。

### Q. プロのエンジニアでも役立つ？
設計相談・DA の批判的レビュー・セカンドオピニオンとして有効。

### Q. 非エンジニアでも使える？
はい。PM やデザイナーが「技術的に可能か」相談するのに使えます。

### Q. セキュリティは本当に大丈夫？
- Claude の学習には使われない
- ハードコード検出で認証情報の誤送信を防ぐ
- OWASP Top 10 観点で自動チェック

### Q. やめたくなったら？
`rm -rf ./.engineer-assistant/`（Windowsは `Remove-Item -Recurse -Force ./.engineer-assistant/`） で完全削除。
