
### 3. 評価軸

- 成熟度: 安定版？ 実績？
- メンテナンス: 活発？ メンテナー数？
- ドキュメント: 充実？ 日本語？
- コミュニティ: 大きい？ Stack Overflow 回答多い？
- パフォーマンス: ベンチマーク
- 学習コスト: チームに合う？
- ライセンス: 商用利用可？
- エコシステム: プラグイン・拡張
- セキュリティ: 脆弱性履歴

### 5. 特定分野の参考

#### バックエンド言語
- Node.js: JavaScript 統一、I/O ヘビー
- Python: AI/ML、スクリプト、読みやすい
- Go: 性能、同時実行、Docker / Kubernetes 等
- Ruby: Rails、スタートアップ向け
- Rust: 高性能、メモリ安全
- Java / Kotlin: 大企業、エンタープライズ
- C# / .NET: Windows エコシステム

#### データベース
- PostgreSQL: 汎用、リレーショナル、機能豊富
- MySQL: シンプル、大量データ
- MongoDB: ドキュメント型、柔軟
- Redis: キャッシュ、セッション
- Elasticsearch: 全文検索、ログ
- DynamoDB: サーバーレス、スケール
- BigQuery: アナリティクス

#### クラウド
- AWS: 最も機能豊富、日本で人気
- GCP: Google エコシステム、AI/ML
- Azure: Microsoft 系、エンタープライズ
- Cloudflare: CDN + Edge
- Vercel / Netlify: 静的サイト

#### CI/CD
- GitHub Actions: GitHub 統合、無料枠
- GitLab CI: GitLab 統合
- CircleCI / Jenkins: カスタマイズ
- ArgoCD: GitOps / Kubernetes

#### コンテナ・オーケストレーション
- Docker: 標準
- Kubernetes: 大規模オーケストレーション
- ECS / Fargate: AWS マネージド
