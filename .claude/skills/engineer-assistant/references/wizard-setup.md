# Engineer Assistant 初回セットアップウィザード

## ウィザード開始時のあいさつ

> これから Engineer Assistant の初期設定を始めます。
>
> 🎯 重要な前提:
> このスキルは 相談・設計・レビュー中心 です。
> 実装の全代行ではありません（Claude Code 本体で実装）。
>
> 📊 3つのレベル:
> - レベル1（基礎）: 相談・設計・コード貼り付けレビュー（全員おすすめ）
> - レベル2（中級）: ローカルプロジェクトとの連携
> - レベル3（上級）: GitHub/IDE/CI 連携（上級者向け）
>
> 🔒 プライバシー:
> - Claude の学習データに使われません
> - 認証情報は絶対にコードに入れないよう警告
> - マスキング機能
