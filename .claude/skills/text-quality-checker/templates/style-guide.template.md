## 基本方針

### 文体
- 基本: `ですます調 / である調 のいずれか`
- 例外: `引用、見出し、箇条書きの一部`

### 敬語レベル
- 基本: `丁寧語中心`
- 顧客向け: `敬語多め`
- 社内向け: `丁寧語のみ`

## 表記ルール

### カタカナ
- 長音: `つける / つけない`
  - 例: 「コンピュータ」か「コンピューター」か
- 複合語の区切り: `中黒 / 半角スペース / 詰めて書く`
  - 例: 「マーケティング・キャンペーン」「マーケティング キャンペーン」「マーケティングキャンペーン」

### 数字
- 全角 / 半角: `基本は半角`
- 3桁区切り: `1,000`
- 単位: `〇〇人、〇〇名のどちらか統一`

### 英字・記号
- 日本語文章中の半角英字は前後に半角スペース: `yes / no`
  - 例: 「AI を活用した」「AIを活用した」
- 記号（！？）: `全角 / 半角`
- 引用符: `「」 or ""`

## 用語統一

頻出語の標準表記:

| 意味 | 標準表記 | 非推奨 |
|------|---------|--------|
| エンドユーザー | お客様 | お客さま、顧客、ユーザー |
| 人工知能 | AI | A.I.、エーアイ、人工知能 |
| ウェブ | Web | WEB、ウェブ、web |
| インターネット | インターネット | ネット、INTERNET |

## 禁則事項

### 使わない言葉
- 差別的表現
- 専門用語の無説明使用
- `{その他、避けたい表現}`

### 使用注意
- 「絶対」「必ず」: 事実誤認リスクがあるため、根拠が明確なときのみ
- 「最大」「最強」「世界一」: ファクトチェック対象
- 「〜だろう」「〜と思われる」: 主観的主張であることを明示

## 敬称ルール

- 社外の方: `〇〇様`
- 社内の方: `〇〇さん`
- 著名人・歴史的人物: `敬称なし（慣例に従う）`

## 数値・データの扱い

- 具体的な数値にはソースを明記
- 「約〇〇」「およそ〇〇」は許容、断定時はソース必須
- パーセンテージ表記: `小数点以下をどこまで `

## 引用ルール

- 引用は `> ` または「」で明示
- 出典を明記（著者名、書籍名/サイト名、ページ/URL）
- 長い引用は許諾を確認

## 見出し・構造

- 見出しレベル: H1 は1つ、H2以下を適切に階層化
- 箇条書きの冒頭: `「・」`「-」「1.」のいずれかで統一
- 段落の長さ: `〇〇文字以内を目安`
