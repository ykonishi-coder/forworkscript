# 原稿チェッカー (Text Quality Checker)

原稿の誤字脱字・文法・ファクトチェック・一貫性を検証するサポーター。

---

## プライバシーについて（最初に）

- 入力した原稿は Claude の学習データには使われません
- 設定は あなたのPC内 に保存されます
- 原稿内容を外部サービスに送信しません（ファクトチェック時の Web 検索を除く）
- Web 検索時も原文をそのまま投げません。固有名詞や数値だけ抽出してクエリ化

---

## できること

### 誤字脱字・文法チェック
- 誤字・脱字・衍字の検出
- 文法ミス（主述不一致、助詞の誤用）
- 敬語の間違い（二重敬語、混在）
- 不自然な言い回し・冗長表現

### ファクトチェック
- Web検索で事実の裏取り
- 複数ソースでの確認
- 信頼性評価とソース提示
- 時期情報の明示

### 一貫性チェック
- 表記ゆれ（「お客様」「お客さま」等）
- 文体の統一（ですます / である）
- 数値・データの整合性
- 論理の矛盾
- 略称と正式名称の混在

## 指摘の優先度

- 🔴 Critical: 必ず修正（明確な誤字、事実誤認）
- 🟡 Warning: 修正推奨（不自然な表現、表記ゆれ）
- 🟢 Info: 任意（スタイル・改善提案）

## よくある質問

### Q. ファクトチェックでうちの業界情報は拾えますか？
Web で公開されている情報の範囲で裏取りします。業界固有の一次資料や有料データベースには直接アクセスできないため、それらの情報は「確認できず」と明示します。信頼できる情報源を設定しておくとより精度が上がります。

### Q. 勝手に書き換えられないか心配
書き換えは 絶対にしません。指摘のみで、修正版は「見せて」と依頼されたときだけ提案として提示します。実際の修正はユーザー判断です。

### Q. 原稿が外部に漏れないか心配
原稿本文は Claude API に送られますが、学習には使われません。ファクトチェック時の Web 検索では、原文をそのまま投げず、固有名詞・数値だけを抽出してクエリ化します。機密度の高い原稿で Web 検索を避けたい場合は、ファクトチェックをスキップできます。

### Q. スタイルガイドを使いたい
`style-guide.md` を編集すれば、組織固有のルール（用語統一、禁則事項）でチェックできます。

### Q. やめたくなったら、どう消せますか？
`rm -rf ./.text-quality-checker/`（Windowsは `Remove-Item -Recurse -Force ./.text-quality-checker/`） で完全に消えます。
