# BizDev フレームワーク集

各フレームワークの使い方・適用タイミング・注意点。

## 市場規模系

### TAM / SAM / SOM

#### 定義
- TAM (Total Addressable Market): 対象業界の全体規模
- SAM (Serviceable Addressable Market): 自社がアクセス可能な市場
- SOM (Serviceable Obtainable Market): 現実的に取りに行ける市場

#### 算出方法

トップダウン方式
- 業界全体 × 対象セグメント割合 × 自社取得見込み

ボトムアップ方式
- 顧客数 × 平均単価 × 頻度

ベストプラクティス: 両方で算出して整合を確認

## 戦略立案系

### SWOT 分析

#### 4要素
- S trengths（強み・内部）
- W eaknesses（弱み・内部）
- O pportunities（機会・外部）
- T hreats（脅威・外部）

#### クロス SWOT（戦略オプション）

| | O | T |
|--|--|--|
| S | SO戦略（積極攻勢） | ST戦略（差別化） |
| W | WO戦略（補強・提携） | WT戦略（撤退・回避） |

### 3C 分析

- Company（自社）
- Customer（顧客）
- Competitor（競合）

### STP

- Segmentation: 市場細分化
- Targeting: 標的市場の選定
- Positioning: 位置づけ決定

#### 位置づけマップ
2軸（例: 価格 × 機能）で競合をプロット、自社の立ち位置を明確化。

## 業界・環境系

### PESTLE 分析

マクロ環境の6要素:
- P olitical（政治）
- E conomic（経済）
- S ocial（社会）
- T echnological（技術）
- L egal（法律）
- E nvironmental（環境）

### ファイブフォース（ポーター）

業界構造の5つの競争要因:

1. 既存競合との競争
2. 新規参入の脅威
3. 代替品の脅威
4. 買い手の交渉力
5. 売り手の交渉力

各要因の「強度」を評価し、業界の収益性を予測。

### バリューチェーン（ポーター）

企業活動を「主活動」と「支援活動」に分解:

#### 主活動
- 購買物流
- 製造
- 出荷物流
- マーケティング・販売
- サービス

#### 支援活動
- 全般管理
- 人事管理
- 技術開発
- 調達

各活動でのコスト・差別化要因を分析。

## 成長戦略系

### アンゾフマトリクス（製品 × 市場）

| | 既存市場 | 新市場 |
|--|--|--|
| 既存製品 | 市場浸透 | 市場開拓 |
| 新製品 | 製品開発 | 多角化 |

多角化は最もリスキー。

### BCG マトリクス（市場成長率 × 市場シェア）

- Star: 高成長・高シェア → 投資
- Cash Cow: 低成長・高シェア → 収穫
- Problem Child: 高成長・低シェア → 選択と集中
- Dog: 低成長・低シェア → 撤退

## 競争戦略系

### ポーターの3つの戦略

- コストリーダーシップ: 規模の経済で低価格
- 差別化: 独自価値で高単価
- 集中戦略: ニッチで深く（コスト集中 or 差別化集中）

### ブルーオーシャン戦略

- 競合と戦わない市場空間
- 価値革新（差別化 + 低コスト同時達成）
- ERRC（Eliminate / Reduce / Raise / Create）

## スタートアップ系

### Lean Startup（リーンスタートアップ）

- Build → Measure → Learn
- MVP（Minimum Viable Product）
- Pivot or Persevere

### Jobs-to-be-Done (JTBD)

顧客は「何を達成したい」のか（機能ではなく結果）で考える。

例: 「ドリルが欲しい」→「穴を開けたい」→「本棚を作りたい」→「整理された部屋に住みたい」

### Problem-Solution Fit / Product-Market Fit

- Problem-Solution Fit: 顧客の問題を解決している
- Product-Market Fit: 市場から十分な需要がある

## 財務・ユニットエコノミクス

### LTV / CAC

- LTV (Lifetime Value): 顧客生涯価値
- CAC (Customer Acquisition Cost): 顧客獲得コスト
- LTV / CAC ≥ 3: 健全
- LTV / CAC < 1: 破綻

### Payback Period（回収期間）

CAC を回収するのに必要な期間。
- 12ヶ月以内: 優秀
- 24ヶ月以内: 許容範囲
- 24ヶ月超: 要改善

### 損益分岐点

```
損益分岐点 = 固定費 / (1 - 変動費率)
```

## 注意点

### フレームワークの罠

- 埋めることが目的化: 意味ある分析に
- 機械的な当てはめ: 個別事情を考慮
- 古い情報で分析: 最新データで
- ポジティブバイアス: 批判的視点を忘れない（advocate の役割）

### 組み合わせて使う

1つのフレームワークで完結しない。複数を組み合わせて総合判断。

例: SWOT で論点 → BMC で構造化 → 財務で検証
