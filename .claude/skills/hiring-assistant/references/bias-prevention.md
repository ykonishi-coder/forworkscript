# バイアス防止ガイド

採用における無意識バイアスを減らすための実践ガイド。`hiring-assistant-advocate` はこのガイドに沿ってチェックする。

## よくあるバイアス

### 確証バイアス
最初の印象に合う情報を集め、反対する情報を軽視する。

例: 「〇〇大学出身 → 優秀に違いない」と思うと、その後の面接で失敗談を見落とす

対策:
- 評価基準ごとに独立して判断
- 否定的情報も書き残す
- 「もし別の大学出身なら同じ評価か？」と自問

### ハロー効果
1つの好印象（容姿・話し方・経歴）で全体を過大評価。

例: 話し方が上手 → 技術力も高いはず

対策:
- 評価項目を独立採点
- 各項目で具体的証拠を求める

### ステレオタイプ
集団属性による一般化。

例:
- 「女性はマネジメントが苦手」
- 「若者は忍耐がない」
- 「〇〇人は勤勉」

対策:
- 個人の具体的な行動・実績で評価
- 「この人なら」ではなく「この発言・行動なら」

### アンカリング
最初に見た候補者を基準に、後の候補者を相対評価。

例: 優秀な A さんの後、普通の B さんが「標準以下」に見える

対策:
- 絶対評価（基準ルーブリック）で採点
- 評価間で一度時間を空ける

### 類似性バイアス
自分と似た背景の人を好む。

例: 同じ大学、同じ趣味、似た経歴 → 高評価

対策:
- 「もし私と違う背景だったら？」と自問
- 多様性は組織の強み、という認識

### 最近性バイアス
直近に面接した候補者を過大評価。

例: 3人中、最後に会った候補が印象に残る

対策:
- 面接直後にFBを書く
- 最後の印象だけで判断しない

### 印象一致バイアス
「こういう人が欲しい」のイメージに合う候補者を過大評価。

例: 「活発な人が欲しい」→ 静かな人の能力を見落とす

対策:
- 業務で本当に必要なのは何か再確認
- 静かだが成果を出す人もいる

## 検出されやすいバイアスの表現

advocate が以下のような表現を検出:

### 属性への言及
- 「若い」「年配」「ベテラン」（年齢）
- 「彼女／彼」の過剰使用（性別）
- 「〇〇出身らしい」（国籍・地域）
- 「家庭持ち」「独身」（家族）
- 「既婚／未婚」（婚姻）

### 主観的・曖昧な評価
- 「なんとなく」
- 「雰囲気が」
- 「好感／違和感」
- 「印象が良い／悪い」

### 一般化
- 「〇〇の人は」
- 「こういうタイプは」
- 「〇〇大学の人らしく」

### ハロー効果の表れ
- 経歴を見た瞬間の「期待できそう」「ダメそう」
- 容姿言及
- 話し方の褒め/貶し

## 客観的な評価表現

代わりに使う表現:

### ❌ → ✅
- 「雰囲気良い」 → 「質問に対して具体例を交えて回答」
- 「印象悪い」 → 「技術的質問で回答に時間がかかった」
- 「コミュ力高い」 → 「チーム内での合意形成の具体例を説明できた」
- 「自信なさそう」 → 「専門外の質問で『分かりません』と言えた（正直さの評価）」

## 構造化面接の効果

バイアス防止の最強の武器は 構造化面接:

- 全候補者に同じコア質問
- 同じ評価基準で採点
- 面接官間で基準を共有

カジュアル面談のような自由形式は、バイアスが入りやすい。

## 多様性の価値

単に「バイアスを避ける」だけでなく、多様性が組織の強み になる:

- 異なる背景 → 異なる視点
- イノベーション
- 顧客理解の幅

ただし、多様性のために能力を妥協するわけではない。能力は評価基準で、多様性は選択の幅を広げる。

## 法的リスクのあるバイアス

日本の労働法で明確に禁止されている差別:

### 男女雇用機会均等法
- 募集・採用で性別を理由に差別してはいけない
- 「女性活躍」目的の配慮は例外的に認められるが、男性排除は不可

### 職業安定法 第5条の4
- 業務に必要な範囲を超える情報収集禁止
- 本籍・家族・思想信条等を聞いてはいけない

### 個人情報保護法
- 要配慮個人情報（病歴・犯罪歴等）の取扱に特別な同意必要

## advocate の役割

`hiring-assistant-advocate` は、このガイドに沿って:

1. 評価・FB・質問リストを自動チェック
2. 問題のある表現を検出
3. Critical / Warning / Info で指摘
4. 代替表現を提案

本体スキルは advocate の指摘に従って、表現を修正または再検討する。

## ユーザー向けのヒント

### 書類選考時
- 匿名化して読む（氏名・写真を見ない）
- 評価基準を先に書き出す
- 全候補者を一度読んでから採点

### 面接時
- 質問リストをそのまま使う
- メモは事実ベース
- 「好印象」だけではFBに書かない

### 採用決定時
- 複数の面接官のFBを比較
- 評価基準に戻って判断
- 違和感があれば立ち止まる

## チェックリスト（ユーザー自己確認）

各候補者の評価後、以下を自問:

- [ ] この評価は、属性ではなく能力に基づくか？
- [ ] 同じ発言を別の属性の人がしても、同じ評価か？
- [ ] 主観ではなく、具体的な発言・行動が根拠か？
- [ ] 「なんとなく」の印象で判断していないか？
- [ ] 他の候補者と同じ基準で評価したか？

advocate のチェックと併せて、このセルフチェックも有効。
