# 採用支援 (Hiring Assistant)

採用業務（書類選考・面接質問作成・面接FB整理・候補者比較）を プライバシー最重視 で支援するエージェント。

---

## 🔒 プライバシーについて（最初に必ずお読みください）

採用業務は個人情報の宝庫です。このスキルは特別な配慮をしています。

### 学習に使われないこと

- 入力した候補者情報は、Anthropic の API 方針により Claude モデルの学習に使われません
- API 経由で処理されたデータは、学習セットに組み込まれずに処理結果だけ返されます

### それでも送信自体が気になる方へ

- マスキング機能: 氏名・住所・電話・メール等を `{候補者A}` 等に自動置換
- 最小情報モード: 評価不要な情報（顔写真・家族構成等）を送信対象から除外
- 手動コピペ推奨: 自動 ATS 連携を使わず、あなたが選んだ情報だけ渡す
- 処理後すぐ破棄: スキル側で履歴書原文を長期保存しない

### なぜ「学習に使わない」が安全か

- 学習に使われると、情報が将来のモデル応答に間接的に現れる可能性がある
- Anthropic はこれを技術的に防ぐ設計
- それでも理論的懸念を消すために、送信情報自体を最小化するのがマスキング

### ローカル保存のみ

- 設定・評価記録はすべてあなたのPC内
- 外部サーバーには一切送信しません
- 選考終了後は自動削除ポリシー設定可能

詳細は `references/privacy-deep-dive.md` をご覧ください。

## できること

### 書類選考
履歴書・職務経歴書を評価基準に沿って評価。強み・懸念・面接で聞きたい質問を抽出。バイアス防止 DA 自動レビュー。

### 面接質問作成
職種・候補者経歴に合わせた構造化面接の質問リスト。STAR法適用。差別的質問は advocate が自動検出。

### 面接フィードバック整理
面接官の生メモを構造化FBに整理。事実と主観を分離。バイアス検出。

### 候補者比較
複数候補の横並び比較。評価基準ベースで公平に。

### オファー判断サポート
総合判断の材料整理。最終決定はユーザー。

### バイアスチェック単独
既存の評価文書に対してバイアス・公平性レビュー。

## ハイブリッド構成

- 本体スキル: 採用支援機能
- 別エージェント `hiring-assistant-advocate`: バイアス・差別・公平性チェック

採用には差別リスクが常にあります。DA が客観的視点から検証し、公平性を守ります。

## セットアップ

```
採用支援セットアップして
```

### 最初に「タイプ」を聞かれます

- A) お試し — 架空候補者でデモ、PCに書き込まない
- B) 最低限（3問）— プライバシー設定重視
- C) しっかり — ATS連携検討まで

### 重要な初期設定

1. マスキングレベル: 最厳重 / 厳重 / 標準（迷ったら最厳重）
2. 評価記録の保持期間: 選考終了後の自動削除
3. 応募者への同意取得状況: 必ず取ってから運用

## 特徴

### プライバシー最重視
- マスキング標準装備
- ローカル保存のみ
- 自動削除ポリシー
- 手動コピペ運用推奨

### バイアス防止
- 別エージェント（DA）が自動チェック
- 差別的質問の検出
- 公平性確保

### 法令遵守支援
- 個人情報保護法
- 男女雇用機会均等法
- 職業安定法 第5条の4
- 最新情報は都度ネット確認

### ATS 連携（慎重に）
- デフォルトは手動コピペ
- 必要な場合のみ、最新の連携方式を調査して提案
- 書き込み権限は最小限

## よくある質問

### Q. 候補者情報が Claude の学習に使われるのが心配
使われません。Anthropic の API は送信データを学習に使わない方針。それでも不安ならマスキング機能を使い、手動コピペで最小情報だけ渡す運用を。

### Q. ATS と連携させたい
技術的には可能ですが、手動コピペを強く推奨 しています。業務効率のためにどうしても必要な場合、セットアップ時に最新の連携方式を調査して提案します。書き込み権限は最小限に。

### Q. 差別的判断をしてしまわないか心配
別エージェント（`hiring-assistant-advocate`）が自動でバイアス・差別をチェックします。検出された場合は修正案を提示。詳細は `references/bias-prevention.md`。

### Q. 法令遵守できる？
スキルは法令遵守を支援 しますが、最終責任はユーザーです。応募者への同意取得、利用目的通知等は必ずお願いします。詳細は `references/legal-compliance.md`。

### Q. 選考終了後のデータ削除
`config.privacy.cleanup.delete_after_days` で自動削除設定可能。手動なら `rm -rf ./.hiring-assistant/`（Windowsは `Remove-Item -Recurse -Force ./.hiring-assistant/`） で完全削除。

### Q. git 事故が怖い
セットアップ時に `.gitignore` への自動追加を提案します。それでも心配なら、リポジトリとは別のフォルダ（`./.hiring-assistant/`）に保存するのが安全。
