# HTML デッキ テンプレート ガイド

`templates/html-deck/` に同梱しているグレースケール基調の HTML スライドテンプレの使い方。

## このテンプレートが何か

- 1920 × 1080 px 固定キャンバスの HTML デッキ
- `<deck-stage>` Web Component で動作（キーボード操作・自動スケール・印刷対応）
- 印刷で 1 スライド 1 ページの PDF が出力できる（`@page` で原寸ページ指定）
- 配色は完全グレースケール基調（特定ブランド非依存）
- 9 種のサンプルスライド: 表紙 / セクション扉 / アジェンダ / 本文 / 3カラム / VS比較 / 数値 / 引用 / クロージング

## ファイル構成

```
templates/html-deck/
├── index.html             # 9種のサンプルスライド
├── colors_and_type.css    # デザイントークン（配色・タイポグラフィ）
├── slides.css             # スライドのレイアウト
└── deck-stage.js          # Web Component（ナビゲーション・印刷）
```

## ロゴをどこに差し替えるか

表紙とクロージングには `.logo-placeholder` `.logo-placeholder-lg` の点線ボックスが入っている。中身を以下いずれかに置き換える。

### 画像で差し替える場合

```html
<!-- 表紙の band 内 -->
<span class="logo-placeholder">
  <img src="path/to/logo.svg" alt="ロゴ" style="height: 48px; width: auto;">
</span>
```

`.logo-placeholder` のクラスは残したままで OK（点線ボーダー・プレースホルダー文字は中身を画像で置き換えると自然に見える）。点線ボーダーが不要なら、クラスを外して直接 `<img>` を置く。

### テキストで差し替える場合

```html
<span class="brand-text" style="font-size: 28px; font-weight: 900; color: var(--primary-0);">ブランド名</span>
```

クロージング（大きめ枠）も同じ要領で `.logo-placeholder-lg` の中身を差し替える。

## アクセントグラデーションを変更したい場合

`colors_and_type.css` の以下 2 行を書き換えるだけで、ヘッダー帯・グラデーションテキスト・数値スライド・クロージングバンドが一括で切り替わる。

```css
:root {
  --accent-start: #1F1F1F;  /* グラデの開始色 */
  --accent-end:   #888888;  /* グラデの終了色 */
}
```

たとえばブランドカラーが青系なら `#1A4A8C` → `#5BA3E0` のように差し替える。`--primary-0` 〜 `--primary-9` を書き換えれば箇条書きの背景・カード枠・チップなども連動する。

## PDF 出力方法

1. ブラウザで `index.html` を開く
2. 画面右上の「PDF」ボタンをクリック（マウスホバーで現れる、控えめなボタン）
3. ブラウザの印刷ダイアログが立ち上がる
4. 送信先で「PDF として保存」を選択
5. 用紙サイズは自動的に 1920×1080 px に設定される（`deck-stage.js` が `@page` を注入）
6. 余白を「なし」、背景グラフィック「あり」を確認して保存

`@media print` で PDF ボタン・ナビゲーションオーバーレイは自動的に非表示になる。

## 配色比率の原則

スライド全体で次の比率を守ると視覚的にまとまる。

| 用途 | 比率 | 例（このテンプレ） |
|------|-----|-------------------|
| ベース | 70% | 白背景 (`#FFFFFF`) と本文テキスト (`--neutral-0`) |
| プライマリ | 25% | チャコール (`--primary-0`) のヘッダー帯・カード強調 |
| アクセント | 5%  | グラデ強調 (`--accent-gradient`) — 数値・タイトル一部だけに |

アクセントは「ここを見てほしい」1 箇所に絞る。多用すると効きが弱まる。

## キャンバスサイズの変更

別比率（4:3、16:10 等）にしたいときは `<deck-stage width="..." height="...">` の値を変える。CSS 内の `1920px` `1080px` も合わせて書き換える必要がある（`slide-w` `slide-h` のCSS変数経由で参照していない箇所が多いため）。

## 禁止事項

- 装飾絵文字を本文中で使わない（`✓` などの記号は意味がある場合のみ）
- 特定の社名・ブランド名・人名をテンプレ本体に固定埋め込みしない（差し替えやすさを保つため）
- `index.html` のサンプル文言（「タイトル」「サブタイトル」「項目サンプル」等）はそのまま納品しない。必ず実コンテンツに置き換える

## キーボード操作

- `←` `PgUp` : 前のスライド
- `→` `PgDn` `Space` : 次のスライド
- `Home` / `End` : 最初 / 最後
- `R` : リセット（最初に戻る）
- `1`〜`9` : 該当スライドへジャンプ（`0` は 10 枚目）
