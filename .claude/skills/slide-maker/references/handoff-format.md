# 工程間引き継ぎフォーマット

## director から各担当への依頼ブリーフ

```markdown
# 依頼ブリーフ

## 宛先
slide-{ROLE}

## 案件
{案件名}

## 担当工程
{構成 / デザイン / ビルド / 品質検証}

## 前工程までの成果物
- work/slide-maker/{案件}/01-director-brief.md
（前工程があれば追加）

## 作業内容
- {具体的な指示}

## 期待アウトプット
- 形式: Markdown / YAML / 実ファイル
- 粒度: {詳細度}

## 制約
- {禁止事項・注意点}

## 納期
{目安}
```

## 各担当から director への完了報告

```markdown
# 完了報告: slide-{ROLE}

## 案件
{案件名}

## 成果物
- パス: work/slide-maker/{案件}/0X-{ROLE}.md

## 要点
1. ...
2. ...
3. ...

## 判断ポイント
- {ユーザー判断が必要な箇所}

## 懸念事項
- {あれば}

## 次工程への申し送り
- {後工程の人が迷わない補足}
```

## 成果物末尾の「申し送り」

```markdown
---
## 次工程への申し送り

### 意図・文脈
- {なぜこう判断したか}

### 使ってほしい素材
- {特に重要な部分}

### 避けてほしいこと
- {この方向には行かないでほしい}
```

## advocate レビュー依頼

```markdown
# レビュー依頼

## 宛先
slide-advocate

## 案件
{案件名}

## レビュー対象
- メイン: work/slide-maker/{案件}/04-builder/final.{形式}
- 参考: 他ファイル

## 重点チェック観点
- {観点1}
- {観点2}

## 厳しさレベル
{standard / strict / lenient}
```

## 修正依頼（指摘反映）

```markdown
# 修正依頼

## 宛先
slide-{ROLE}

## 案件
{案件名}

## 元成果物
work/slide-maker/{案件}/04-builder/final.{形式}

## 修正箇所
### 🔴 Critical
1. {指摘} → {修正指示}

### 🟡 Warning
1. {指摘} → {修正指示}

## 納期
{目安}
```

修正後は元ファイルを `final.{形式}.bak` としてバックアップしてから上書き。
