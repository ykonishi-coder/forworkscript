# スライド作成チーム 初回セットアップウィザード

## ウィザード開始時のあいさつ

> これから スライド作成チーム の初期設定を始めます。
>
> このチームは 5人の専門担当 で構成されています:
> - 🎯 director（全体統括）
> - 📐 composer（ストーリー構成）
> - 🎨 designer（デザイン）
> - 🏗️ builder（実ファイル生成）
> - 🛡️ advocate（品質検証）
>
> 対応形式: Google Slides / Marp / reveal.js / PowerPoint / HTML
>
> 安心事項:
> - スライド・中間成果物はあなたのPC内にのみ保存
> - Claude の学習データには使われません
> - Google Slides 生成時もあなたのアカウント内で完結

## Q0: ユーザータイプ

> Q0. スライド作成チームをどう使っていきたいですか？
>
> A) まず何ができるか試してみたい
> B) 最低限だけ設定して、すぐ使い始めたい
> C) しっかり設定して、自分に合わせて便利に活用したい
> D) まだよく分からない

## A プラン: お試しモード

1. サンプル案件（例: 社内勉強会の10枚スライド）で各担当の動きを見せる
2. 出力形式は Marp のMarkdownを使う（どこでも見られる）
3. 結果をコードブロックで提示、ダウンロードはユーザー操作
4. PCに書き込まない

## B プラン: 最小セットアップ（3問）

### BQ1: 使いたい出力形式

> Q. どの形式でスライドを出力しますか？（複数選択可）
>
> 1) Google Slides（共有・共同編集が楽）
> 2) Marp（Markdownベース・バージョン管理向き）
> 3) PowerPoint (.pptx)（会社標準）
> 4) reveal.js（Web配信・インタラクティブ）
> 5) HTML（カスタム）
> 6) 手動モード（構成・デザイン指示だけ作って、実ファイルは自分で）
>
> 迷ったら 6) 手動モードがおすすめ。必要になったら自動化に切り替えられます。

選択肢ごとに必要なセットアップ:

- 1: GAS Web App の設定が必要（`references/format-guide.md` を見せる）
- 2: Marp CLI のインストール
- 3: Python + python-pptx のインストール
- 4, 5: 特別なセットアップ不要（HTMLテンプレのみ）
- 6: セットアップ不要

### BQ2: 典型的な用途

> Q. よく作るスライドは？（複数選択可）
>
> 1) 提案プレゼン（客先・稟議）
> 2) 社内報告（進捗・振り返り）
> 3) 勉強会・教育資料
> 4) 展示・デモ用
> 5) 経営層向けサマリ
> 6) その他

### BQ3: デザイン傾向

> Q. 好みのデザイン傾向は？
>
> 1) シンプル・クリーン（モノトーン + アクセント1色）
> 2) コーポレート・落ち着き（ネイビー系）
> 3) クリエイティブ・動的
> 4) 学術・資料性重視
> 5) ブランドテンプレートがある（提供予定）
>
> 後から変えられるので、今はざっくりでOK。

## C プラン: フルセットアップ

B プランに加えて:

### Q4: 出力形式の詳細設定（その場で最新調査）

重要: 固定の手順書を読むのではなく、WebSearch で最新情報を確認してから ユーザーに提案する。

#### 調査ステップ

1. 選ばれた出力形式ごとに、以下を WebSearch:
   ```
   {形式} Claude MCP {今年}
   {形式} Anthropic skills {今年}
   {形式} latest version
   slide generation MCP server
   presentation builder MCP
   ```
2. 公式・準公式（Anthropic 公式 Skills リポジトリ等）を優先して WebFetch
3. 新しい MCP の登場、破壊的変更、推奨方法の変化を把握
4. 以下のテンプレートで提示:

```markdown
## {形式} セットアップ方法（YYYY-MM-DD 調査時点）

### 選択肢A: {最新の推奨方式}
- 公式性: {Anthropic公式 / サービス公式 / 非公式}
- セットアップ手順: ...
- リスク: {認証情報・データ経路・破壊的権限の有無}
- AIおすすめ度: ★★★★☆

### 選択肢B: {代替方式}
...

### 選択肢C: 手動モード（ツール不要）
- セットアップ: 不要
- AIおすすめ度: ★★★★★（安心重視）
```

5. 調査日時を `config.integration_research.{形式}.date` に記録
6. 要約を `config.integration_research.{形式}.summary` に記録（30日後の再調査トリガー用）

#### 参考情報（古くなっている可能性あり。実際の判断は上記調査結果優先）

Google Slides の一般的な選択肢:
- GAS Web App 方式（`scripts/google-slides-gas.js` 参照、自分のGoogleアカウント内で完結）
- Google Slides MCP（利用可能なら最短、最新を調査）
- 手動モード

Marp:
- Marp CLI（`npm install -g @marp-team/marp-cli`）
- カスタムテーマCSS

PowerPoint:
- python-pptx
- テンプレート (.pptx) の流用

reveal.js:
- 公式テンプレート（[revealjs.com](https://revealjs.com)）

いずれの方式も、認証情報はスキルの設定ファイルに保存せず、環境変数や OSキーチェーン、GAS プロパティなどで管理する。

## セットアップ完了処理

### 1. 設定ファイル生成

`./.slide-maker/config.yaml` を `templates/config.template.yaml` から生成する（既に存在する場合は内容確認のみ）。あわせて `.gitignore` への `./.slide-maker/` 追加を提案。
※この config.yaml が生成されないと、以後の各モードが「未セットアップ」と判定して起動できない。

### 2. サブエージェント配置確認

> このチームは以下のサブエージェント定義が必要です:
>
> - `.claude/agents/slide-director.md`
> - `.claude/agents/slide-composer.md`
> - `.claude/agents/slide-designer.md`
> - `.claude/agents/slide-builder.md`
> - `.claude/agents/slide-advocate.md`
>
> これらは既に配置されていますか？

### 3. 作業フォルダ

```
work/slide-maker/
```

.gitignore への追加提案。

### 4. GAS Web App セットアップ（Google Slides を選んだ場合）

`scripts/google-slides-gas.js` を自分の Google アカウントにデプロイする手順を案内:

1. GAS プロジェクト作成
2. コードをコピー
3. 許可シートIDを登録
4. Web App としてデプロイ
5. URL を config.yaml に記録
