# 他エージェントとの連携

スライド作成チームは、同じパックの他エージェントと連携して素材・機能を取り込める。連携は毎回ユーザー承認 を取る。

## 連携先

### 秘書（secretary）

取り込む素材:
- メールから決定事項・論点
- 相手とのやり取り背景

活用例:
- 「〇〇社との提案スライド、過去のメールやり取りを踏まえて」
  → secretary から関連メールスレッドの要点を取り込み

### MTGサポーター（meeting-supporter）

取り込む素材:
- 議事録から決定事項・議論ポイント
- To-Do・次回議題

活用例:
- 「〇〇プロジェクトの進捗スライド、過去の定例議事録ベースで」
  → meeting-supporter から関連議事録を取り込み

### スプレッドシート操作（spreadsheet-operator）

取り込む素材:
- 数値データ
- グラフ（ピボット結果）

活用例:
- 「今期のKPIスライド、このシートの数値から」
  → spreadsheet-operator がシートから数値を取得、グラフも生成

### レポート作成（report-writer）

活用例:
- 「先週まとめた調査レポートを基にスライド化して」
  → report-writer の既存レポート（Markdown）をスライド構成に変換
  → compositor が章立てを引き継ぎ、各章をスライドに展開

### 原稿チェッカー（text-quality-checker）

活用例:
- ビルド後の各スライドテキストを送って校正
- 誤字脱字・表記ゆれを検出
- advocate のレビュー前に使うと効率的

## 連携手順

### 1. director が必要性を判断

依頼内容から「連携があった方が良い」と判断:
- 「過去の議論を踏まえて」→ MTG連携
- 「この数値を元に」→ スプシ連携
- 「先週のレポートから」→ report-writer連携

### 2. ユーザー承認

```markdown
このスライド作成で、以下のエージェントを連携させてよろしいですか？

- meeting-supporter: 2026-04-10 〇〇定例の議事録を参照
- spreadsheet-operator: 「KPIシート 2026年」の A1:E20 を読み取り

連携先の保存先（./.meeting-supporter/、./.spreadsheet-operator/）から
必要な情報だけを取り込みます。

承認いただけますか？
```

### 3. 素材取り込み

承認後、composer が素材を受け取って構成に反映。取り込んだ情報は `02-composer.md` 冒頭の「取り込み済み素材」セクションに出典付きで記録。

### 4. 連携しない場合

director がユーザーから直接素材を受け取り、composer に転送。

## プライバシー配慮

### 他スキルの設定ファイル読み取り
- 読むのは 指定されたファイルのみ
- secretary の設定本体（config.yaml）は読まない

### 情報の最小化
- 全メール丸読みせず、関連部分だけ
- 全議事録ではなく、該当日付のファイルのみ

### 機密マーカー
- `[CONFIDENTIAL]` 付きは追加承認必須
- スライドに機密情報を含める場合は、配布前に必ずユーザーチェック

## エラー時の対応

### 連携先が設定されていない
- ユーザーに手動モードへの切り替えを案内:
  > {連携先エージェント} が設定されていません。
  > 今回は手動で素材を貼っていただくか、後日 {エージェント} をセットアップしてから再実行しますか？

### 連携先が動作しない
- 一時フォールバック（手動）
- 後で連携見直し案内

### 権限エラー
- 各エージェント公式の認証フローで対応
- スキル設定ファイルに認証情報を書かせない

## 連携情報の記録

連携を使った案件は、`02-composer.md` に記録:

```markdown
## 取り込み済み素材
- meeting-supporter: 2 議事録参照（2026-04-10, 2026-04-03）
- report-writer: 1 レポート参照（weekly-2026-04-15.md）
- spreadsheet-operator: 1 シート範囲参照（KPIシート A1:E20）

## プライバシー確認
- 機密マーカー付き素材: なし
- 個人情報を含む: なし
```
