# 機能: デザインレビュー

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.design-consultant/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


既存デザインを批判的にレビューする。

## 入力

- レビュー対象（デザイン画像、URL、スクリーンショット）
- 目的（改善提案 / 最終チェック / 第三者視点）
- 対象オーディエンス

## 観点

`references/design-principles.md` と `accessibility.md` の観点で:

### 1. 視覚的階層
- 重要情報が目立つか
- 視線誘導が機能しているか

### 2. 配色
- コントラスト比（WCAG 準拠）
- 色数の適切性
- ブランド整合

### 3. タイポグラフィ
- 読みやすさ
- サイズ階層
- フォント選定

### 4. レイアウト
- 余白
- バランス
- 整合性

### 5. アクセシビリティ
- WCAG AA / AAA 準拠
- 色覚多様性配慮
- キーボード操作（Web）

### 6. ブランド整合
- ブランドガイドライン準拠（あれば）

### 7. 実装性
- 媒体特性
- パフォーマンス

## DA に丸投げ

このレビュー機能は実質 DA（advocate）の仕事。本体は窓口として受け取り、advocate に渡す。

## 出力

`.claude/agents/design-consultant-advocate.md` のフォーマットに準拠。

## 独立利用

ユーザーから直接「このデザインレビュー」と依頼された場合、本体を介さず advocate が直接対応。

## 複数デザイン比較

A 案 vs B 案 の比較:

```markdown
### デザイン比較

| 観点 | 案A | 案B |
|------|-----|-----|
| 視覚的階層 | ✅ | 🟡 |
| 配色 | 🟡 | ✅ |
| タイポグラフィ | ✅ | ✅ |
| アクセシビリティ | ✅ | ❌ |
| ブランド整合 | ✅ | 🟡 |

### 推奨: 案A

理由:
- アクセシビリティ基準を満たす
- ブランドガイドラインに沿っている

### 改善提案（案A）
- 配色の一部調整
```
