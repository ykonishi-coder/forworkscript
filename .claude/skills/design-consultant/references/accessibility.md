# アクセシビリティガイド

すべての人がアクセスできるデザインの基準。

## WCAG（Web Content Accessibility Guidelines）

### レベル
- A: 最低限
- AA: 標準（推奨）
- AAA: 最高

一般的には AA 準拠 が推奨。行政・公共サービスは AAA 目指す。

## 主要基準

### 1. コントラスト比

| 要素 | AA | AAA |
|------|-----|-----|
| 通常文字 (16-17px) | 4.5:1 | 7:1 |
| 大きい文字 (18px+ bold or 24px+) | 3:1 | 4.5:1 |
| UI コンポーネント | 3:1 | - |

#### コントラスト比ツール
- WebAIM Contrast Checker: https://webaim.org/resources/contrastchecker/
- Chrome DevTools 内蔵

### 2. 色だけで情報を伝えない

色覚多様性（色盲・色弱）の方への配慮:

#### NG例
- 「赤字=マイナス、緑字=プラス」だけ
- 信号「赤・黄・緑」だけ

#### OK例
- 赤字＋マイナス記号（−）
- 緑字＋プラス記号（+）
- パターン（ストライプ・ドット）併用

### 3. 文字サイズ

- 本文: 16px 以上（絶対最小）
- 推奨: 18px
- 見出し: 24px 以上

### 4. 代替テキスト (alt)

画像には必ず代替テキスト:

```html
<!-- OK -->
<img src="logo.png" alt="会社ロゴ">
<img src="chart.png" alt="2025年売上推移（前年比+20%）">

<!-- NG -->
<img src="logo.png">
<img src="logo.png" alt="ロゴ">（不十分）
```

装飾画像は `alt=""` で空文字（スクリーンリーダーに読ませない）。

### 5. キーボード操作

- Tab で全要素に到達できる
- Enter / Space で操作
- Esc でモーダル閉じる
- フォーカスが見える（outline / border）

### 6. スクリーンリーダー

- セマンティック HTML（`<button>`, `<nav>`, `<main>`）
- 見出し階層を正しく（H1 → H2 → H3）
- ARIA ラベル（必要な場合）

### 7. フォーム

- ラベルと入力の関連付け（`<label for>`）
- エラーメッセージの明示
- 必須項目の表示（* だけでなくテキストも）

### 8. 動画・音声

- 字幕
- 音声説明
- 自動再生しない

## 色覚多様性シミュレーション

ツールで確認:
- Coblis: https://www.color-blindness.com/coblis-color-blindness-simulator/
- Chrome DevTools

#### タイプ
- P型（1型、Protan）: 赤が見えにくい
- D型（2型、Deutan）: 緑が見えにくい
- T型（3型、Tritan）: 青が見えにくい
- モノクロ: 色がほぼ見えない

## 視力低下への配慮

- 文字サイズ拡大でもレイアウト崩れない
- ズーム 200% でも使える
- 高コントラストモード対応

## 運動機能の制約

- 十分なクリック範囲（44x44px 以上）
- ホバーに依存しない
- 時間制限なし or 延長可能

## 認知の多様性

- 読みやすい言葉
- 専門用語の説明
- エラー時の分かりやすい指示
- 複雑な手順は段階的に

## モバイル配慮

- タッチターゲット: 44x44px 以上
- 十分な間隔
- 横スクロールしない

## チェックリスト

デザイン完成前に:

- [ ] 文字と背景のコントラスト比を確認
- [ ] 色だけで情報を伝えていないか
- [ ] 文字サイズは 16px 以上
- [ ] 画像に alt
- [ ] キーボードで操作できる
- [ ] フォーカスが見える
- [ ] フォームにラベル
- [ ] 動画に字幕

## アクセシブルなデザインの利点

法的義務だけでなく:

- 高齢者 も使いやすい（視力・認知）
- 一時的な障害（骨折・疲労）にも対応
- 多様な環境（屋外で明るい画面・片手操作）
- SEO 向上（構造化されたマークアップ）
- CV 向上（より多くの人が使える）

## やってはいけないこと

- コントラスト不足（白背景に薄いグレー）
- 色だけで OK/NG 表現
- 小さすぎる文字
- フォーカスを `outline: none` で消す
- 自動再生動画・音声
- 時間制限の厳しいフォーム
