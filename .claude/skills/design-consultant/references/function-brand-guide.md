# 機能: ブランドガイドライン作成

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.design-consultant/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


ブランドの一貫性を保つためのガイドラインドキュメントを作成。

## 内容

1. ブランドの核（ミッション・バリュー・パーソナリティ）
2. ロゴ使用規定
3. カラーパレット
4. タイポグラフィ
5. ボイス＆トーン
6. 画像スタイル
7. 使用例・NG例

## テンプレート

`templates/brand-guideline.template.md` 参照。

## 手順

### 1. ブランド核のヒアリング

- ミッション: 何を実現するか
- バリュー: 大切にする価値
- パーソナリティ: ブランドを人に例えると

### 2. 各要素の規定

#### ロゴ使用
- バリエーション（横型・縦型・アイコンのみ）
- 最小サイズ
- 余白（セーフゾーン）
- 背景色別の使用（濃い背景は白抜き 等）
- NG 使用例（変形・色変え・他ロゴと並べない等）

#### カラー
- プライマリ / セカンダリ / アクセント / ニュートラル
- HEX / RGB / CMYK / Pantone
- 使用用途・比率
- アクセシビリティ

#### タイポグラフィ
- 見出し用フォント
- 本文用フォント
- 代替フォント（Web フォント使えない場合）
- サイズ階層

#### ボイス＆トーン
- 書き方の例（OK / NG）
- 顧客への呼びかけ（「お客様」「〇〇さん」等）
- 避ける表現

#### 画像スタイル
- 写真 / イラスト の使い分け
- 撮影・イラストのトーン
- 参考例

### 3. 使用例ページ

各メディアでの具体例:
- Web サイト
- SNS 投稿
- 名刺
- プレゼン資料
- メール署名

### 4. 保存・配布

```
{保存先}/brand-guidelines/{ブランド名}-v1.md
```

バージョン管理で更新履歴を残す。

## 簡易版と完全版

### 簡易版（A4 5-10ページ）
- 小規模組織・スタートアップ向け
- 必須要素のみ

### 完全版（A4 30-50ページ）
- 大企業・広範囲利用向け
- すべての使用シーンをカバー
