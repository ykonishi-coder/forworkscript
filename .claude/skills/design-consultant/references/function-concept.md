# 機能: コンセプト案出し

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.design-consultant/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


デザインの 方向性 を複数案提示する。

## 入力

1. 用途（Web / ロゴ / バナー / 資料 等）
2. 目的（何を達成したいか）
3. ターゲット
4. ブランド情報（あれば）
5. 制約（予算・納期・禁則）

## 手順

### 1. ブリーフ確認

```markdown
コンセプト案出しを始めます。以下を教えてください:

- 用途: {例: LP}
- 目的: {例: SaaS の無料トライアル申込}
- ターゲット: {例: 中小企業の経営者・情シス}
- ブランド情報: {ある/ない}
- 好きな / 嫌いな方向性: {参考になる例・NG例}

不明な点があっても、こちらで推測して複数方向性を出します。
```

### 2. 3〜5 案の方向性

### 案1: コーポレート・信頼
- トーン: 堅実・信頼感・プロフェッショナル
- 配色: ネイビー + グレー + アクセントブルー
- フォント: Noto Sans JP Bold（見出し）/ Noto Sans JP（本文）
- レイアウト: グリッドベース・整然・余白広め
- イメージ: 企業ビル・握手・スーツ
- 向いている場合: 経営層向け・BtoB・金融・法務

### 案2: モダン・クリーン
- トーン: 洗練・ミニマル・先進的
- 配色: ホワイト + ブラック + アクセント1色（鮮やか）
- フォント: Inter（英）/ 游ゴシック（日）
- レイアウト: 非対称・大きな余白・タイポ主導
- イメージ: 抽象的・幾何学的・プロダクト中心
- 向いている場合: テック系・スタートアップ・デザイン意識高め

### 案3: 親しみやすい・温かい
- トーン: 柔らかい・親近感・人間味
- 配色: ベージュ + ウォームトーン + アクセント（暖色）
- フォント: 明朝系・手書き風
- レイアウト: 丸み・余裕・有機的
- イメージ: イラスト・人物・自然
- 向いている場合: BtoC・ライフスタイル・子育て・健康

### 案4: エッジ・クリエイティブ（実験的）
- トーン: 大胆・独創的・印象強い
- 配色: 高彩度・補色対比
- フォント: ディスプレイフォント・実験的組版
- レイアウト: 破壊的・重なり・動的
- イメージ: アート的・抽象的・グラフィカル
- 向いている場合: クリエイター向け・ブランド立ち上げ・差別化重視

### 案5: 学術・資料性（情報重視）
- トーン: 真面目・情報密度高・読み物
- 配色: 抑えめ・モノトーン寄り
- フォント: セリフ・明朝
- レイアウト: テキスト中心・箇条書き・表
- イメージ: 図解・グラフ・チャート
- 向いている場合: 論文的資料・報告書・学術系サイト

### 3. 各案の詳細

案ごとに以下を詳細化:

```markdown
## 案X: {コンセプト名}

### キーワード
- {3〜5 の形容詞}

### 配色
- プライマリ: #XXXXXX（ネイビー）
- セカンダリ: #XXXXXX（グレー）
- アクセント: #XXXXXX（ブルー）
- ニュートラル: #FFFFFF, #F9FAFB

### タイポグラフィ
- 見出し: {フォント名} Bold
- 本文: {フォント名} Regular
- キャプション: {フォント名} Italic

### レイアウト方針
- グリッド: 12カラム
- 余白: 大きめ（20% 以上）
- 配置: {対称 / 非対称}

### ビジュアル方針
- 画像: {写真 / イラスト / 抽象}
- トーン: {高彩度 / 彩度低め / モノトーン}
- スタイル: {リアリズム / フラット / 手描き}

### 参考イメージ（検索推奨）
- 「{キーワード} デザイン」
- 「{業界} {スタイル}」

### 向いているケース
- ...

### 向いていないケース
- ...
```

### 4. 推奨

ユーザーのブリーフから、AI として最適と思う案を推奨:

```markdown
## AI 推奨: 案2（モダン・クリーン）

理由:
1. ターゲット（中小企業経営者）が「洗練された SaaS」を期待する傾向
2. 競合（A社・B社）とは差別化したい
3. スタートアップらしいスピード感・新しさを訴求

ただし:
- 案1（コーポレート） も、保守的なターゲットなら有効
- 案3（親しみ） は、親しみやすさで差別化するなら

最終選択はあなたに委ねます。どれにしますか？
```

### 5. 絞り込み後の深掘り

選ばれた案を深掘り:

- 具体的なフォント推奨
- 詳細な配色パレット
- レイアウトバリエーション
- 参考サイト・参考デザイン

### 6. advocate チェック

選ばれた方向性について、DA にレビュー依頼:
- ブランド整合性
- アクセシビリティ
- 実現可能性

## ブランドガイドラインがある場合

ブランドカラー・フォントが決まっている場合:
- ブランドガイドライン内で 解釈のバリエーション を提案
- 「同じブランドでも、こういう表現の幅がある」を示す

## 他エージェント連携

### 画像生成AI（レベル2）
選ばれた方向性を元に、image-prompt-generator でイメージ画像を生成するためのプロンプトを作成。

### デザインツール（レベル3）
選ばれた方向性で、実際のデザイン制作に進む（ユーザーが実施 or 連携があれば一部自動）。

## やってはいけないこと

- 1案だけ出して押し付ける（必ず複数案）
- 抽象的すぎる提案（具体的な色コード・フォント名を）
- ユーザーの意図を無視（ブリーフを読む）
- 著作権リスクのあるスタイル模倣（特定ブランドを真似する等）

## 完了メッセージ

```markdown
## コンセプト案出し完了

5つの方向性を提案しました:
- 案1: コーポレート・信頼
- 案2: モダン・クリーン
- 案3: 親しみやすい・温かい
- 案4: エッジ・クリエイティブ
- 案5: 学術・資料性

### AI 推奨: 案2

### 次のステップ
- どの案で進めるか選んでください
- 複数案を組み合わせることも可能
- 選んだ案を深掘りします（配色詳細・レイアウト等）

⚖️ 最終判断は、あなた or プロのデザイナーとご相談ください。
```
