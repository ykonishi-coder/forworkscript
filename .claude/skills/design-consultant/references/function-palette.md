# 機能: 配色パレット提案

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.design-consultant/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


デザインに合うカラーパレットを提案する。

## 入力

1. 用途・コンセプト
2. ブランドカラー（あれば）
3. 好み（明るい / 落ち着いた / 鮮やか 等）
4. 業界・ターゲット

## 手順

### 1. コンセプトから方向性

コンセプトに合う色系統:

- コーポレート: ネイビー + グレー + ブルー
- モダン: モノトーン + アクセント1色
- ナチュラル: ベージュ + アース系
- ラグジュアリー: 黒 + ゴールド or 深いブルー
- フレンドリー: パステル・暖色
- エネルギッシュ: ビビッド・原色
- 学術: 抑えめ・寒色・モノトーン

### 2. パレット構成

5色構成:

```markdown
### パレット案1: {名称}

- プライマリ（メイン・ブランド色）: #XXXXXX
- セカンダリ（サブ）: #XXXXXX
- アクセント（強調・CTA）: #XXXXXX
- ニュートラル（背景・区切り）: #FFFFFF, #F9FAFB
- テキスト（本文）: #1F2937
```

### 3. 用途別の色コード指定

各色について:

```markdown
#### プライマリ: ネイビーブルー

- HEX: #1E40AF
- RGB: rgb(30, 64, 175)
- HSL: hsl(221, 71%, 40%)
- CMYK: cmyk(83%, 63%, 0%, 31%)

使用シーン:
- ロゴ
- 見出し
- 重要な UI 要素

避ける:
- 本文テキスト（コントラスト不足の可能性）
- 大きな背景色（重すぎる）

補完色:
- 明るい版: #3B82F6
- 暗い版: #1E3A8A
```

### 5. アクセシビリティチェック

各組み合わせのコントラスト比を計算:

```markdown
### コントラスト比チェック

| 前景 | 背景 | 比率 | WCAG |
|------|-----|------|------|
| #1F2937 | #FFFFFF | 13.65:1 | ✅ AAA |
| #1E40AF | #FFFFFF | 8.59:1 | ✅ AAA |
| #6B7280 | #FFFFFF | 4.43:1 | ⚠️ AA Large のみ |
| #3B82F6 | #FFFFFF | 4.24:1 | ⚠️ AA Large のみ |

### WCAG 基準
- AAA 通常文字: 7:1 以上
- AA 通常文字: 4.5:1 以上
- AA 大きい文字: 3:1 以上
```

### 6. 色覚多様性配慮

色覚異常（色盲）の方への配慮:

```markdown
### 色覚多様性チェック

P型・D型色覚（赤緑色弱）で見たとき:
- 赤色 と 緑色 の区別が困難
- 重要な情報は色だけでなく形・ラベルでも区別

具体的チェック:
- 「赤＝悪い、緑＝良い」→ 形（×と○）も併用
- 信号機の色 → 位置で判別
- グラフ → 色＋パターン
```

### 7. 用途別の適用例

```markdown
### Web サイトでの使用例

- ヘッダ: ニュートラル（白 or 薄グレー）
- ナビゲーション: プライマリ
- CTA ボタン: アクセント
- リンク: プライマリ or アクセント
- フッター: ニュートラル（暗いグレー）
- 警告: 赤系（別途）
- 成功: 緑系（別途）
```

### 8. advocate チェック

DA に確認:
- アクセシビリティ
- ブランド整合
- 文化的配慮

### 9. 提案と決定

```markdown
## 配色パレット提案完了

5案提示しました。AI 推奨は 案1（コーポレート・ネイビー） です。

### 理由
- ターゲット（BtoB 経営者）に信頼感
- WCAG AA を全組み合わせで満たす
- 既存業界トップ企業との差別化も可能

### 決定後
- デザインガイドラインに記録
- パレット情報をファイル保存

⚖️ 最終判断はあなた or プロのデザイナーとご相談ください。
```

## 色彩理論の基礎知識

### 色相環
- 補色（反対側）: 強いコントラスト
- 類似色（隣接）: 調和
- トライアド（120°離れた3色）: バランス

### 色の意味
- 赤: 情熱・危険・緊急
- 青: 信頼・冷静・プロフェッショナル
- 緑: 自然・健康・成長
- 黄: 注意・明るさ・幸福
- 紫: 高貴・創造性・神秘
- 黒: 高級・フォーマル・強さ
- 白: 清潔・シンプル・余白

### 文化的差異
- 白: 日本では喪、西洋では純粋
- 赤: 中国では祝い、欧米では危険

## やってはいけないこと

- コントラスト不足の提案（WCAG 違反）
- 色だけで情報を区別する設計
- 文化的に不適切な色の使用
- 著作権のある色の組み合わせ模倣（競合のブランドカラーそのまま等）
