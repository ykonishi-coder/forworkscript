# デザインツール連携（レベル3）

⚠️ レベル3 は上級機能。まずレベル1で基礎をマスターしてから検討を。

## 大原則

1. レベル1 で効果が出てから レベル3 を検討
2. 都度ネット調査 で最新の連携方式を確認
3. 手動運用が最も安心（連携なしでも案出しは可能）
4. 認証情報はスキルに保存しない

## 主要デザインツール別

### Canva

特徴:
- ブラウザベース・初心者でも使いやすい
- テンプレート豊富
- 日本語対応

サポート方式:

#### レベル1: 相談相手
- 「Canva でこう作ると良い」のアドバイス
- テンプレート選定の相談
- 連携なし

#### レベル2: 画像生成AI 活用
- Canva に貼り付けるアイコン・画像を、image-prompt-generator で生成

#### レベル3: Canva Connect API / MCP
- 要件: Canva Pro アカウント、Developer アクセス
- 都度調査: Canva MCP 最新状況
- できること: デザインの自動生成・編集
- リスク: API レート制限、ライセンス規定

### Adobe Creative Cloud（上級者向け・実験的）

ツール:
- Photoshop
- Illustrator
- InDesign
- Premiere Pro / After Effects

サポート方式:

#### レベル1
- 操作方法の相談
- デザイン原則の適用アドバイス

#### レベル2
- Photoshop に配置する画像を画像生成AIで
- Illustrator の参考用にビジュアル生成

#### レベル3: Adobe Creative SDK
- 要件: Adobe Developer アカウント、各アプリの SDK
- できること: 限定的（アプリごとに違う）

#### レベル4: コンピュータ操作経由（上級者・実験的）
- Claude の Computer Use 系やブラウザ連携を使って、Photoshop / Illustrator のネイティブ操作を自動化できる可能性が出てきている
- 技術的な接続自体より、「自分が普段手でやっている作業を、AI に伝わる粒度で 言語化・手順化・テンプレート化 できているか」 が本当の難所
- 言い換えると、AI を使う以前の「自分の仕事のデータ化」がどこまで進んでいるかで難易度が決まる。漠然とした「Photoshop を自動化したい」では動かない
- 日常的に Adobe を使っている上級者で、自動化したい作業を手順書レベルで書き起こせる人と、段階的に一緒に整えていく方針
- 依頼時は「自動化したい作業を手順で説明できる」状態を前提にする

### Figma（MCP あり・導入しやすい・特にワイヤーフレーム自動化がおすすめ）

特徴:
- ブラウザ / デスクトップアプリ
- リアルタイム協業
- UI / UX デザインの定番
- 公式・非公式の MCP が存在しており、Claude Code から接続するハードルが低い

サポート方式:

#### レベル1
- Figma での構成相談
- コンポーネント設計のアドバイス

#### レベル2
- Figma に配置する画像を画像生成AIで

#### レベル3: Figma MCP 連携（おすすめ）
- 接続自体は MCP 経由で比較的素直
- 特に効くのが「ワイヤーフレーム → Figma 上のフレーム生成」や「既存ファイルの読み取り・整理」
- 要件: Figma API トークン（Enterprise は要制限確認）
- できること: デザインデータの読み取り・一部書き込み
- 都度調査: Figma MCP 最新状況・推奨パッケージ
- 鍵は 「自動化したい作業を、手順レベルで言語化できているか」。ここを整えてから接続に進むと効果が出やすい

### Sketch

- Mac 限定
- Figma に押されてシェア低下中
- サポート: レベル1 中心

### InVision, Principle, Framer 等

- ツールごとに状況が違う
- 都度調査

## 連携しないメリット

「連携なし（レベル1）」でも、できることは多い:

- コンセプト提案
- 配色・フォント選定
- ワイヤーフレーム（Markdown）
- ムードボード（参考キーワード）
- デザインレビュー
- ブランドガイドライン作成

これだけで、デザイナー or ユーザーの実制作を大いに加速 します。

## セキュリティ上の注意

### 認証情報
- API キー・OAuth トークンを `config.yaml` に書かない
- OS キーチェーン / 環境変数で管理

### 書き込み権限
- 読み取りで済む操作なら書き込み権限不要
- 書き込みが必要でも、毎回ユーザー承認

### データの扱い
- デザインデータをローカルに長期保存しない
- 処理後に破棄

## レベル3 導入のチェックリスト

以下をすべて満たせる方のみ推奨:

- [ ] デザインツールの基本操作を熟知
- [ ] 業務で毎日デザイン制作している
- [ ] MCP / API のセットアップに慣れている
- [ ] セキュリティリスクを理解
- [ ] 認証情報の適切な管理ができる
- [ ] 連携設定が上手くいかないとき、自分でトラブルシュートできる

チェックが少ない場合、レベル1 または 2 から始める ことを強くおすすめします。
