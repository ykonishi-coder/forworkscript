# 機能: ワイヤーフレーム

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.design-consultant/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


画面構成・レイアウト案を Markdown + ASCII で表現。

## 入力

- 画面の用途
- 必要な要素
- 画面サイズ（PC / タブレット / スマホ）

## 出力フォーマット

### 例: LP（ランディングページ）


### レイアウトの説明

```markdown
## 各セクションの意図

### Hero セクション
- 目的: 訪問者に「何のサイトか」を 3秒で伝える
- 要素: メインビジュアル、ヘッドコピー、CTAボタン
- コピー例: 「〇〇で△△を実現」

### 3つの特徴
- 目的: 主要なバリュープロポジション
- 要素: アイコン + 見出し + 短い説明
- 並列表示で比較しやすく

### お客様の声
- 目的: 社会的証明・信頼感
- 要素: 顔写真 + 肩書き + 声
- 3-5件

### 料金プラン
- 目的: 購入検討材料
- 要素: プラン名 + 価格 + 機能比較
- 「おすすめ」プランを目立たせる

### クロージング CTA
- 目的: 最後の申込促進
- 要素: インパクトあるボタン
```
