# Design Consultant 初回セットアップウィザード

## ウィザード開始時のあいさつ

> これから Design Consultant（デザインコンサル）の初期設定を始めます。
>
> 🎯 大切なお知らせ:
> このスキルは 案出し・下書きメイン です。
> 高品質な完成デザインは、プロのデザイナーやデザインツールで作ります。
> このスキルは、その 前段階の思考整理・アイデア出し を支援します。
>
> 📊 3つのサポートレベル:
> - レベル1（基礎）: 案出し・下書き・配色・フォント・WF（全員おすすめ）
> - レベル2（中級）: 画像生成AI連携（イメージ画像を生成）
> - レベル3（上級）: Canva / Adobe / Figma 連携（難易度高）
>
> 段階が大事: まずレベル1で効果を実感してから、必要に応じてレベルアップを。
>
> 🔒 プライバシー:
> - Claude の学習データに使われません
> - ローカル保存のみ

## Q0: ユーザータイプ

> Q0. Design Consultant をどう使っていきたいですか？
>
> A) まず何ができるか試してみたい
> B) 最低限だけ設定して、すぐ使い始めたい
> C) しっかり設定して、自分に合わせて便利に活用したい
> D) まだよく分からない

## A プラン: お試しモード

1. サンプル3種:
   - 1) Web サイトのデザインブリーフ整理
   - 2) カフェのロゴコンセプト案出し
   - 3) プレゼン資料のカラーパレット
2. デモ実行
3. 続けるか確認

PC に書き込まない。

## B プラン: 最小セットアップ（3問）

### BQ1: 主な用途

> Q. 主にどんなデザインを扱いますか？（複数可）
>
> 1) Web サイト / LP
> 2) ロゴ・ブランディング
> 3) SNS 投稿・バナー
> 4) プレゼン・ドキュメント
> 5) 印刷物（パンフ・チラシ・名刺）
> 6) UI / UX（アプリ・サービス）
> 7) パッケージ
> 8) その他

### BQ2: デザインの経験レベル

> Q. デザインの経験・知識は？
>
> 1) 初心者（デザインの基本を学びたい）
> 2) 中級（自分で作ることもあるがプロではない）
> 3) プロ・デザイナー（仕事で毎日デザインする）
> 4) 発注者（自分は作らないが、デザインを依頼する立場）
>
> これで提案のスタイル・専門用語の使い方が変わります。

### BQ3: サポートレベル（最重要）

> Q. どのサポートレベルから始めますか？
>
> レベル1（基礎・案出し）: 🌱 おすすめ・全員
> - 文字ベースで完結、連携なし
> - 配色・フォント・WF の提案
>
> レベル2（画像生成AI連携）: 🎨 中級
> - image-prompt-generator と連携
> - Midjourney / SD / DALL-E のプロンプト作成
>
> レベル3（デザインツール連携）: 🔧 上級
> - Canva / Adobe / Figma 連携
> - セットアップが複雑、認証が必要
> - ⚠️ 初心者はまずレベル1から
>
> 迷ったら レベル1 から。後からレベルアップ可能。

### 完了後の案内

> セットアップ完了です。
>
> 使い方:
> - 「デザインブリーフ整理」で要件構造化
> - 「{用途}のコンセプト案出し」で方向性複数提案
> - 「配色提案」でカラーパレット
> - 「フォント選定」
> - 「ワイヤーフレーム作って」
> - 「デザインレビュー」で既存デザインチェック

## C プラン: フルセットアップ

B プランに加えて:

### Q4: ブランド情報

ブランドガイドラインがある場合は登録:
- ブランド名
- プライマリカラー
- セカンダリカラー
- 指定フォント
- ロゴの使用規則
- トーン＆マナー

これで提案時にブランド整合性がチェックされます。

### Q5: デザインツール（レベル2/3の場合）

レベル2 の場合:
- 使っている画像生成AI（Midjourney / SD / DALL-E / FLUX 等）

レベル3 の場合:
- 使っているデザインツール（Canva / Adobe / Figma / Sketch 等）
- その場でネット検索 で最新の連携方式を確認:

```
Canva MCP Claude {今年}
Adobe Creative SDK
Figma API MCP
デザインツール Anthropic
```

提案フォーマット:
```markdown
## {ツール名} 連携の調査結果（YYYY-MM-DD）

### 選択肢A: {MCP 名}
- 公式性: ...
- リスク: ...
- セットアップ難易度: 上級
- AIおすすめ度: ★★★☆☆

### 選択肢B: API 直接
- ...

### 選択肢C: 手動運用（推奨）
- AIおすすめ度: ★★★★★
- Claude が生成した指示をあなたが手で実行
```

### Q6: アクセシビリティ要件

> Q. アクセシビリティ対応は？
>
> 1) WCAG AA 準拠（一般的・推奨）
> 2) WCAG AAA 準拠（高度、行政・公共サービス等）
> 3) 内部向け資料（参考程度）

### Q7: 対象オーディエンス

プロフェッショナル向け / 一般消費者向け / 子ども向け / 高齢者向け 等。

### Q8: 他エージェント連携

- image-prompt-generator: 画像生成プロンプト作成
- slide-maker: スライドデザインへの流用
- text-quality-checker: デザイン内テキストの校正

## レベル3 について特に注意

レベル3 を選んだ場合、以下を確認:

> ⚠️ レベル3 は上級機能です。以下を確認してください:
>
> - [ ] デザインツール（Canva / Adobe / Figma）の基本操作ができる
> - [ ] 業務で頻繁にデザイン制作する
> - [ ] MCP / API のセットアップ（認証等）に対応できる
> - [ ] 連携のセキュリティリスクを理解している
>
> すべてチェックできない場合は、レベル1 または 2 を強く推奨します。

>
> 1) サンプルプロジェクトでレベル1を体験
> 2) 実際の案件を投入
> 3) セットアップだけで終える

### 5. 段階的レベルアップの提案

> 段階的に活用 するのがおすすめ:
>
> 1. まず レベル1 で 数プロジェクトこなす
> 2. 「もっと視覚的に見たい」と感じたら レベル2（画像生成AI）
> 3. 業務量が増えたら レベル3（ツール連携）
>
> いきなりレベル3 は挫折しやすい。まず基礎をマスターしてから。
