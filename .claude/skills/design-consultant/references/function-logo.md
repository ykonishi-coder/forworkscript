# 機能: ロゴコンセプト案出し

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.design-consultant/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


ロゴデザインの 方向性提案（実制作ではない）。

## 手順

### 1. ヒアリング

- ブランド名
- 事業内容
- ターゲット
- トーン（フォーマル / カジュアル / テック / クラシック 等）
- 既存の制約（色・フォント等）

### 2. ロゴタイプ

#### ロゴの種類
- ワードマーク (Wordmark): 文字のみ（例: Google、Coca-Cola）
- レタマーク (Lettermark): 頭文字のみ（例: IBM、CNN）
- シンボル (Symbol): 記号のみ（例: Apple、Nike）
- 組み合わせ (Combination): 文字＋記号（最も一般的）
- エンブレム (Emblem): バッジ型（例: Starbucks）

コンセプトに応じて、どの種類が合うか提案。

### 3. コンセプト案（3-5案）

```markdown
## ロゴコンセプト案

### 案1: {コンセプト名}

#### 種類
- 組み合わせマーク（ワードマーク + シンボル）

#### 意図・ストーリー
- {ブランドの価値を視覚化する意図}
- {モチーフの由来}

#### モチーフ
- 主要モチーフ: {例: 幾何学形状}
- 象徴: {何を表すか}

#### スタイル
- {フラット / 立体 / 手描き風 / etc}

#### タイポグラフィ
- フォント提案: {フォント名}

#### カラー
- プライマリ: #XXXXXX
- セカンダリ: #XXXXXX

#### バリエーション
- 横組み / 縦組み
- モノクロ版
- 最小サイズ

#### 参考の方向性
- 「{業界} モダン ロゴ」で検索するとイメージが掴みやすい
- 近いスタイルのブランド例: {例}（模倣ではなく、方向性の参考）

### 案2: ...
```

### 4. 画像生成プロンプト（レベル2）

レベル2 以上なら、image-prompt-generator 連携:

```markdown
### ロゴイメージ生成プロンプト

#### Midjourney 向け
```
minimalist logo design for {業種}, geometric shapes, clean typography, navy blue color, vector style, white background --v 6
```

注意: 画像生成AIのロゴは 参考用。実装は Figma / Illustrator 等で。
```

### 5. 実制作への誘導

```markdown
### 次のステップ

ロゴの方向性が決まったら、以下の方法で実制作を:

1. プロのデザイナーに依頼 （高品質推奨）
2. Canva / Figma で自分で制作（中級）
3. ロゴ生成サービス: Looka / Tailor Brands 等（初級）

注意:
- 商標登録する場合、既存商標との競合確認
- 業種によっては弁理士相談を
```

### 6. 商標チェックの注意喚起

```markdown
### ⚠️ 商標リスク

ロゴを作る前・使う前に:

- [ ] J-PlatPat（特許庁）で既存商標検索
  - https://www.j-platpat.inpit.go.jp/
- [ ] 同業界で類似ロゴがないか
- [ ] 商標登録する場合は弁理士・商標事務所相談

本スキルでは商標判断はできません。法的リスクは必ず専門家に。
```

## やってはいけないこと

- 既存ロゴの模倣・パクリ提案
- 商標登録済みのロゴに類似する提案を断定的に推奨
- 実制作したロゴ画像を「完成品」と扱う（あくまで参考イメージ）
- 法的リスクを見逃す

## DA チェック

- [ ] 他社ロゴとの類似性
- [ ] ブランド意図との整合
- [ ] 実装可能性（小さくても認識可能か）
- [ ] バリエーション展開（モノクロ版等）
- [ ] 長期使用に耐えるシンプルさ
