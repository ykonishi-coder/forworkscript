# ツール連携 調査フレームワーク

MTGサポーターと連携できる主な外部ツール:

- 文字起こしツール（Otter.ai、Zoom、Teams、Whisper等）
- タスク管理ツール（Linear、Notion、Todoist等）
- カレンダー（秘書エージェント経由で連携可能）

## 大原則

1. 連携は強制ではない — テキスト貼り付けだけで全機能が動く
2. 毎回その場で調査 — WebSearch/WebFetch で最新の連携方法を確認
3. リスクを隠さない — 認証情報の保管、外部送信の有無を明示
4. 認証情報はスキルに保存しない — OSキーチェーン等で管理

## 文字起こし連携

### 候補パターン

#### A) MCP 経由（対応ツールがあれば推奨）
- 調査クエリ例: `Otter.ai MCP Claude {今年}` `transcription MCP Anthropic`
- 自動取り込み可能
- AIおすすめ度: ★★★★☆（公式があれば）

#### B) API 直接連携
- Otter.ai API、Whisper API 等
- OAuth or APIキー管理が必要
- AIおすすめ度: ★★★☆☆

#### C) エクスポート→貼り付け（最も一般的）
- ツールから .txt / .vtt / .srt 等でエクスポートしてClaudeに渡す
- AIおすすめ度: ★★★★★（安心・シンプル）

#### D) ローカル録音→Whisperで自前文字起こし
- プライバシー最優先の場合
- Whisper.cpp 等のローカル実行
- AIおすすめ度: ★★★★☆（技術慣れ必要）

### 提案テンプレート

```markdown
## 文字起こし連携の選択肢（YYYY-MM-DD 時点）

### A: {MCP名}
- できること: 自動取り込み
- リスク: {認証情報}、{データ経路}
- AIおすすめ度: ★★★★☆

### B: エクスポート→貼り付け
- できること: 手動で持ち込み
- リスク: 最小（選んだ会議だけ Claude に渡る）
- AIおすすめ度: ★★★★★
```

## タスク管理ツール連携（To-Do機能拡張）

### 候補

#### A) Linear / Notion / Todoist の API or MCP
- 最新情報を都度調査
- 書き込み権限が必要な場合、誤操作リスクに注意

#### B) CSV / Markdown エクスポート
- タスク管理ツールから定期的にエクスポート
- MTGサポーターが読み取って集計

#### C) 連携なし
- MTGサポーター内でローカル追跡のみ
- AIおすすめ度: ★★★★★（安心）

### 重要な制約

書き込み系の操作は慎重に:
- タスク作成は ドラフトを作って見せる → ユーザー承認後にAPI実行
- 一括登録は必ずプレビュー → 承認フロー
- 自動削除・自動完了は 絶対にしない

## カレンダー連携（秘書経由）

MTGサポーターは単体でもカレンダーから会議情報を取得できるが、秘書エージェントの `schedule-check` 機能を利用するのが効率的。

- 秘書が設定済みなら: 「次の会議の議事録テンプレ用意して」で連動可能
- 秘書未設定なら: ユーザーに会議情報を手動入力依頼

## 連携情報の鮮度管理

```yaml
integration_research:
  transcription:
    date: "YYYY-MM-DD"
    summary: "..."
  task_management:
    date: "YYYY-MM-DD"
    summary: "..."
```

30日経過で再調査を提案。

## トラブルシュート

### 文字起こしの品質が低い
- 録音環境の確認をユーザーに案内
- 別ツール（Whisper 等）の提案
- 一時的に手動でメモを貼ってもらう

### 認証エラー
- OAuth トークン期限切れの可能性
- 公式再認証フローへ案内
- 認証情報をスキル設定ファイルに保存しない

### API レート制限
- 一時停止を案内
- 次の実行時間を提示

## まとめ

- 連携は 強制ではない。貼り付けだけで動く
- 都度ネット調査で最新情報
- 書き込み系操作は プレビュー→承認フロー が必須
- プライバシー重視なら手動モードで始めるのがおすすめ
