# 機能: 過去議事録検索

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.meeting-supporter/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


## 目的

ユーザーの曖昧な記憶（「いつの会議だっけ」「〇〇の話いつしたっけ」）から、該当する議事録を特定し、該当箇所を提示する。

## 入力

以下のいずれか（複数組み合わせ可）:

- キーワード: 議題・発言・プロジェクト名
- 日付範囲: 「今月」「先月」「3月の第2週」等
- 参加者: 「〇〇さんと話した会議」
- 会議タイプ: 「定例」「1on1」「提案会議」

不明な場合は1往復で聞く:

> 何を探したいですか？以下のどれかが分かると絞り込みやすいです:
> - キーワード（プロジェクト名・話題）
> - だいたいの時期（先週・先月・3月頃など）
> - 参加していた人
> - 会議の種類

## 手順

### 1. 検索対象の確定

`config.search.scope` に従って議事録フォルダをスキャン:

- `new_only`: `{config.output_dir}/` 配下の、MTGサポーター生成分のみ
- `all`: 設定された追加フォルダも含む

### 2. 検索実行

#### キーワード検索
- Grep で該当行を抽出
- 同義語・表記ゆれも考慮（例: 「MTG」「会議」「ミーティング」）

#### 日付範囲
- ファイル名の日付（`YYYY-MM-DD-*.md`）で絞り込み
- 「先月」「今月」等の相対表現を解決

#### 参加者
- 議事録冒頭の「参加者」欄を照合

### 3. 結果の提示

#### 単一ヒットの場合

```markdown
## 該当議事録

2026-04-15 定例ミーティング

### 該当箇所
> 〇〇プロジェクトの件、田中さんから進捗共有。
> 来月末までに△△を完了予定とのこと。

### その他の要点
- 決定: 〇〇は継続、△△は見送り
- To-Do: 田中さんが来週までに報告書提出

ファイル: {パス}
```

#### 複数ヒット

```markdown
## 該当する議事録が3件見つかりました

### 候補1: 2026-04-15 定例ミーティング（直近・最も関連）
- 該当箇所: 「〇〇プロジェクトの進捗」
- 要点: ...

### 候補2: 2026-04-01 定例ミーティング
- 該当箇所: 「〇〇プロジェクトの開始」
- 要点: ...

### 候補3: 2026-03-18 キックオフ会議
- 該当箇所: 「〇〇プロジェクトの立ち上げ」
- 要点: ...

どれの詳細を見ますか？（番号で教えてください）
```

#### ヒットなし

```markdown
該当する議事録は見つかりませんでした。

以下の可能性を確認していただけますか:
- 議事録がまだ作成されていない
- 検索対象フォルダに入っていない
- キーワードが異なる（同義語・略語）

検索条件を変えて再度試しますか？
```

### 4. 発言の引用ルール

該当箇所を引用するとき:

- 原文改変なし: 議事録に書かれていることをそのまま抜粋
- 文脈補足: 引用前後の議論を1〜2文添える
- 出典明記: 「{議事録ファイル名} の {セクション}」

## 関連情報の提示

検索結果に関連する情報があれば添える:

- その議題に関連する 未完了 To-Do
- その議題が 複数回議論されている 場合、時系列
- その議題の 決定事項の変遷

例:

```markdown
## 関連情報

### 未完了 To-Do
- 田中さん: 〇〇の追加調査（期限未定）

### 議論の変遷
- 2026-03-18: 方針として決定
- 2026-04-01: 進捗共有
- 2026-04-15: 課題発覚、リスケ検討

次回の議論が必要な状態です。
```

## やってはいけないこと

- 議事録の創作・補完: 見つからないのに「こう書かれていたはず」と創作しない
- 機密会議のアクセス権なし検索: `[CONFIDENTIAL]` マーカー付き議事録は、明示的な許可なく検索結果に含めない
- 他ユーザーの議事録: 共有フォルダに他者の議事録がある場合、無許可アクセス禁止

## プライバシー配慮

- 検索結果を外部に送信しない
- 引用範囲は最小限に
- 機密マーカー付き議事録は別扱い
- 長期保存された議事録でも、プライバシーポリシーは作成時と同じ基準で扱う
