# MTGサポーター (Meeting Supporter)

会議の議事録作成・To-Do追跡・過去議事録検索を自動化するMTGサポーター。

---

## プライバシーについて（最初に）

- 議事録・設定は あなたのPC内 にのみ保存されます
- 入力した情報は Claude の学習データには使われません
- 機密度の高い会議内容を扱うため、特に配慮しています
- 外部送信・共有は一切しません（Slack等への自動投稿もしません）

---

## できること

### 議事録生成
録音文字起こしやメモを渡すと、構造化議事録（決定事項・To-Do・次回議題）を自動生成。

### To-Do追跡
過去の議事録から未完了のアクションアイテムを集計。担当者別・期限別に整理。リマインド下書きも作成（送信はしません）。

### 過去議事録検索
「いつ〇〇の話したっけ」の曖昧な記憶から該当議事録を特定。関連する決定事項や To-Do も横断して表示。

---

## セットアップ

```
MTGサポーターセットアップして
```

### 最初に「タイプ」を聞かれます

- A) お試し（質問ゼロ・約3分・ファイル作らない）
- B) 最低限（3問・約5分・迷ったらこれ）
- C) しっかり（全問・約10分）

## よくある質問

### Q. 会議内容が Claude に送られることに抵抗がある
手動モード（テキスト貼り付け）で使うと、あなたが選んだ会議内容だけが Claude に渡ります。自動連携なしで全機能が動きます。

### Q. 機密会議の議事録はどう扱われる？
- 議事録に `[CONFIDENTIAL]` マーカーを入れると、検索時に許可なくアクセスされない挙動になります
- 設定で `confidential_handling: separate` にすると、別フォルダに隔離保存されます

### Q. 勝手にリマインド送信されない？
送信機能は 物理的に持っていません。下書き作成までで必ず止まります。

### Q. やめたくなったら、どう消せますか？
`rm -rf {保存先}`（Windowsは `Remove-Item -Recurse -Force {保存先}`） で設定・議事録フォルダを削除すれば完全に消えます。
