# Meeting Supporter

会議の議事録を自動で作り、To-Doを抽出し、過去議事録から情報を探せるMTGサポーター。

## 安心してください（プライバシーについて）

- 入力した情報は Claude の学習データには使われません
- 議事録や設定はあなたのPC内に保存されます
- 機密度の高い会議内容を扱うため、特にプライバシー配慮を重視 しています
- 外部送信や共有は一切しません。保存先はあなた指定のローカルフォルダのみ

## 提供する3機能

| 機能 | 入力 | 出力 |
|------|------|------|
| 議事録生成 | 録音文字起こし or 手書きメモ | 構造化議事録（決定・To-Do・次回議題） |
| To-Do追跡 | 生成済み議事録 | 未完了To-Doリスト・担当者別一覧 |
| 過去議事録検索 | 検索クエリ（キーワード・日付・参加者） | 該当議事録の抜粋・要約 |

## 設定の読み込み（setup以外の全モードで最初に必ず実行）

setup 以外のどのモードでも、処理を始める前に必ず設定ファイルを読み込む。
これをしないと setup ウィザードで作成した設定（保存先・連携方式・各種オプション）が
一切反映されず、setup の結果が使われないまま動作してしまう。

1. `./.meeting-supporter/config.yaml` を Read する
2. 見つからない場合 → 「まだセットアップされていません」と伝え、setup モードへ誘導して中断する
3. 読み込めた場合 → 内容を記憶し、以降の手順や `references/function-*.md` 内で参照する
   `config.xxx` は、この config.yaml の値を指すものとして扱う
4. config 内に他スキルの参照パス（peer_agents 等）がある場合も、ユーザー承認を取ってから読む。
   勝手に他スキルの config.yaml は読まない

## 動作モード

| モード | トリガー | 動作 |
|--------|---------|------|
| setup | 「セットアップして」等、または設定ファイル不在 | Q0から始まるウィザード |
| generate | 「議事録作って」「会議まとめて」等 | 議事録生成 |
| todo-check | 「To-Do確認」「宿題残り」等 | To-Do追跡 |
| search | 「過去議事録で〇〇」「いつ話したっけ」等 | 過去議事録検索 |

### モード判定手順

1. 「セットアップ」「初回」等 → setup
2. 会議メモ・録音文字起こしが貼られている、または「議事録作って」等 → generate
3. 「To-Do」「宿題」「残り」「未完了」等 → todo-check
4. 「過去」「以前」「いつ」「どの会議」等 → search
5. 不明 → ユーザーに「①議事録作成 ②To-Do確認 ③過去議事録検索、どれですか？」と1回だけ確認

## 各モードの処理

### setup モード

`references/wizard-setup.md` に完全に従う。Q0（タイプ選択） から始め、A/B/C/D で分岐。

### generate モード

`references/function-generate.md` を参照。要点:

1. 入力を読み込む（録音文字起こし / メモ / 構造化データ）
2. 参加者・日時・議題を抽出
3. 決定事項・議論点・To-Do を構造化
4. 次回議題の候補を抽出
5. `{保存先}/meetings/YYYY-MM-DD-{タイトル}.md` に保存
6. ユーザーに要点とリンクを返す

### todo-check モード

`references/function-todo.md` を参照。要点:

1. 過去の議事録から未完了To-Doを集計
2. 担当者別・期限別に整理
3. リマインド候補を提示（ユーザー承認でメール下書きへ渡す）

### search モード

`references/function-search.md` を参照。要点:

1. 検索クエリから該当議事録を特定（日付範囲、参加者、キーワード）
2. 該当箇所を抜粋
3. 複数ヒット時は要約付きリストを返す

## 連携ツール（表示系のみ・入力取り込みが主）

- 録音文字起こし: Otter.ai / Zoomの文字起こし / Whisper API等 → テキスト貼り付けで対応
- カレンダー: 予定から会議情報を引いてくる（秘書エージェントと連携可）
- ファイル: ローカルの録音ファイル、.docx、.txt

連携は都度ネット調査（詳細は `references/tool-integrations.md`）。最小構成は「テキスト貼り付けのみ」で動く。

## 絶対にやらないこと

- 議事録の外部送信・共有（Slack等への自動投稿もしない）
- 議事録原文の外部保存
- 参加者への自動通知（ドラフトまで）
- 機密会議の要約を無承諾で他エージェントに渡す
