# 機能: 通知配信

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.academic-scout/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


研究開発の発見・定期監視結果を関係者に通知。

research-assistant の function-notify.md と同じ原則・仕組み。

## 原則（再掲）

1. 下書き→承認→送信 がデフォルト
2. 自動送信は自分宛のみ
3. 送信前プレビュー必須
4. 認証情報は環境変数

## 通知内容の種類

### 日次アラート（自分宛）
- 監視対象の新着論文
- 上位 N 本の要約

### 週次サマリ（チーム内、承認制）
- その週の重要論文
- 主要トピック

### 月次レポート（経営層向け、承認制）
- 分野動向
- 示唆

### 緊急通知
- 重大論文発表
- 撤回論文

## 内容別の通知先例

```markdown
### 自分宛（自動 OK）
- 日次 arXiv ダイジェスト → 自分の Slack DM
- 週次論文要約 → 自分のメール

### チーム宛（承認制）
- 週次研究動向 → チーム Slack
- 月次 R&D レポート → 関係者メール

### 経営層向け（承認必須）
- 戦略的示唆を含む四半期レポート
```

## ツール

- メール / Slack / Teams / Discord / Chatwork / LINE Messaging API

詳細は `references/tool-integrations.md`（research-assistant と共通の仕組み）。

## やってはいけないこと

- 論文全文の無断配布
- 著作権侵害
- ユーザー承認なしの他者送信
- スパム的な大量配信

## 著作権配慮

- 引用は短く・出典明記
- 要約は OK（自分の言葉で）
- 原文のコピペは NG
