# 機能: 論文検索

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.academic-scout/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


特定トピックで論文を探す。

## 手順

### 1. 検索条件の明確化

- トピック・キーワード
- 期間（最新のみ / 過去5年 / 全期間）
- 分野
- 論文タイプ（実験 / サーベイ / 理論）

### 2. 複数 DB で並列検索

- Google Scholar (汎用)
- Semantic Scholar (AI 支援検索、API あり)
- arXiv (プレプリント、分野特化)
- PubMed (医学・生命)
- J-STAGE (日本語論文)
- DBLP (CS)

### 3. 検索クエリ設計

効果的:
```
"large language model" safety evaluation
"LLM" "alignment" 2024
transformer efficiency "attention"
```

英語推奨: 英語論文が圧倒的に多い

演算子:
- `AND` / `OR` / `NOT`
- 引用符で完全一致
- `-` で除外

### 4. 初回スクリーニング

検索結果から候補を絞る:
- タイトル
- アブスト
- 著者・所属
- 被引用数
- 年

### 5. 詳細確認

候補論文の詳細:
- Abstract を読む
- DOI で実在確認
- 全文アクセス確認

### 6. 要約作成

`function-summarize-paper.md` に従い要約。

### 7. DA チェック

- 実在確認（ハルシネーション防止）
- 信頼性評価
- 方法論チェック

### 8. 提示

```markdown
## 論文検索結果: {トピック}

### 🌟 最重要（3-5本）

#### 1. {論文タイトル}
- 著者: {著者}
- 掲載: {誌名 / 会議}, YYYY
- 被引用: {数}
- DOI: {DOI}
- 要約: {3行}
- なぜ重要: {理由}
- リンク: ...

#### 2. ...

### 📚 関連論文（5-10本）

（簡潔に）

### 🔍 サーベイ論文（あれば）

分野俯瞰に役立つ。

### 推奨読書順
1. {論文名}
2. ...

### 情報源
- Google Scholar: 検索日 YYYY-MM-DD
- arXiv: 検索日 YYYY-MM-DD
- Semantic Scholar: 検索日 YYYY-MM-DD

⚖️ 全論文の実在は AI として確認しましたが、重要な引用は原典確認 をお願いします。
```

## ハルシネーション防止

- すべての引用論文の DOI 確認
- Google Scholar で存在確認
- 不確実な場合は「要確認」と明示

## やってはいけないこと

- 存在しない論文の創作
- 著者名の創作
- DOI の創作
- 引用数の創作
