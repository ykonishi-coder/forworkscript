# 機能: R&D レポート作成

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.academic-scout/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


研究動向・技術調査をレポート化。

## レポートの種類

### 技術動向サーベイ
特定技術分野の全体像。

### 競合 R&D 分析
競合企業の研究活動。

### 特許分析
特定分野の特許出願傾向。

### サーベイ（Meta-analysis）
複数論文を横断した分析。

### R&D 定期レポート
月次・四半期の研究動向。

## 構造

`templates/rnd-report.template.md` 参照。

```markdown
# R&D レポート: {テーマ}

## エグゼクティブサマリ
- 主要発見
- 示唆

## 1. 調査範囲・方法
- 対象分野
- 情報源
- 期間

## 2. 主要論文・研究
（重要論文 5-10本の要約）

## 3. 技術動向
- 急成長トピック
- 衰退トピック
- 新しいアプローチ

## 4. 主要プレイヤー
- 大学・研究機関
- 企業（R&D ラボ）
- 注目研究者

## 5. 特許動向（該当時）
- 出願数推移
- 主要出願者

## 6. カンファレンス・学会動向
- 主要発表
- ホットトピック

## 7. 実務的示唆
- ビジネス応用
- 技術選択の指針
- 次のアクション

## 8. 付録
- 論文リスト
- 参考文献
```

## 他エージェント連携

- report-writer: 正式なレポート化
- slide-maker: 経営層向けプレゼン
- text-quality-checker: 校正
