# 論文評価ガイド

論文の信頼性・重要度を評価する観点。

## 評価の 5 軸

### 1. 信頼性

#### 査読
- 査読付き: 信頼度高
- プレプリント: 未査読、注意
- 会議録: 分野により査読レベル差

#### 掲載誌の評価
- インパクトファクター
- 分野での評判
- 撤回論文の履歴

#### 方法論
- 統計的妥当性
- サンプルサイズ
- 対照群
- バイアス対策

### 2. 再現性

- コードが公開されているか
- データが公開されているか
- 他グループが再現したか
- Papers with Code にあるか

### 3. 重要度

- 被引用数
- 掲載誌・カンファレンスの格
- 後続研究への影響
- 分野を変える発見か

### 4. 新規性

- 既存研究からの進歩
- 本質的な新しさ vs 漸進的改良
- 新しい問題設定

### 5. 利害相反（COI）

- 資金源
- 著者所属
- 結果の恣意性

## 論文を読むコツ

### 3パス読み（Keshav）

#### 1st Pass (5-10分)
- Title, Abstract, Introduction, Conclusion のみ
- Figures を眺める
- 自分に関連あるか判断

#### 2nd Pass (30分-1時間)
- 全体を読み、要点把握
- 理解できない部分はスキップ
- 引用論文を要チェック

#### 3rd Pass (数時間)
- 徹底的に読む
- 再現を試みる
- 批判的に検討

### 読む順序

1. Abstract
2. Conclusion
3. Figures（図表）
4. Introduction（文脈把握）
5. Related Work（位置づけ）
6. Methodology（詳細手法）
7. Experiments（結果）
8. Discussion（限界・示唆）

## 要約の書き方

### ELEV（Essential, Limitations, Evaluation, Value）

- Essential: 要点 2-3 行
- Limitations: 限界
- Evaluation: AI としての評価
- Value: なぜ重要

### サンプル

```markdown
## Paper: {タイトル}

### Essential
- {何を提案 / 何を発見}
- {どう評価 / 結果}

### Limitations
- サンプル n=50
- 特定条件下のみ

### Evaluation
- 手法: 妥当（ただし対照群弱い）
- 結果: 統計的有意だが効果量小
- 再現性: コード公開、追試待ち

### Value
- 新しい問題設定を提示
- 今後のベースラインになる可能性
```

## ハルシネーション対策

AI（含む Claude）は 存在しない論文を引用 することがある:

### 対策
- 論文タイトル + 著者で Google Scholar 検索
- DOI 確認（`https://doi.org/{doi}` でアクセス）
- arXiv ID 確認
- PubMed ID 確認

### よくあるハルシネーション
- 実在の著者 + 架空の論文
- 実在の論文 + 架空の年
- 一部正しい + 一部創作

### このスキル使用時の注意
- advocate に実在確認させる
- 重要な引用は必ず原典確認
- 「{論文タイトル}」を直接検索

## 撤回論文のチェック

### Retraction Watch
- https://retractionwatch.com/
- 撤回論文の監視

### 論文 DB で確認
- PubMed: 「Retracted」ラベル
- 各 DB の撤回告知

撤回論文を知らずに引用するリスクあり。

## 倫理

- 盗用（Plagiarism）は絶対に NG
- 引用ルール厳守
- 出典なしの改変は禁止
- ハゲタカジャーナル（低品質・有料掲載）への注意
