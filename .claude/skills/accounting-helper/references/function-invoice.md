# 機能: 請求書作成支援

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.accounting-helper/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


インボイス制度に対応した請求書を作成する。

## 入力

- 請求先情報
- 請求内容（品目・数量・単価）
- 発行日・支払期限

## 手順

### 1. ユーザー情報の確認

セットアップで登録済みの情報を使用:
- 発行者名称（会社名・個人名）
- 登録番号（T+13桁、インボイス対応の場合）
- 住所
- 振込先
- 連絡先

### 2. 請求書の構成

`templates/invoice.template.md` の形式で作成:

```markdown
# 請求書 No. {連番}

発行日: YYYY-MM-DD

### 請求先
{請求先名称}
{請求先住所}

### 発行者
{自社名}
{自社住所}
登録番号: T{13桁}（適格請求書発行事業者）

---

### 請求金額合計: ¥{税込合計}

### 明細

| 品目 | 数量 | 単価 | 税率 | 金額 |
|------|-----|------|------|-----|
| {品目1} | {数量} | {単価} | 10% | {金額} |
| {品目2} | {数量} | {単価} | 8% (軽減) | {金額} |

### 税率別の集計

| 税率 | 本体 | 消費税 | 合計 |
|------|-----|-------|-----|
| 10% | 100,000 | 10,000 | 110,000 |
| 8% (軽減) | 50,000 | 4,000 | 54,000 |
| 合計 | 150,000 | 14,000 | 164,000 |

### 振込先
{銀行名} {支店名}
{口座種別} {口座番号}
口座名義: {名義}

### 支払期限
YYYY-MM-DD

### 備考
{あれば}
```

### 3. インボイス要件チェック

`accounting-helper-advocate` にチェック依頼:

- [ ] 登録番号（T+13桁）
- [ ] 取引年月日
- [ ] 取引内容（軽減税率対象はその旨）
- [ ] 税率ごとに区分した合計額
- [ ] 税率ごとの消費税額
- [ ] 受領者の氏名・名称

### 4. 源泉徴収の計算（必要な場合）

個人事業主で源泉徴収対象の業種の場合:

```markdown
### 源泉徴収込みの内訳

請求額（税抜）: 100,000円
消費税: 10,000円
請求金額合計: 110,000円

源泉徴収税（10.21%）: 10,210円

### 振込予定額: ¥99,790
※ 源泉徴収税は支払者（先方）が納付
```

### 5. ファイル保存・出力

```
{保存先}/invoices/{YYYY-MM}/{請求書番号}.md
```

Markdown のまま、または Word / PDF に変換（ユーザーが別途）。

### 6. 売掛金の登録

請求書発行後、売掛金として記録:

```markdown
### 売掛金登録

- 請求先: {マスキング}
- 金額: 164,000円
- 請求日: YYYY-MM-DD
- 入金予定: YYYY-MM-DD
- ステータス: 請求済
```

`function-payment.md` の入金管理と連動。

## インボイス対応の重要ポイント

### 登録番号の確認方法
- 国税庁の「適格請求書発行事業者公表サイト」で検索
- https://www.invoice-kohyo.nta.go.jp/

### 免税事業者の場合
- 登録番号なし
- インボイス発行不可
- 取引先の消費税計算に影響
- 経過措置: 2029年9月まで段階的に仕入税額控除可能

### 経過措置の確認
- 2023年10月〜2026年9月: 80% 控除
- 2026年10月〜2029年9月: 50% 控除
- 2029年10月以降: 控除不可

## やってはいけないこと

- 登録番号の創作（虚偽のインボイスは違法）
- 消費税額の計算ミス（端数処理は事業者選択）
- 請求先情報の誤り

## 完了メッセージ

```markdown
## 請求書作成完了

請求書番号: INV-2026-0001
請求先: {マスキング or 請求先名}
金額: ¥164,000（税込）

### インボイス要件
✅ 登録番号記載
✅ 税率別集計
✅ 必要項目すべて

### 保存先
{パス}/invoices/2026-04/INV-2026-0001.md

### 次のステップ
1. Word / PDF に変換（手動）
2. 請求先に送付
3. 売掛金として登録（完了）
4. 入金予定日に支払確認

⚖️ 請求書の法的有効性・税務上の扱いは税理士にご確認を。
```
