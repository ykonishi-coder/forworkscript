# 会計ソフト別サポートガイド

各会計ソフトで、Claude Code がどうサポートできるか。連携方式は都度ネット検索で最新確認 が原則。

## 大原則

1. 都度最新調査: MCP / API は頻繁に状況が変わる
2. 手動コピペでも全機能動作: 連携なしでも支援可能
3. 書き込みは毎回ユーザー承認: 会計データの直接変更は最も慎重に
4. 認証情報をスキルに保存しない

## 調査プロセス

### Step 1: WebSearch

```
freee MCP Claude {今年}
マネーフォワード API MCP
弥生会計 API {今年}
勘定奉行 API OBC
PCA API
会計ソフト Anthropic MCP
```

### Step 2: 公式優先で WebFetch

- Anthropic 公式: `github.com/anthropics/skills`
- 各会計ソフト公式ドキュメント
- 公式 API リファレンス

### Step 3: リスク評価

- 認証方式（OAuth / API キー）
- 権限スコープ（読み取り / 書き込み）
- 書き込み権限は最小限に
- データ経路
- 会計ソフト側のログ・監査機能

### Step 4: 提案

```markdown

- AIおすすめ度: ★★★★☆

- 最も安心
```

## 【参考】主要会計ソフト別の一般情報

以下は 2026年前半時点での一般的な情報。実際の選定時は上記の調査プロセスで最新確認。

## freee 会計

### 特徴
- クラウド型、UI が直感的
- 中小企業・個人事業主に人気
- 自動仕訳機能あり
- 銀行・クレカ連携強い

### サポート方式

#### レベル1: 相談相手
- freee の操作方法を Claude に相談
- 「この取引、freee でどう入力？」
- 連携なしで十分機能

#### レベル2: CSV 連携
- freee から CSV エクスポート（レポート類）
- Claude がデータを分析
- 逆方向は、仕訳CSVを作って freee にインポート

#### レベル3: API / MCP（都度調査）
- freee 公式 API: https://developer.freee.co.jp/
- OAuth 認証
- 読み取り: `read` スコープ
- 書き込み: `write` スコープ（慎重に）
- 2026年時点でMCP対応があるか は都度調査

### 特有の機能活用
- freee の自動仕訳候補を Claude が精査
- freee の月次レポートを Claude が分析
- freee のタグ機能を活用

## マネーフォワード クラウド会計

### 特徴
- クラウド型
- 中堅・中小企業、会計事務所に人気
- 仕訳辞書・自動連携強い
- 給与・人事と統合的

### サポート方式

#### レベル1: 相談相手
- MFクラウド会計の操作相談
- 仕訳科目の選択相談

#### レベル2: CSV 連携
- MF から仕訳帳・試算表を CSV エクスポート
- 分析・チェック

#### レベル3: API / MCP（都度調査）
- MF API: https://biz.moneyforward.com/accounting/developer
- 認証・権限スコープは公式確認
- MCP の有無を都度調査

## 弥生会計

### 特徴
- 日本で最も歴史あるソフトの一つ
- デスクトップ版（弥生会計）とクラウド版（弥生会計オンライン）
- 税理士事務所で広く使われる
- 年間契約モデル

### サポート方式

#### レベル1: 相談相手
- 弥生会計の操作相談
- デスクトップ版は手動コピペ中心

#### レベル2: CSV 連携
- 弥生から仕訳データエクスポート
- 独自形式に注意

#### レベル3: API / MCP（クラウド版のみ）
- 弥生 API: クラウド版のみ
- デスクトップ版は直接連携困難
- 弥生IDからの連携を調査

## 勘定奉行（OBC）

### 特徴
- 中堅・大企業向け ERP
- オンプレ版 / クラウド版
- 他の奉行シリーズとの統合（人事・販売等）

### サポート方式

#### レベル1: 相談相手
- 勘定奉行の操作相談
- 仕訳入力のヒント

#### レベル2: CSV 連携
- 勘定奉行クラウドから CSV エクスポート
- 分析・チェック

#### レベル3: API / MCP
- 勘定奉行クラウド API（あれば）
- オンプレ版は API 少ない
- OBC MCP の有無は都度調査

## PCA 会計

### 特徴
- 中堅企業向け
- デスクトップ / クラウド両対応
- 業種別ソリューション

### サポート方式
- レベル1/2 が中心
- API は PCA Cloud のみ

## freee / MF 以外の中小クラウド

- 会計王
- ソリマチ
- 他のクラウド会計

基本的に CSV 連携 or 手動で対応。

## Excel / Google Sheets で管理

### よくある運用
- 個人事業主・スタートアップ
- 仕訳帳・試算表を Excel で管理

### サポート方式
- spreadsheet-operator と連携して数値操作
- Excel / Sheets からのデータ読み取り・整形
- 仕訳ドラフトを Excel に直接書き込み（承認後）

### メリット
- 柔軟性が高い
- MCP 不要、手動コピペで完結

## 書き込み系操作のガードレール

会計データへの直接書き込みは特に慎重に:

1. 常にユーザー承認: 書き込み前にプレビュー
2. バックアップ推奨: 書き込み前に現状のエクスポート
3. 最小権限: 読み取り専用で十分なら書き込み権限を渡さない
4. 監査ログ: 誰が何をしたかを記録

## 認証情報の扱い

- API キー・OAuth トークンを スキル設定ファイルに書かない
- 環境変数、OS キーチェーン、会計ソフト側の認証フロー
- git 事故防止（`.gitignore` で隔離）

## 移行・乗り換えサポート

会計ソフトを乗り換える場合:

1. 旧ソフトから仕訳データを CSV エクスポート
2. Claude がデータを整理・チェック
3. 新ソフトへの形式変換
4. 新ソフトへインポート（承認後）

期中移行は特に慎重に。税理士相談を推奨。

## まとめ

### 会計ソフトがある場合
- まずは レベル1（相談相手） で試す
- 慣れたら レベル2（CSV） に
- 業務量が多く MCP/API があれば レベル3 も検討

### 会計ソフトがない場合
- Excel / Google Sheets + 本スキル で足りるかも
- 事業規模が大きくなったら会計ソフト導入を検討

### 共通
- 最終的な入力・確認は ユーザー or 会計ソフト側
- AI はサポート、決定はユーザー
