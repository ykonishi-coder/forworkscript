# 機能: 月次レポート分析

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.accounting-helper/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


試算表・P/L（損益計算書）・B/S（貸借対照表）を読み解き、気になる変動や異常値を指摘する。

## 入力

1. 月次試算表 or P/L・B/S（CSV / テキスト / 会計ソフトの出力）
2. 前月・前年同月（比較用、あれば）
3. 予算（比較用、あれば）

## 手順

### 1. データの読み込み

会計ソフトからエクスポートされた試算表を読む:

```
勘定科目 | 借方残高 | 貸方残高
売上高 | | 10,000,000
売上原価 | 6,000,000 |
...
```

### 2. P/L の分析

#### 売上・利益
- 売上高
- 売上総利益（粗利）
- 営業利益
- 経常利益
- 税引前当期純利益
- 当期純利益

#### 前月比・前年同月比

```markdown
## P/L 分析

### 売上高
- 当月: 10,000,000円
- 前月: 9,000,000円 (+11.1%)
- 前年同月: 8,500,000円 (+17.6%)

### 売上総利益
- 当月: 4,000,000円 (粗利率 40.0%)
- 前月: 3,600,000円 (粗利率 40.0%)

✅ 粗利率は安定

### 販管費
- 当月: 3,000,000円
- 前月: 2,800,000円 (+7.1%)

### 営業利益
- 当月: 1,000,000円 (営業利益率 10.0%)
- 前月: 800,000円 (営業利益率 8.9%)

✅ 売上増加に伴い、営業利益率も改善
```

#### 気になる変動の検出

```markdown
### 変動アラート

🟡 広告宣伝費が前月比 +150%
- 前月: 100,000円 → 当月: 250,000円
- 原因確認推奨: キャンペーン実施? 予算超過?

🔴 通信費が前年同月比 +300%
- 前年: 30,000円 → 当月: 120,000円
- 契約変更? 個人利用の混入?

🟢 旅費交通費は前月並み
```

### 3. B/S の分析

#### 資産の部
- 現金・預金
- 売掛金
- 棚卸資産
- 固定資産

#### 負債の部
- 買掛金・未払金
- 借入金

#### 純資産の部
- 資本金
- 利益剰余金

#### 流動性・安全性

```markdown
## B/S 分析

### 流動比率
- 流動資産 / 流動負債 = 5,000万 / 2,000万 = 250%
- 評価: 🟢 健全（200%以上が理想）

### 自己資本比率
- 純資産 / 総資産 = 6,000万 / 10,000万 = 60%
- 評価: 🟢 健全（30%以上が目安）

### 現金・預金の推移
- 前期末: 3,000万 → 当月: 2,500万 (-500万)
- 原因: 設備投資 or 運転資金
```

#### 気になる兆候

```markdown
### 要注意ポイント

🟡 売掛金の増加
- 前月: 1,500万 → 当月: 2,000万 (+33%)
- 売上増加に比例して増加、ただし回収状況の確認推奨

🟡 棚卸資産の増加
- 前月: 500万 → 当月: 700万 (+40%)
- 売れ筋と滞留在庫の確認推奨

🟢 現金・預金は十分
```

### 4. キャッシュフローの推定

正式な C/F 計算書がなくても、P/L と B/S から推定:

```markdown
## キャッシュフロー（簡易）

### 営業活動によるCF（推定）
- 当期純利益: 500万
- 減価償却費: +100万
- 売掛金増加: -500万
- 買掛金増加: +200万
- 棚卸資産増加: -200万
合計: +100万

### 投資活動によるCF
- 固定資産取得: -300万

### 財務活動によるCF
- 借入金返済: -100万

合計: -300万

💡 キャッシュが減少傾向。売掛金回収と在庫管理に注意。
```

### 5. 予算実績比較（予算がある場合）

```markdown
## 予算実績

| 項目 | 予算 | 実績 | 達成率 |
|------|------|-----|-------|
| 売上高 | 900万 | 1,000万 | 111% ✅ |
| 売上総利益 | 360万 | 400万 | 111% ✅ |
| 販管費 | 280万 | 300万 | 107% ⚠️ |
| 営業利益 | 80万 | 100万 | 125% ✅ |

### 分析
- 売上は予算超過
- 販管費も予算超過（広告費増加が主因）
- 営業利益は予算超過で結果オーライ
```

### 6. 改善提案

```markdown
## 改善提案

### ✅ 好調
- 売上の伸び（前年同月 +17.6%）
- 粗利率の維持（40%）

### ⚠️ 要注意
1. 通信費の異常増加
   - 原因特定 → 適正化
   - 個人利用混入のチェック

2. 売掛金の増加
   - 滞留売掛の有無確認
   - 回収サイクルの短縮検討

3. 棚卸資産の増加
   - 滞留在庫の処分検討
   - 発注量の見直し

### 💡 検討事項
- キャッシュ減少トレンド → 資金繰りの長期計画
```

### 7. DA レビュー

`accounting-helper-advocate` に分析結果を渡してチェック:

- 数字の計算ミス
- 見落としている異常値
- 表現の妥当性

### 8. ファイル保存

```
{保存先}/monthly-analyses/{YYYY-MM}.md
```

月次で蓄積、トレンド分析に活用。

## 特殊な論点

### 季節性のある業種
- 前月比 よりも 前年同月比を重視
- 季節変動の正常範囲を設定

### 年度末決算への影響
- 決算前の経費先取り・収益先送りの兆候
- 在庫評価の方法
- 固定資産の減損判定

### 税務調査で指摘されやすいポイント
- 役員報酬の変動
- 交際費の急増
- 個人経費の混入
- 売上計上漏れ

## やってはいけないこと

- 数字を創作
- 根拠のない判断（「問題あり」の断定）
- 税務上の最終判断
- 経営判断を代行（経営者の領域）

## 完了メッセージ

```markdown
## 月次レポート分析完了

対象期間: 2026年4月
保存先: {パス}

### 総評
- 売上・利益ともに好調（前年同月比 +17.6%）
- 一部費用に変動あり（通信費・広告費）
- 流動性・安全性は健全

### 🟢 好調ポイント
- 売上成長の継続
- 粗利率の安定

### ⚠️ 要注意
1. 通信費の異常増加（前年比 +300%）
2. 売掛金の増加（回収状況の確認）
3. 棚卸資産の増加（滞留チェック）

### 次のアクション
- 通信費の内訳調査
- 売掛金の年齢管理表作成
- 棚卸資産の品目別分析

⚖️ 経営判断・税務申告等は税理士・会計士にご確認ください。
```
