# 機能: 仕訳ドラフト作成

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.accounting-helper/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


取引内容から会計の仕訳ドラフトを生成する。

## 入力

1. 取引内容（日本語での説明）
2. 金額
3. 取引日
4. 追加情報（税込/税抜・インボイス該当・取引相手）

## 手順

### 1. 取引分類

取引を以下のタイプに分類:

- 収入取引: 売上・受取利息・雑収入
- 費用取引: 仕入・経費・支払利息
- 資産取引: 現金入出金・固定資産購入・貸付
- 負債取引: 借入・買掛・未払金
- 資本取引: 出資・配当・役員報酬

### 2. 複式簿記の原則適用

借方・貸方を決定:

#### 現金支払の経費
```
借方: {費用科目} / 貸方: 現金
```

#### 預金からの支払
```
借方: {費用科目} / 貸方: 普通預金
```

#### 掛け取引（後払い）
```
借方: {費用科目} / 貸方: 買掛金 or 未払金
```

#### 売上（現金）
```
借方: 現金 / 貸方: 売上高
```

#### 売上（掛け）
```
借方: 売掛金 / 貸方: 売上高
```

### 3. 消費税の処理

#### 税抜経理の場合
```
借方: {費用} {税抜金額}
借方: 仮払消費税 {消費税額}
貸方: 現金 {税込金額}
```

#### 税込経理の場合
```
借方: {費用} {税込金額}
貸方: 現金 {税込金額}
```

どちらかは会計方針による（`config.accounting.tax_method`）。

### 4. 仕訳ドラフトの生成

```markdown
## 仕訳ドラフト

取引日: 2026-04-23
取引内容: 交通費（新幹線往復・東京-大阪）

### 仕訳

| 借方 | 金額 | 貸方 | 金額 |
|------|-----|------|-----|
| 旅費交通費 | 27,273 | 現金 | 30,000 |
| 仮払消費税 | 2,727 | | |

### 詳細
- 消費税区分: 課税10%
- インボイス: {適格/非適格}
- 補助科目: {必要なら}
- 摘要: 出張旅費（東京-大阪 新幹線往復）

### 会計ソフト入力時の注意
- 勘定科目: 旅費交通費
- 税区分: 課対仕入 10%
- 部門: {部門設定がある場合}
```

### 5. 複数パターンの提示（迷う場合）

```markdown
### 仕訳の候補（どちらがよいか検討）

#### パターンA: 消耗品費として処理
借方: 消耗品費 18,182 / 貸方: 現金 20,000
借方: 仮払消費税 1,818

適用ケース: 通常の消耗品（文房具、事務用品）

#### パターンB: 器具備品として資産計上
借方: 器具備品 18,182 / 貸方: 現金 20,000
借方: 仮払消費税 1,818
（少額減価償却資産の特例で全額当期費用化も可）

適用ケース: 1年超使用予定の什器備品で10万円以上

### 推奨: 今回は20,000円（10万円未満）なので パターンA（消耗品費）
```

### 6. 源泉徴収の処理

個人への報酬支払:

```markdown
### 仕訳: 個人事業主への報酬支払

報酬額: 100,000円（税抜）
消費税: 10,000円
源泉徴収税: 10,210円（報酬 100,000 × 10.21%）

### 仕訳

| 借方 | 金額 | 貸方 | 金額 |
|------|-----|------|-----|
| 外注費 | 100,000 | 現金 | 99,790 |
| 仮払消費税 | 10,000 | 預り金（源泉） | 10,210 |

### 注意
- 源泉徴収税は翌月10日までに納付
- 支払調書を翌年1月31日までに税務署提出
```

### 7. DA チェック

`accounting-helper-advocate` にドラフトを渡してチェック:

- 借方・貸方の金額一致
- 勘定科目の妥当性
- 消費税区分
- 源泉徴収の漏れ
- インボイス対応

### 8. ファイル保存

```
{保存先}/journal-drafts/{YYYY-MM}/{日付}-{連番}.md
```

月次で集約して会計ソフトにインポート or 手動入力。

### 9. CSV 形式での出力（レベル2以上）

会計ソフトにインポートできる CSV 形式で出力:

```csv
日付,借方科目,借方金額,貸方科目,貸方金額,摘要,税区分
2026-04-23,旅費交通費,27273,現金,30000,新幹線往復,課対仕入10%
2026-04-23,仮払消費税,2727,,,,
```

ユーザーが会計ソフトにインポート。

### 10. API / MCP 連携（レベル3）

レベル3設定の場合:
1. 仕訳ドラフトを提示
2. ユーザー承認
3. 会計ソフトに API / MCP で登録
4. 結果レポート

勝手な自動登録はしない。毎回プレビュー → 承認 → 実行。

## よくある取引パターン集

### 消耗品購入（レシート払い）
```
借方: 消耗品費 / 貸方: 現金
```

### 給与振込
```
借方: 給料手当 / 貸方: 普通預金
借方: 給料手当（社会保険会社負担分）/ 貸方: 預り金（社会保険）
　　　　　　　　　　　　　　　　　　預り金（所得税）
　　　　　　　　　　　　　　　　　　預り金（住民税）
```

### 売上（前受金）
```
借方: 普通預金 / 貸方: 前受金
（サービス提供時）
借方: 前受金 / 貸方: 売上高
```

### 借入金
```
借方: 普通預金 / 貸方: 長期借入金（1年超）or 短期借入金（1年以内）
```

### 減価償却
```
借方: 減価償却費 / 貸方: 減価償却累計額
```

### 期末棚卸
```
借方: 期末商品棚卸高 / 貸方: 商品
```

## やってはいけないこと

- 個人経費の混入
- 架空仕訳の生成
- 税法違反の処理（脱税になる処理）
- ユーザー承認なしの自動登録

## 完了メッセージ

```markdown
## 仕訳ドラフト完成

件数: 3件
合計借方: 60,000円 / 合計貸方: 60,000円（一致OK）

### サマリ
- 旅費交通費: 30,000円
- 会議費: 20,000円
- 消耗品費: 10,000円

### DA チェック
🟢 借方・貸方一致、勘定科目適切、消費税区分 OK

### 次のステップ
- レベル1: 会計ソフトに手動入力
- レベル2: CSV 出力済み → 会計ソフトでインポート
- レベル3: 会計ソフトへの自動登録（承認待ち）

⚖️ 最終的な仕訳は、税理士・会計士にご確認ください。
```
