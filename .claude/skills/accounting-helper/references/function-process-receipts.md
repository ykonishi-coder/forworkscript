# 機能: 領収書・請求書処理

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.accounting-helper/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


領収書や請求書の内容を読み取り、勘定科目・消費税区分を提案する。

## 入力

1. 領収書・請求書の情報
   - テキスト（手動入力）
   - OCR 結果（会計ソフトの読み取り結果）
   - 画像（処理時に Claude API に送る、マスキング推奨）

2. 用途・目的
   - 「営業会議の飲食代」等、何の支出か

## 手順

### 1. プライバシー確認

```markdown
領収書処理を始めます:

- マスキング: 店名・取引先名をマスキングしますか？
- 画像送信: 領収書画像を送る場合、一時処理後破棄されます（保存しません）

進めてよろしいですか？
```

### 2. 情報抽出

領収書から以下を抽出:

- 取引日
- 取引先（店名・社名）
- 金額（税込）
- 消費税額（明示されていれば）
- 適用税率（10% / 8% 軽減税率）
- 品目・内容
- インボイス登録番号（T+13桁、あれば）

抽出できない情報はユーザーに確認。

### 3. 勘定科目の提案

用途・内容から勘定科目を提案:

#### よくある勘定科目

##### 販管費
- 旅費交通費: 電車・タクシー・出張旅費
- 通信費: 携帯電話・インターネット・郵送
- 水道光熱費: 電気・ガス・水道
- 消耗品費: 文房具・10万円未満の備品
- 新聞図書費: 書籍・雑誌・新聞
- 会議費: 1人5,000円以下の会議・打合せ飲食
- 接待交際費: 得意先との飲食・贈答
- 広告宣伝費: 広告・PR
- 支払手数料: 振込手数料・決済手数料
- 諸会費: 業界団体費
- 租税公課: 収入印紙・税金
- 福利厚生費: 従業員慰労・健康診断

##### 仕入・外注
- 仕入高: 商品仕入
- 外注費: 業務委託費用

##### 固定資産
- 器具備品: 10万円以上の備品（減価償却対象）
- ソフトウェア: 会計ソフト等のライセンス

#### 選択の目安

```markdown
### 提案: 営業会議の飲食代 (4人、18,000円)

勘定科目の候補:

1. 接待交際費（★★★ 標準）
   - 社外の方との飲食
   - 税法上の損金算入に制限あり（中小企業 年800万円まで）
   - 社交業務関連

2. 会議費（1人5,000円以下の場合のみ）
   - 1人あたり 18,000 ÷ 4 = 4,500円 → 会議費該当可
   - 損金算入に制限なし

3. 福利厚生費（社内メンバーのみの場合）
   - 社外の方が含まれるなら該当しない

推奨: 4人で4,500円/人 なので 会議費 が適切
（社外の方が含まれる場合、会議目的が明確なら会議費、懇親が主なら接待交際費）

### 消費税区分
- 飲食は課税取引（10% 標準税率 / 店内飲食）
- テイクアウトなら 8% 軽減税率
```

### 4. インボイス対応の確認

2023年10月以降の請求書・領収書:

```markdown
### インボイス要件チェック

- [ ] 適格請求書発行事業者の登録番号（T+13桁）が記載されているか
  - 現状: {あり / なし}

【登録番号なしの場合】
- インボイス経過措置期間中:
  - 2023年10月〜2026年9月: 仕入税額控除 80% まで可
  - 2026年10月〜2029年9月: 50% まで
  - 2029年10月以降: 控除不可

- 経理処理の注意: 仕入税額控除の区分記帳が必要
```

### 5. 源泉徴収の必要性

個人への支払の場合:

```markdown
### 源泉徴収対象かチェック

この支払は個人宛ですか？

【源泉徴収対象】
- 原稿料・講演料
- 税理士・弁護士等の士業報酬
- デザイナー・ライター・カメラマン等のクリエイター報酬
- 芸能人の報酬

【源泉徴収税率】
- 100万円以下の部分: 10.21%
- 100万円超の部分: 20.42%

請求書金額の内訳:
- 報酬額: {X}円
- 源泉徴収税: {X × 0.1021}円
- 差引支払額: {X × 0.8979}円
- 別途、消費税の扱いを確認

【注意】法人への支払は原則として源泉徴収不要
```

### 6. 仕訳ドラフト生成

勘定科目・消費税区分が決まったら、仕訳を生成:

```markdown
### 仕訳ドラフト

日付: 2026-04-15
摘要: 〇〇プロジェクト打合せ（4名）

| 借方 | 金額 | 貸方 | 金額 |
|------|-----|------|-----|
| 会議費 | 16,363 | 現金 | 18,000 |
| 仮払消費税 | 1,637 | | |

消費税区分: 課税10%
補助科目: {あれば}

### 備考
- 領収書: {店名マスキング or 実店名}
- 取引日: 2026-04-15
- 参加者: 4名（社外2・社内2）
```

### 7. advocate チェック

勘定科目選択・消費税区分・源泉徴収の要否について `accounting-helper-advocate` にレビュー依頼:

```markdown
### DA レビュー

🟢 勘定科目: 会議費で適切
🟢 消費税区分: 課税10% OK
🟢 源泉徴収: 法人宛のため不要
🟡 注意: 参加者に社外が含まれる場合、接待交際費の可能性も検討
```

### 8. ファイル保存

```
{保存先}/receipts/{YYYY-MM-DD}-{連番}.md
```

仕訳ドラフトも個別ファイル or 月次まとめに追加。

### 9. 次のアクション

```markdown
### 次のステップ

1. 会計ソフトへの入力:
   - レベル1: 自分で会計ソフトに入力してください
   - レベル2: CSV 形式でエクスポートしますか？
   - レベル3: 会計ソフトに自動投入（要承認）

2. 領収書の保管:
   - 紙の場合: 7年間保管（法人税法）
   - 電子の場合: 電子帳簿保存法に従い保管
```

## OCR 結果の取り扱い

会計ソフト（freee 等）の OCR 結果を渡された場合:

1. OCR 結果の誤読をチェック
2. 金額・日付・店名の不一致を検出
3. 勘定科目の提案

```markdown
### OCR 結果のチェック

読み取られた内容:
- 日付: 2026-04-15（OK）
- 店名: 株式会社〇〇（OK）
- 金額: 15,000円

⚠️ 注意:
- 税抜/税込の表記が不明瞭
- 領収書原本で確認を推奨
```

## 複数領収書の一括処理

```markdown
10枚の領収書を一括処理します。

進め方:
1. 各領収書を順に処理
2. 共通パターン（例: 同じ取引先）があれば自動学習
3. 仕訳ドラフトを月次で一覧化
4. 最終確認後に会計ソフトへ

所要時間: 約{N}分。進めてよろしいですか？
```

## 電子帳簿保存法への配慮

2024年1月から電子取引は電子保存が義務化:

- 電子でもらった請求書・領収書は電子のまま保存
- タイムスタンプ or 検索要件 or 事務処理規程
- このスキルで処理した領収書画像は 会計ソフト or クラウドストレージに保存、スキル側では長期保存しない

## やってはいけないこと

- 勘定科目を断定する（個別事情で変わる）
- 税務上の判断を断定（税理士領域）
- 領収書画像を長期保存（プライバシー）
- 個人的経費を法人経費として処理（税務リスク）
