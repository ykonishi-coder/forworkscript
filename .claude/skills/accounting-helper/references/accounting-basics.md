# 会計の基礎知識

このスキルを使うための基本的な会計知識。

## 複式簿記の基本

### 借方・貸方の原則

すべての取引は、借方（左） と 貸方（右） に同額で記録:

```
借方 = 貸方 （必ず一致）
```

### 5要素の位置

| 要素 | 増加 | 減少 |
|------|-----|------|
| 資産 | 借方 | 貸方 |
| 負債 | 貸方 | 借方 |
| 純資産 | 貸方 | 借方 |
| 収益 | 貸方 | 借方 |
| 費用 | 借方 | 貸方 |

### 基本パターン

```
現金で経費を払った:
借方 {費用} / 貸方 現金（資産減少）

現金売上:
借方 現金（資産増加）/ 貸方 売上高（収益増加）

借入した:
借方 現金（資産増加）/ 貸方 借入金（負債増加）

買掛で仕入:
借方 仕入高（費用）/ 貸方 買掛金（負債増加）
```

## 財務諸表

### 損益計算書（P/L）

一定期間の利益を計算:

```
売上高
- 売上原価
= 売上総利益（粗利）
- 販管費
= 営業利益
+ 営業外収益 - 営業外費用
= 経常利益
+ 特別利益 - 特別損失
= 税引前当期純利益
- 法人税等
= 当期純利益
```

### 貸借対照表（B/S）

一時点の財政状態:

```
[左]               [右]
資産の部          負債の部
 流動資産          流動負債
 固定資産          固定負債
                  純資産の部
                   資本金
                   利益剰余金
```

### キャッシュフロー計算書（C/F）

現金の増減:

- 営業活動によるCF
- 投資活動によるCF
- 財務活動によるCF
- = 現金増減

## 消費税の仕組み

### 税率
- 標準: 10%
- 軽減税率: 8%（飲食料品・新聞）

### 課税・非課税・不課税・免税

- 課税: 通常の取引
- 非課税: 社会政策的配慮（医療・教育・住宅・土地・利息等）
- 不課税: 事業として行われない（給与・寄付等）
- 免税: 輸出等

### 仕入税額控除

売上の消費税 - 仕入の消費税 = 納付税額

### インボイス制度（2023年10月〜）

仕入税額控除に適格請求書が必要:
- 登録番号（T+13桁）
- 税率ごとの区分

### 経過措置
- 2023/10 - 2026/9: 非適格でも 80% 控除可
- 2026/10 - 2029/9: 50% 控除
- 2029/10 〜: 控除不可

## 源泉徴収

### 対象
- 給与・賞与
- 報酬・料金（個人への支払）

### 報酬の源泉徴収（所得税法204条）
- 100万円以下の部分: 10.21%
- 100万円超の部分: 20.42%

### 対象業種（例）
- 原稿料・講演料
- 弁護士・税理士・公認会計士等
- デザイナー・ライター・カメラマン

## 減価償却

### 対象
- 取得価額10万円以上の資産

### 少額減価償却資産の特例
- 中小企業: 30万円未満の資産を全額損金算入（年間300万円まで）

### 方法
- 定率法: 初年度に多く償却
- 定額法: 毎年同額

## 交際費

### 中小企業の損金算入限度
- 年間800万円までは全額損金算入
- または、接待飲食費の50%

### 会議費との区分
- 1人5,000円以下の飲食: 会議費（交際費対象外）
- 5,000円超: 接待交際費
