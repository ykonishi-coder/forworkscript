# 経理データのプライバシー配慮

経理業務は機密情報の塊。特に慎重な扱いが必要。

## 含まれる機密情報

- 売上・利益: 会社の業績
- 経費: 取引関係・内部構造
- 給与: 従業員の個人情報（要配慮個人情報の一部）
- 取引先情報: 相手方の営業情報
- 銀行口座: 認証情報ではないが漏洩リスク
- 税務情報: 税額・申告内容

## プライバシー保護の方針

### 1. 学習に使われない
Anthropic API は送信データを学習に使わない（デフォルト方針）。

### 2. マスキング

設定 `privacy.masking_level` に応じて自動マスキング:

#### 最厳重
- 取引先名 → `{取引先A}`
- 具体的金額 → `{金額}`
- 個人名 → `{氏名}`
- 銀行口座 → マスキング
- 日付 → マスキング

#### 厳重
- 取引先名 → マスキング
- 個人名 → マスキング
- 金額・日付 → 残す

#### 標準
- 個人名 → マスキング
- その他 → 残す

### 3. ローカル保存
設定・処理結果サマリはすべてユーザーのPC内。外部送信なし。

### 4. 自動削除ポリシー
`config.privacy.cleanup.delete_after_days` で設定。

### 5. git 事故防止
`.gitignore` への自動追加提案。

## 給与情報の特別扱い

給与情報は特に機密:

- 本スキルでは原則扱わない
- 給与計算は別ソフト（freee人事労務・マネーフォワード給与等）
- このスキルで扱うのは仕訳（給料手当の合計のみ）
- 個別の給与明細・源泉徴収票は扱わない

## 送信最小化のコツ

### 条項単位で渡す
契約書レビューと同様、必要な部分だけ を送信:

- 領収書: 金額・日付・店名だけ（画像全体より安全）
- 月次レポート: 該当科目の数字だけ
- 請求書: 合計金額と内容だけ

### 手動コピペ推奨
自動連携より手動コピペが最も安全:
- あなたが選んだ情報だけ渡る
- マスキングの判断ができる

## 会計ソフトとの連携時の注意

### 読み取り権限のみで済ます
- API 連携時、書き込み権限は渡さない
- 読み取りだけで機能は十分

### 認証情報
- OS キーチェーン管理
- スキル設定ファイルに書かない

### 監査ログ
- 会計ソフト側で、誰がアクセスしたかのログ
- 定期的に確認

## 組織的なプライバシー対応

### 社内ルール
- 経理データの扱い方針
- AI ツール利用の承認フロー
- 漏洩時の対応フロー

### 契約関係
- 顧問税理士との情報共有同意
- 従業員の給与情報の扱い（労使協定等）

### 法令遵守
- 個人情報保護法
- 要配慮個人情報（病歴等が含まれる場合）

## 漏洩リスクと対策

### 主なリスク
1. git への誤コミット
2. スクリーンショットの共有
3. メール送信先ミス
4. クラウド同期の誤設定

### 対策
1. `.gitignore` で隔離
2. 設定フォルダを安全な場所に
3. 送信前の確認
4. バックアップの適切な管理

## 事故時の対応

### 誤って公開してしまった
1. 即座に削除（サーバー側含む）
2. 影響範囲の確認
3. 関係者への通知
4. 個人情報保護委員会への報告（該当時）

### 会計ソフトのパスワード漏洩
1. 即座にパスワード変更
2. 不正アクセスログ確認
3. 必要なら税務署・税理士に相談

## データ削除

### 手動削除

```bash
# Mac / Linux
# 設定フォルダごと
rm -rf ./.accounting-helper/
# 特定のデータのみ
rm -rf ./.accounting-helper/monthly-analyses/2025-*
```

```powershell
# Windows PowerShell
# 設定フォルダごと
Remove-Item -Recurse -Force ./.accounting-helper/
# 特定のデータのみ
Remove-Item -Recurse -Force ./.accounting-helper/monthly-analyses/2025-*
```

### 自動削除ポリシー

`config.privacy.cleanup`:
- `delete_after_days`: 何日後に削除するか
- `notify_before_delete`: 削除前に通知

## まとめ

- 最厳重マスキングから始める
- 必要最小限の情報で処理
- ローカル保存徹底
- 自動削除ポリシー設定
- .gitignore 必須
- 給与情報は原則扱わない
- 顧問税理士との情報共有ルール整備
