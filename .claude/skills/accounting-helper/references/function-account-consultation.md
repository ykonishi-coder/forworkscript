# 機能: 勘定科目相談

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.accounting-helper/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


「この取引、何勘定で処理すれば？」への回答。

## 入力

- 取引内容（自然言語）
- 金額
- 取引相手（必要なら）

## 手順

### 1. 取引の分析

- 何のための支出/収入か
- 継続的か単発か
- 業務関連性

### 2. 候補の提示

複数の候補を、該当可能性の高い順に提示:

```markdown
## 勘定科目の候補

### 取引: 従業員の健康診断費用 45,000円

候補1: 福利厚生費（★★★ 推奨）
- 要件: 全従業員を対象
- 税務: 費用として全額損金算入可

候補2: 保健衛生費（★★☆）
- 福利厚生費の内訳細目として

候補3: 給与（経済的利益）（★☆☆）
- 特定個人のみの場合 → 給与扱いになる可能性
- 税務リスクあり

### 推奨
この支出が「全従業員対象」なら 福利厚生費。
特定個人だけなら、給与扱いのリスクがあるため税理士確認を。
```

### 3. 税務上の取り扱い

- 損金算入の可否
- 消費税区分
- 源泉徴収の要否

### 4. よく間違えるパターンの注意

```markdown
### 注意点

- 福利厚生費 vs 給与: 対象範囲で変わる
- 接待交際費 vs 会議費: 1人5,000円基準
- 広告宣伝費 vs 販売促進費 vs 交際費: 提供対象で変わる
- 資産 vs 消耗品費: 10万円基準
```

## 代表的な勘定科目（参考）

### 売上原価系
- 仕入高
- 外注費
- 材料費

### 販管費系
- 給料手当 / 役員報酬
- 賞与
- 法定福利費
- 福利厚生費
- 旅費交通費
- 通信費
- 水道光熱費
- 消耗品費
- 事務用品費
- 修繕費
- 賃借料
- 支払手数料
- 会議費
- 接待交際費
- 広告宣伝費
- 販売促進費
- 新聞図書費
- 研修費
- 諸会費
- 租税公課
- 減価償却費

### 営業外
- 受取利息
- 支払利息
- 為替差損益
- 雑収入 / 雑損失

### 資産系
- 現金
- 普通預金
- 売掛金
- 未収入金
- 棚卸資産（商品・製品・仕掛品・原材料）
- 前払費用
- 器具備品（10万円以上）
- 建物
- ソフトウェア（20万円以上）

### 負債系
- 買掛金
- 未払金
- 短期借入金 / 長期借入金
- 預り金（源泉・社保等）
- 前受金

## やってはいけないこと

- 断定（「絶対〇〇」と言い切らない）
- 税務リスクの見落とし
- 個別事情の無視
