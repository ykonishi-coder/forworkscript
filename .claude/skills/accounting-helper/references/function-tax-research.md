# 機能: 税務情報調査

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.accounting-helper/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


日本の税務（消費税・法人税・所得税・住民税・印紙税等）に関する一般情報を、信頼できる公式ソースから調査する。

## 大原則

1. 公式ソース最優先: 国税庁・e-Gov
2. 最新情報確認: 税制は毎年改正
3. 断定しない: 「〜と解される」「〜の可能性」
4. 税理士相談推奨: 必ず添える

## 信頼できる情報源

### 最優先（公式）
- 国税庁: https://www.nta.go.jp/
  - タックスアンサー: https://www.nta.go.jp/taxes/shiraberu/taxanswer/
- e-Gov 法令検索: https://elaws.e-gov.go.jp/

### 補足
- 中小企業庁: https://www.chusho.meti.go.jp/
- 財務省: https://www.mof.go.jp/
- 地方自治体（住民税・地方税）

## 検索クエリの例

```
{税目} 国税庁 最新
消費税 インボイス {今年}
法人税 改正 {今年}
{テーマ} タックスアンサー
```

## よくある調査テーマ

### 消費税
- インボイス制度
- 簡易課税
- 2割特例
- 国際取引の税務
- 税率（10%、軽減8%）

### 法人税
- 損金算入・不算入
- 交際費の損金算入限度
- 役員報酬の取り扱い
- 減価償却・少額減価償却資産特例
- 欠損金繰越

### 所得税
- 給与所得控除
- 所得控除（医療費・社会保険料・生命保険料等）
- 確定申告

### 源泉徴収
- 報酬・料金等の源泉徴収
- 給与の源泉徴収
- 外国人への支払

### 印紙税
- 契約書の印紙
- 金銭の授受に関する印紙

## 手順

### 1. 調査テーマ確認
```markdown
何について調べますか？
- 具体的な税目
- 取引内容
- 期間
- 目的（申告準備 / 知識 / 判断材料）
```

### 2. Web 検索

国税庁・e-Gov を最優先。

### 3. 複数ソースで確認

### 4. 情報整理

```markdown
## {税目} 調査結果

テーマ: {調査内容}
調査日: YYYY-MM-DD

### 結論
{一般的に言えること}

### 根拠
- 国税庁タックスアンサー No.XXXX: {URL} / YYYY-MM-DD 確認
- 所得税法 第XXX条: {e-Gov URL}
- 通達: {該当通達}

### 注意事項
- 個別事情で結論が変わる可能性
- 最新の法改正の有無（{次回改正予定等}）

### 例外・特殊ケース
- {あれば}

⚖️ 免責: 本情報は一般情報です。具体的な税務判断は税理士にご相談ください。
```

### 5. ファイル保存

```
{保存先}/research/{YYYY-MM-DD}-{テーマ}.md
```

## やってはいけないこと

- 断定的な税務判断
- 脱税・節税の具体的手法の教示（違法領域）
- 古い税制情報（毎年改正される）
- 税務申告書の代理作成
