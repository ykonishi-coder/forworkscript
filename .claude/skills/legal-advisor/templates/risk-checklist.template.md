# 契約書リスクチェックリスト

契約書レビュー時のチェック項目。契約タイプ別・観点別。

## 共通チェック（全契約書）

### 形式
- [ ] 契約当事者が特定されている（名称・住所）
- [ ] 代表者の記名押印欄がある
- [ ] 締結日・契約書作成日の記載
- [ ] 収入印紙が必要な契約か、必要なら貼付
- [ ] ページ番号・契印

### 基本条項
- [ ] 契約の目的が明確
- [ ] 契約期間が明確（開始日・終了日）
- [ ] 対価・支払条件が明確
- [ ] 解除条件・解除の効果
- [ ] 紛争解決（協議・裁判管轄）
- [ ] 反社条項

### 曖昧な表現
- [ ] 「速やかに」→ 具体的期間
- [ ] 「合理的な」→ 基準の明示
- [ ] 「誠実に」→ 具体的な義務内容
- [ ] 「必要に応じて」→ 判断基準

## NDA（秘密保持契約）

### 必須
- [ ] 秘密情報の定義
- [ ] 秘密保持義務（主体・範囲）
- [ ] 使用目的制限
- [ ] 秘密保持期間（契約終了後も含む）
- [ ] 複製・加工の制限
- [ ] 返還・廃棄義務
- [ ] 除外事項（公知情報等）

### 不利ポイント
- [ ] 秘密保持義務が一方的（相手方だけ開示、自分だけ義務）
- [ ] 「秘密情報」の定義が広すぎる（契約関連すべて）
- [ ] 秘密保持期間が長すぎる（10年以上等）
- [ ] 従業員の記憶に残る情報も厳格に規制
- [ ] 返還・廃棄義務が非現実的

## 業務委託契約

### 必須
- [ ] 業務内容・範囲（SOW）
- [ ] 成果物の定義
- [ ] 対価・支払条件
- [ ] 支払期日
- [ ] 検収条件・検収期間
- [ ] 瑕疵担保 / 契約不適合責任
- [ ] 知的財産権の帰属
- [ ] 秘密保持
- [ ] 再委託の可否
- [ ] 解除条件
- [ ] 損害賠償

### 不利ポイント（受注側から見て）
- [ ] 業務範囲が不明確（後で追加要求される）
- [ ] 検収条件・期間が曖昧
- [ ] 検収完了を支払条件にしているが検収期間がない
- [ ] 成果物の著作権が全て発注側（ノウハウ含む）
- [ ] 瑕疵担保期間が長すぎる
- [ ] 損害賠償の上限なし
- [ ] 中途解除権が発注側のみ
- [ ] 追加・変更作業の対価規定なし
- [ ] 再委託絶対禁止

### 不利ポイント（発注側から見て）
- [ ] 受注側の責任制限が強すぎる
- [ ] 瑕疵担保期間が短すぎる
- [ ] 成果物の知財が受注側に留まる
- [ ] 納期遅延のペナルティ不在

### 下請法適用時（発注側1000万円超×受注側1000万円以下 等）
- [ ] 発注書面（3条書面）の必要事項
- [ ] 支払期日 60日以内
- [ ] 減額条項がない
- [ ] 返品条項が合理的
- [ ] 買叩きでない

## 売買契約

### 必須
- [ ] 目的物の特定
- [ ] 価格
- [ ] 納期・納品方法
- [ ] 所有権移転時期
- [ ] 危険負担
- [ ] 契約不適合責任
- [ ] 検収

### 不利ポイント
- [ ] 契約不適合責任の期間が短すぎる
- [ ] 検収期間が長すぎる（支払遅延）
- [ ] 所有権移転時期が曖昧
- [ ] 危険負担の帰属が不明確

## 賃貸借契約

### 必須
- [ ] 目的物の特定
- [ ] 賃料
- [ ] 敷金・礼金
- [ ] 契約期間
- [ ] 更新条件
- [ ] 原状回復義務
- [ ] 禁止事項
- [ ] 解除条件

### 不利ポイント（借主側）
- [ ] 原状回復の範囲が広すぎる
- [ ] 賃料改定条項が一方的
- [ ] 更新料の金額
- [ ] 借主の解除権制限

## 利用規約

### 必須
- [ ] サービス内容
- [ ] 利用料金
- [ ] 禁止事項
- [ ] 免責事項
- [ ] 変更条項
- [ ] 準拠法・管轄
- [ ] 個人情報取扱

### 消費者契約法適合性（B to C）
- [ ] 事業者の免責が過度でない（故意・重過失の免責は無効）
- [ ] 消費者の解除権を不当に制限していない
- [ ] 事業者の一方的変更権が不当に広くない
- [ ] 違約金が平均的な損害額を超えていない

### 特商法適合性（通販・サブスク）
- [ ] 事業者情報の表示
- [ ] 契約の申込みの撤回・解除の規定
- [ ] 定期購入の場合、金額・解約方法の明示

## 雇用契約書

### 必須
- [ ] 就業の場所・業務内容
- [ ] 労働時間・休憩・休日
- [ ] 賃金
- [ ] 退職に関する事項
- [ ] 期間の定めがある場合、期間と更新の有無

### 不利ポイント（労働者側）
- [ ] 試用期間が長すぎる（6ヶ月超等）
- [ ] 競業避止義務が広範囲・長期
- [ ] 退職後の秘密保持が過度
- [ ] 固定残業代の内訳が不明確
- [ ] 労働条件の書面明示が不足

### 違法リスク
- [ ] 最低賃金を下回っていないか
- [ ] 法定労働時間を超えていないか（36協定なしの残業）
- [ ] 労基法違反の解雇条項

## 権利の帰属・知的財産

### 業務委託・制作系契約での論点
- [ ] 成果物の著作権帰属
- [ ] 著作者人格権の取扱（譲渡不可、不行使特約）
- [ ] 既存知財・汎用ノウハウの留保
- [ ] 第三者知財の保証
- [ ] 特許出願の合意
- [ ] ライセンス許諾

## 損害賠償

### 論点
- [ ] 賠償範囲（直接損害のみ/間接損害含む）
- [ ] 逸失利益の扱い
- [ ] 上限額の有無
- [ ] 免責事由（不可抗力等）
- [ ] 遅延損害金

### 注意
- 消費者契約では事業者の故意・重過失の免責は無効
- 独占禁止法違反の可能性ある損害賠償条項

## 解除

### 論点
- [ ] 解除事由（債務不履行/合意解除/任意解除）
- [ ] 通知期限
- [ ] 解除の効果（既履行分の扱い）
- [ ] 違約金
- [ ] 中途解約権の対等性

## 紛争解決

### 論点
- [ ] 協議優先条項
- [ ] 調停・仲裁の選択肢
- [ ] 専属管轄裁判所
- [ ] 準拠法（国際契約の場合）

### 注意
- 裁判管轄は被告地（訴えられる側の所在地）が中立
- 相手方の所在地管轄は不利になりがち

## 使い方

各契約タイプで該当する項目をチェック。
- ✅: 問題なし
- ⚠️: 要検討
- ❌: 修正必要

advocate レビューと合わせて、総合的なリスク判定を。

最終判断は必ず弁護士・法務専門家にご相談ください。
