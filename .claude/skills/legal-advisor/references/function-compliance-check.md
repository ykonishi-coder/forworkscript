# 機能: コンプライアンスチェック

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.legal-advisor/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


事業活動・契約書・社内文書が、日本の主要法令に適合しているかチェックする。

## 対象法令

業種・業務によって重点が変わる。主要なもの:

### 共通
- 民法（契約・不法行為）
- 会社法（株式会社・取引）
- 個人情報保護法
- 独占禁止法

### 発注・受注関係
- 下請法（下請代金支払遅延等防止法）

### 消費者取引
- 消費者契約法
- 特定商取引法
- 景品表示法

### 労働
- 労働基準法
- 労働契約法
- 男女雇用機会均等法
- 労働安全衛生法

### 知財
- 著作権法
- 特許法
- 商標法
- 不正競争防止法

### 業種別
- 金商法（金融業）
- 貸金業法（貸金業）
- 医薬品医療機器等法（医療）
- 電気通信事業法（通信）
- 宅建業法（不動産）

## 手順

### 1. チェック対象の特定

```markdown
何をコンプライアンスチェックしますか？

1. 特定の契約書（第三者との契約）
2. 利用規約・プライバシーポリシー（自社Web等）
3. 就業規則・労働契約
4. 広告・販促資料
5. 事業スキーム全体
6. その他
```

### 2. 関連法令の絞り込み

対象と業種から、チェックする法令を絞る:

```markdown
以下の法令との適合性をチェックします:

- 民法（契約全般）
- 下請法（貴社が資本金1000万円超、相手方が1000万円以下の場合）
- 消費者契約法（B to C の場合）
- 個人情報保護法（個人情報を扱う場合）

他にチェックしたい法令はありますか？
```

### 3. 法令別の重点チェック項目

#### 下請法

対象範囲:
- 親事業者（発注側）の資本金: 1000万円超
- 下請事業者（受注側）の資本金: 1000万円以下
- または、親側3億円超 / 下請側3億円以下 等（条件あり）
- 製造・修理・情報成果物作成 / 役務提供委託

親事業者の11の義務・禁止事項:

義務:
1. 発注書面の交付
2. 支払期日の定め（60日以内）
3. 遅延利息の支払い
4. 書類の保存

禁止事項:
1. 受領拒否
2. 支払遅延
3. 減額
4. 返品
5. 買叩き
6. 購入・利用強制
7. 報復措置
8. 有償支給原材料の早期決済
9. 割引困難手形の交付
10. 不当な経済上の利益提供要請
11. 不当な給付内容の変更・やり直し

チェックポイント:
- 発注書面（3条書面）に必要事項が記載されているか
- 支払期日が 60日以内か
- 減額・返品条項がないか

#### 消費者契約法

対象: 事業者 対 消費者（B to C）

無効となる条項:
- 事業者の損害賠償責任を免除する条項（故意・重過失の免責は無効）
- 消費者の解除権を放棄させる条項
- 事業者が任意に契約解除できる条項（消費者側に同等権なし）
- 平均的な損害額を超える違約金
- 消費者の利益を一方的に害する条項

チェックポイント:
- 利用規約に上記無効条項がないか
- 不当な勧誘（不実告知・断定的判断・不利益事実の不告知）に該当する表現がないか

#### 特定商取引法

対象: 訪問販売、通信販売、電話勧誘、連鎖販売、特定継続的役務、業務提供誘引、訪問購入

通信販売の規制:
- 広告記載事項（事業者名・住所・連絡先・返品条件等）
- 返品規定の表示
- 誤認を生じさせる表示の禁止

チェックポイント:
- EC サイトの法定表示（事業者情報・返品等）
- 定期購入の場合、「契約の申込みの撤回・解除」規定

#### 景品表示法

対象: 優良誤認表示、有利誤認表示、景品類の提供

チェックポイント:
- 広告表示が実態と合っているか
- 「最大」「No.1」等の表示に根拠があるか
- 打消表示（※印等）が読めるサイズか

#### 個人情報保護法

チェックポイント:
- 個人情報の利用目的が明示されているか
- 第三者提供の同意取得プロセスがあるか
- 安全管理措置が講じられているか
- 外国への第三者提供の規制
- 本人の権利（開示・訂正・利用停止等）対応フローがあるか
- 個人関連情報の取り扱い

#### 労働基準法

チェックポイント:
- 労働条件の書面明示
- 就業規則の作成・届出（常時10人以上）
- 労働時間・休憩・休日・休暇
- 時間外労働・割増賃金
- 解雇予告・解雇理由
- 賃金支払の5原則（通貨・直接・全額・毎月・一定期日）

#### 男女雇用機会均等法

チェックポイント:
- 募集・採用で性差別をしていないか
- 性別による処遇格差がないか
- セクハラ・妊娠出産等に関するハラスメント対策

### 4. チェック実施

各法令について、対象文書を確認:

```markdown
## 法令別チェック結果

### 下請法
適用の有無: 適用あり（貴社 資本金5000万円、相手方1000万円以下）

#### チェック項目

| 項目 | 状態 | 備考 |
|------|------|------|
| 発注書面（3条書面） | ✅ あり | 必要事項すべて記載 |
| 支払期日（60日以内） | ✅ 30日 | OK |
| 減額条項 | ✅ なし | OK |
| 返品条項 | ⚠️ あり | 「甲が検収しなかった場合」の返品可能性、下請法では「正当な理由がない返品」は禁止、要確認 |
| 買叩き | - | 価格の妥当性は個別判断 |

総合: 🟡 部分的に要注意（返品条項の確認）

### 消費者契約法
適用の有無: 適用なし（B to B のため）

### 個人情報保護法
適用の有無: 適用あり（個人情報を扱う）

#### チェック項目

| 項目 | 状態 | 備考 |
|------|------|------|
| 利用目的の明示 | ✅ 契約書に記載 | |
| 安全管理措置 | ⚠️ 言及なし | 別途の取扱い覚書の添付を推奨 |
| 第三者提供 | ✅ 原則なし | |

総合: 🟡 安全管理措置の明確化を
```

### 5. advocate レビュー

`legal-advisor-advocate` に評価を渡してチェック。見落としの指摘。

### 6. 推奨アクション

```markdown
## 推奨アクション

### 🔴 Critical（法令違反の可能性）
（なければ空）

### 🟡 Warning（改善推奨）
1. 下請法の返品条項を見直し
   - 「乙の瑕疵による返品のみ可」等、正当な理由を明確に

2. 個人情報の安全管理措置
   - 取扱覚書を別途締結、または契約書の条項として追加

### 🟢 Info（推奨事項）
1. 下請法の記録保存義務
   - 5年間の保存義務があります。システム化を検討

### 専門家相談が必要な点
1. 下請法の「買叩き」該当性判断（個別事案）
2. 個人情報取扱いの具体的な安全管理措置

### 次のステップ
- [ ] 🟡 Warning 項目の修正
- [ ] 🟢 Info 項目の検討
- [ ] 弁護士・法務専門家による最終確認
- [ ] 定期的なコンプライアンスチェック計画（年1回など）
```

### 7. ファイル保存

```
{保存先}/compliance/{YYYY-MM-DD}-{対象名}.md
```

## やってはいけないこと

- 「100%適法です」と断定（個別判断の領域）
- 古い法令知識で判断（法改正は常に確認）
- 専門家領域の判断を代行
- 複雑な事案を単純化しすぎる
