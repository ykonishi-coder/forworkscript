# 機能: 法務調査

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.legal-advisor/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


日本の法律・判例・法改正情報を、信頼できる公式ソースからネット検索して提供する。

## 大原則

1. 公式ソース最優先: e-Gov、裁判所、各省庁
2. 複数ソース確認: 1つだけで断定しない
3. 取得日を明記: 法改正で情報が変わる可能性
4. 断定しない: 「〜と解釈される」「〜の可能性」
5. 専門家相談推奨: 必ず添える

信頼できるソースの詳細は `references/japanese-legal-sources.md` 参照。

## 入力

1. 調査テーマ（法律名・条文・判例・事案）
2. 目的（契約書への反映 / 業務適用 / 一般知識）
3. 急ぎ度

## 手順

### 1. 調査クエリの明確化

ユーザーの「〇〇について調べて」を具体化:

```markdown
調査内容を確認させてください:

- 何を知りたい？（条文解釈 / 判例 / 法改正 / 一般解説）
- 関連する法律は？（例: 民法、労基法、下請法）
- 特定の条文・判例・事案があれば具体的に
- 情報の鮮度（最新のみ / 過去の経緯も）
```

不明点は1往復で聞く。

### 2. 調査プランの提示

どう調査するかを提示:

```markdown
以下の順で調査します:

1. e-Gov 法令検索: 該当条文の現行版を確認
2. 最高裁判例検索: 関連判例があるか
3. {省庁} ガイドライン: 行政解釈
4. 専門誌・書籍: 補足情報（あれば）

調査時間: 約2-3分程度。進めてよろしいですか？
```

### 3. Web 検索実行

以下を順に WebSearch / WebFetch:

#### e-Gov
```
{法令名} 第{条番号}条 e-Gov
{テーマキーワード} 法令
```

#### 裁判所
```
{キーワード} 判例 裁判所
{事案の特徴} 最高裁
```

#### 各省庁
```
{テーマ} 法務省
{テーマ} 厚生労働省
{テーマ} ガイドライン
```

#### 補足
```
{テーマ} 解説 {今年}
{テーマ} 改正 {今年}
```

### 4. 情報の整理

取得した情報を以下で整理:

```markdown
## 調査結果

テーマ: {調査テーマ}
調査日: YYYY-MM-DD

### 関連する条文

#### 民法 第415条（債務不履行による損害賠償）

> 債務者がその債務の本旨に従った履行をしないとき又は債務の履行が不能であるときは、債権者は、これによって生じた損害の賠償を請求することができる。ただし、その債務の不履行が契約その他の債務の発生原因及び取引上の社会通念に照らして債務者の責めに帰することができない事由によるものであるときは、この限りでない。

出典: [e-Gov 法令検索](https://elaws.e-gov.go.jp/...) / YYYY-MM-DD 確認
施行日: 2020年4月1日（改正民法）

### 関連する判例

#### 最高裁判所 2023年X月X日判決
事案: ...
判旨: ...
出典: [裁判所ウェブサイト](https://...) / YYYY-MM-DD 確認

### 行政解釈・ガイドライン

#### 法務省「債務不履行と損害賠償の実務」
要点: ...
出典: ...

### 専門家の解説

#### BUSINESS LAWYERS 記事
要点: ...
出典: ...

### 一般的な解釈（複数ソース確認）

{主要な解釈を複数ソースで裏付けて提示}
```

### 5. 複数ソース確認

重要な主張は 必ず複数ソース で確認:

```markdown
### クロスチェック結果

主張: 債務不履行の成立には「帰責事由」が必要

- ✅ 民法 415条ただし書（e-Gov）
- ✅ 最高裁判例（1950年代〜一貫）
- ✅ 法制審議会議事録での整理
- ✅ 商事法務の解説

→ 確定的に言える
```

1ソースしかない主張は「一部の解釈」として扱う。

### 6. 結論と適用

ユーザーの目的に応じて、調査結果をどう使えるかを整理:

```markdown
### あなたの目的への適用

契約書作成時の示唆:
- 民法415条ただし書の「帰責事由不要」条項が削除され、原則復帰
- 契約書で「故意または重過失」に免責範囲を限定する条項は有効
- 改正民法に対応した条項例を参照（→ `templates/service-agreement.template.md`）

注意点:
- 改正民法は2020年4月施行。旧民法との適用関係に注意
- 判例の射程は個別事案次第。類似事案でも結論が異なる可能性
```

### 7. 免責と専門家相談

必ず最後に:

```markdown
---

⚖️ 重要:
- 本調査は AI による一般情報提供です
- 具体的な事案への適用は、事案ごとに判断が異なります
- 重要な判断は、必ず弁護士・法務専門家にご相談ください
- 法令・判例は改正・変更される可能性があります（本情報は YYYY-MM-DD 時点）

---
```

### 8. ファイル保存

```
{保存先}/research/{YYYY-MM-DD}-{テーマスラッグ}.md
```

後で参照できるように、出典URLを含めて保存。

### 9. 次のステップ

```markdown
### 次のアクション

この調査結果を元に:
- 契約書に反映 → 「契約書チェック」で該当契約を見直す
- 社内ガイドライン作成 → 「レポート作成」で社内文書化
- 深掘り調査 → 具体的な事案を追加で相談
- 専門家相談 → 弁護士へ
```

## 調査テーマ別のコツ

### 条文解釈
- e-Gov で条文原文 → 立法趣旨を法制審議会で確認 → 判例 → 学説

### 判例調査
- 最高裁から下級審へ
- キーワードと事案の特徴で絞り込み
- 新しい判例を優先（古い判例が覆されている可能性）

### 法改正情報
- 施行日 / 公布日 を区別
- 経過措置の有無
- 主要な改正ポイント

### 業界規制
- 業法（金商法・医薬品医療機器等法 等）
- 業界団体の自主ルール
- 行政指導・通達

### 新しいテーマ（AI・暗号資産等）
- まだ法整備が進んでいない領域
- ガイドライン・解釈通達で実務が動く
- 国際動向も参考に

## 情報の鮮度チェック

調査結果に必ず含める:

```markdown
### 情報の鮮度

- 条文: 2024年X月X日改正、2025年4月1日施行
- 判例: 最新の確認 YYYY-MM-DD、以降の新判例に注意
- ガイドライン: 最終改訂 YYYY-MM、次回改訂予定 YYYY-MM
- 調査実施日: YYYY-MM-DD（この日時点の情報）
```

30日以上前の調査を参照するときは、再調査を推奨。

## やってはいけないこと

- 断定的な法解釈（「〇〇は違法です」等）
- 事案への具体的適用 の断言
- 訴訟戦略・交渉戦略 のアドバイス
- 弁護士資格が必要な行為 の代行
- 古い情報のまま回答（再調査せず）

## 完了メッセージ

```markdown
## 法務調査完了

テーマ: 改正民法下での契約不履行と損害賠償
調査日: YYYY-MM-DD
保存先: ./.legal-advisor/research/2026-04-23-breach-damage.md

### 主要な発見
1. 改正民法 415条では「帰責事由不要」原則が復帰
2. ただし「契約の性質及び取引上の社会通念」で判断
3. 最高裁は伝統的な解釈を概ね維持

### 契約実務への影響
- 免責条項の設計に影響
- 不可抗力条項の書き方

### 次のアクション候補
- 既存契約書の免責条項を見直す → 「契約書チェック」
- 社内ガイドライン更新 → 「レポート作成」
- 個別事案は弁護士相談を推奨

⚖️ 免責: 本情報は一般情報であり、具体的事案への適用は専門家相談を推奨します。
```
