# 機能: 契約書管理

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.legal-advisor/config.yaml` と
> 契約書インデックス（`config.contract_management.index_path` = 既定 `./.legal-advisor/index.md`）を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` は config.yaml の値を、
> 「契約書インデックス」「index.md」は読み込み済みの一覧内容を指す。
> インデックスが未作成なら「新規作成として進める」と明示すること。


契約書のメタデータを一覧管理し、期限アラート・更新管理を行う。

## 扱うデータ

機密保護の観点で、以下のみ管理:

- 契約書のメタデータ（相手方・契約タイプ・期間・金額サマリ等）
- レビュー結果のサマリ
- バージョン履歴

以下は管理しない:
- 契約書の全文（ユーザーが自分で管理）
- 個人情報の詳細
- 機密情報の具体的内容

## データ構造

### 契約書インデックス（index.md）

```markdown
# 契約書インデックス

最終更新: YYYY-MM-DD

## アクティブ契約（N件）

| ID | 相手方 | タイプ | 締結日 | 終了日 | 自動更新 | 次アラート |
|----|-------|-------|--------|--------|---------|----------|
| C001 | {相手方A} | 業務委託 | 2024-04-01 | 2026-03-31 | ◯ | 2026-02-28 |
| C002 | {相手方B} | NDA | 2024-06-01 | (期間なし) | - | - |

## 終了済み契約（N件）

| ID | 相手方 | タイプ | 締結日 | 終了日 |
|----|-------|-------|--------|--------|
| C000 | ... | ... | ... | ... |

## 検討中（N件）

| ID | 相手方 | タイプ | レビュー状況 |
|----|-------|-------|------------|
```

### 契約書個別ファイル

```
{保存先}/contracts/{ID}.md
```

形式は `templates/contract-index.template.md` 参照。

## 機能

### 1. 契約書の登録

ユーザーが新しい契約書を管理対象に追加:

```markdown
新しい契約書を登録します。以下を教えてください:

- 相手方（社名または個人名、マスキング設定に応じて）
- 契約タイプ（NDA / 業務委託 / 売買 / 賃貸借 / 雇用 / その他）
- 締結日
- 契約期間（終了日 or 期間の定めなし）
- 自動更新の有無
- 更新通知期限（自動更新の場合）
- 主要金額（マスキング可）
- 特記事項（あれば）
```

ID を自動採番（C001, C002, ...）、インデックスに追加。

### 2. 一覧表示

```markdown
現在アクティブな契約（5件）:

| ID | 相手方 | タイプ | 終了日 | 状態 |
|----|-------|-------|--------|------|
| C001 | {相手方A} | 業務委託 | 2026-03-31 | 🟢 正常 |
| C002 | {相手方B} | NDA | なし | 🟢 正常 |
| C003 | {相手方C} | 業務委託 | 2026-05-15 | 🟡 更新検討期 |
| C004 | {相手方D} | 売買 | 2026-01-30 | 🔴 期限切れ |

### 🔴 期限切れ（1件）
- C004: {相手方D} - 2026-01-30 で終了済み。更新が必要か確認してください

### 🟡 更新検討期（1件、30日以内に期限）
- C003: {相手方C} - あと 22日で期限

### 🟢 正常（3件）
```

### 3. 特定契約の詳細

ユーザーが「C001 の詳細」と言ったら:

```markdown
## 契約 C001 詳細

相手方: {相手方A}
タイプ: 業務委託
締結日: 2024-04-01
終了日: 2026-03-31（あと 342日）
自動更新: あり（終了60日前までに不更新通知）
金額: {マスキング or 記載}

### 主要条項サマリ
- 業務内容: {サマリ}
- 対価: {サマリ}
- 検収: 納品後30日以内
- 解除: 90日前通知
- 知的財産: 成果物著作権は{当方 / 相手方}に帰属

### 履歴
- 2024-04-01: 初回締結
- 2025-09-15: 第1回更新交渉、条件変更なし
- 2026-01-10: 今回の更新検討開始

### 次のアクション
- 2026-02-28 までに不更新通知 or 更新交渉開始
- リマインダーを `./.legal-advisor/alerts/` に生成済み

### 関連ファイル
- レビュー結果: {パス}
- レビュー日: 2024-03-15 / 2025-09-15
```

### 4. 更新期限アラート

scheduled-run で定期実行:

- 毎月1日: 今月・来月の期限を持つ契約をリストアップ
- 毎週月曜: 今週・来週の期限
- 重要な期限（30日以内）: 別途目立つようにマーク

アラートファイル生成:

```
./.legal-advisor/alerts/YYYY-MM-DD.md
```

例:

```markdown
# 契約アラート: 2026-04-23

## 🔴 期限切れ（要対応・2件）

### C004: {相手方D} - 売買契約
- 終了日: 2026-01-30（83日前）
- 状態: 期限切れ、継続取引があるなら新契約が必要

### C005: {相手方E} - 業務委託
- 終了日: 2026-03-31（23日前）
- 状態: 期限切れ、更新 or 終了の判断が未完

## 🟡 今月中に対応必要（3件）

### C003: {相手方C} - 業務委託
- 終了日: 2026-05-15（22日後）
- 自動更新: あり、不更新通知期限 2026-04-15（8日前に期限）
- ⚠️ 既に不更新通知期限を過ぎています。自動更新になる見込み。

### C010: {相手方F} - NDA
- 終了日: 2026-05-10（17日後）
- 状態: 通常は自動更新、継続するなら確認

### C012: {相手方G} - 業務委託
- 終了日: 2026-05-25（32日後）
- 更新交渉を開始する時期

## 🟢 次月以降（参考・5件）

（6月〜の期限、参考として）

---

### 推奨アクション

1. 🔴 C004, C005 の扱いを即確認
2. 🟡 C003 は自動更新確定を受けて、次回の見直し時期を検討
3. 🟡 C010, C012 の継続可否を決定
```

通知は送らない。ユーザーが次回起動時に確認。

### 5. バージョン管理

契約書の修正版が締結された場合:

```markdown
### 新バージョン登録

既存契約 C001 の修正版を登録しますか？

- 旧バージョン: v1（2024-04-01 締結）
- 新バージョン: v2（2026-04-01 締結、条件変更あり）

変更点のメモ:
- 対価が〇〇円 → △△円に増額
- 契約期間を1年延長

登録します？
```

登録後、履歴に追記。

### 6. 検索・フィルタ

```markdown
## 検索機能

- 相手方で検索
- 契約タイプで検索
- 期限範囲で検索（今月・来月・来四半期）
- ステータスで絞り込み
- 金額範囲（マスキングしていない場合）
```

### 7. 契約終了処理

契約終了時:

```markdown
契約 C001 を終了しますか？

終了タイプ:
- [ ] 期間満了
- [ ] 合意解約
- [ ] 一方的解除
- [ ] その他

終了後の措置:
- 秘密情報の返還/破棄
- 成果物の引き渡し
- 最終支払
- 契約書のアーカイブ

登録されているチェックリストに従って確認しますか？
```

終了後はアクティブから終了済みへ移動。

## プライバシー配慮

### マスキング設定

最厳重モードの場合:
- 相手方名: `{相手方A}` 等
- 具体的金額: `{金額}` 等
- 個別日付: 残す（管理に必要）

標準モードの場合:
- 相手方名: 残す
- 金額: 残す
- すべての情報を管理

### 削除ポリシー

契約終了後:
- `config.privacy.cleanup.delete_after_days` 日後に自動削除
- または手動で即削除

### エクスポート

必要に応じてエクスポート:

```bash
# 全契約をエクスポート（CSV）
「契約一覧を CSV でエクスポートして」

# 特定契約のみ
「C001 の詳細をエクスポート」
```

エクスポート先はユーザー指定のパス。

## やってはいけないこと

- 契約書全文を長期保存（サマリのみ）
- 相手方に無断でクラウド同期
- 機密情報を含むアラートを外部送信
- 勝手にレポート化・共有

```markdown
- 🟡 更新交渉を開始（3件）

詳細を見たい契約の ID を教えてください。
```
