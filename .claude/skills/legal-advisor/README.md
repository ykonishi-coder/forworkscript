# 法務支援 (Legal Advisor)

日本の法務業務を支援するエージェント。契約書チェック・法務調査・契約書管理・契約書作成支援・コンプライアンスチェック・取引先リスク判定・社内規程整備。

---

## ⚖️ 最重要: 免責事項

このスキルは弁護士・法務専門家の代わりではありません。

- 一般的な参考情報を提供するツール
- 最終的な法的判断は必ず 弁護士・法務専門家 に相談
- 重要契約・訴訟・法的トラブルは専門家へ
- 情報は参考目的、出力に起因するリスクは使用者責任

詳細は `references/disclaimer.md` 参照。

---

## 🔒 プライバシーについて

契約書は機密情報の塊です。hiring-assistant と同等以上の配慮:

- 学習に使われません: Anthropic API 方針による
- マスキング機能: 相手方名・金額・日付を自動置換
- ローカル保存のみ: 契約書サマリのみ保存、原文は保存しない
- 自動削除ポリシー
- .gitignore 必須（セットアップ時に自動提案）

## 提供機能

### 契約書チェック
NDA・業務委託・売買・利用規約等の契約書を条項別にレビュー。不利条項の検出、必要条項の欠落チェック、法令適合性。

### 法務調査
日本の法律・判例・法改正情報をネット検索:
- e-Gov 法令検索（全法令の最新条文）
- 最高裁判所（判例検索）
- 法務省・厚労省・消費者庁・個人情報保護委員会等
- 公正取引委員会（下請法・独占禁止法）

最新の公式ソースから取得、複数ソースでクロスチェック。

### 契約書管理
- 契約一覧（相手方・タイプ・期間サマリ）
- 更新期限アラート（30日前・90日前）
- バージョン管理
- 終了処理

### 契約書作成支援
- テンプレート（NDA・業務委託等）
- ユーザーの立場に有利な条項選定
- バイアス・バランスチェック（advocate）

### コンプライアンスチェック
- 下請法
- 個人情報保護法
- 消費者契約法
- 特商法・景表法
- 労働基準法
- 独占禁止法
- 他、業種別法令

### 取引先リスク判定
新規取引先を公開情報ベースで一次チェック。実在・登記・経営状況・反社関連情報・係争・行政処分・レピュテーションを整理し、🟢緑 / 🟡黄 / 🔴赤 で判定レポート化。
（最終的な与信・反社チェックは、契約している専門調査会社・弁護士・警察窓口へ）

### 社内規程整備
就業規則・プライバシーポリシー・情報セキュリティ規程・利用規約などの雛形整備、法改正に合わせた追従、実態とのズレチェック。重要なものは社労士・弁護士・専門家の確認を必ず挟む前提。

## ハイブリッド構成

- 本体: 契約書チェック・調査・管理・作成

## よくある質問

### Q. 契約書情報が外部に漏れないか
ローカル保存のみ。Claude API に送る情報はマスキング可能、学習には使われません。最厳重モードで相手方名・金額を自動マスキング。

### Q. 弁護士に頼むほどではない軽い相談でも使える？
一次スクリーニング として有効です。ただし、重要な契約・交渉は必ず弁護士確認。費用対効果を考えた使い分けを。

### Q. 法改正情報はいつのもの？
都度ネット検索で 最新情報 を取得します。取得日を必ず明記します。

### Q. 海外の契約にも対応？
このスキルは 日本法特化 です。英文契約・外国法準拠の契約は対応範囲外（ただし日本語での一般的論点整理は可能）。国際契約は必ず国際法務の専門家へ。

### Q. やめたくなったら？
`rm -rf ./.legal-advisor/`（Windowsは `Remove-Item -Recurse -Force ./.legal-advisor/`） で完全削除。アラート登録していた場合は `/schedule` も解除。
