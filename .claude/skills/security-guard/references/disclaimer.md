# 免責事項

## このスキルの位置付け

このスキルは、一般的なセキュリティ知識に基づいた 参考情報 と 設計サポート を提供します。
情報セキュリティ専門家・弁護士・個人情報保護法専門家・フォレンジック会社の代わりではありません。

## 本スキルが行わないこと

- 法的判断（個人情報保護法・GDPR・業界規制への該当判断）
- 医療・金融・法務など、専門資格が必要な領域の判断
- 実際の攻撃手法の再現・ペンテスト代行
- 他者のシステム・ネットワークへの無断調査（ユーザー自身の環境・明示的許可を得た環境のみ対象）

## ユーザーが自ら行うこと

- 重大インシデント発生時の専門家・警察・保険会社への連絡
- 法定期限のある通知（個人情報漏洩時の委員会報告等）
- 社外発表・顧客通知の判断
- 身代金支払い等の法的・倫理的判断（原則として非推奨）
- サービス契約・規約の最終確認

## 責任の範囲

- 本スキルの助言に基づく行動の結果について、作者・配布元は責任を負いません
- 最新の法令・サービス仕様・脆弱性情報は必ず利用者自身で確認してください
- 本スキルが検出しなかった脆弱性・リスクについても、セキュリティが保証されるものではありません

## 専門家への接続が必須のケース

以下のいずれかに該当する場合は、本スキルの利用を停止し、速やかに専門家・関係機関に相談してください。

1. 顧客の個人情報を含むデータが漏洩した or 漏洩した可能性がある
2. 金銭被害が発生した or 不正送金・不正課金が確認された
3. ランサムウェア・マルウェア感染の疑いがある
4. 業務用システム・サーバーへの不正アクセスが確認された
5. 退職予定者・外注先による情報持ち出しの疑いがある
6. 取引先・顧客から情報漏洩の指摘を受けた
7. 捜査機関から連絡があった

## 相談先の一覧（日本の場合・都度最新確認）

- JPCERT コーディネーションセンター: インシデント報告
- 情報処理推進機構（IPA）: セキュリティ相談
- 警察 サイバー犯罪相談窓口: 都道府県警のサイバー犯罪対策課
- 個人情報保護委員会: 個人情報漏洩報告
- 契約中のサイバー保険会社
- 顧問弁護士・企業法務
- 所属組織の情報セキュリティ責任者（CISO）

海外・多国籍企業の場合は、該当地域の規制当局（EU: DPA / 米: FTC 等）と、各国語の専門家ネットワークを活用すること。

## プライバシーに関する再確認

- 入力情報は Anthropic API の方針により、Claude の学習には利用されません
- 認証情報（APIキー・パスワード・トークン・カード番号等）は 本スキル内に保存しません
- レポート・プロファイル・監査結果は、ユーザーのローカル環境にのみ保存されます
- ユーザーが明示的に許可しない限り、外部への送信・連携は行いません

## 利用規約への準拠

本スキルを利用する前に、以下を必ず確認してください。

- 所属組織の情報セキュリティ規程
- 利用中のAI（Anthropic等）の利用規約
- 業界のガイドライン・規制
- 契約している保険・弁護士の連絡先

不明点は、本スキルを使い始める前に専門家に相談すること。
