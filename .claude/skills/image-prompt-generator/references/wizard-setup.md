> - Nano Banana / GPT Image / Midjourney V7 / FLUX.1 / Stable Diffusion 3.5 / Adobe Firefly / Ideogram 等のプロンプト生成

## プライバシー関連FAQ

### Q. 参考画像を渡すのは大丈夫？
画像は処理時に Claude API に送られますが、学習データには使われません。権利処理済みの画像、自分で撮影した画像、権利者の許可を得た画像に限定してください。

### Q. 生成したプロンプトで商用利用しても大丈夫？
プロンプトの生成自体は問題ありませんが、実際に画像を生成・商用利用する際には、使用する画像生成AIの利用規約・商用ライセンスを必ず確認してください。
