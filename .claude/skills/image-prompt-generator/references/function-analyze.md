# 機能: リファレンス分析

> 前提: 呼び出し元（SKILL.md）の「設定の読み込み」で `./.image-prompt-generator/config.yaml` を読み込み済み。
> 未読込なら先に読むこと。本ファイル内の `config.xxx` はその値を指す。


参考画像からスタイル要素を抽出し、同じ雰囲気を再現するためのプロンプトを生成する。

## 入力

1. 参考画像（ユーザーが貼り付け、またはファイルパス）
2. 何を再現したいか（全体の雰囲気 / 特定要素のみ）
3. 対象AI

## 大前提（権利確認）

参考画像の利用には権利的配慮が必要。処理開始前に確認:

> 参考画像の権利について確認させてください:
>
> - 自分で撮影・制作した画像ですか？
> - 権利者の許可を得ていますか？
> - 商用利用可能なストック画像ですか？
>
> 以下の場合はサポートしません:
> - 他者の著作物を無断で模倣する目的
> - 特定アーティスト・ブランドを完全再現する目的（スタイルの影響を受ける程度はOK）

## 手順

### 1. 画像の観察

以下の観点で画像を読み取る:

#### 被写体
- 何が写っているか
- 主題・副題の区別

#### 構図・カメラ
- 画角（クローズアップ / ミディアム / ワイド）
- アングル（アイレベル / ローアングル / ハイアングル / 俯瞰）
- 構図の法則（三分割 / 対称 / 中央配置）

#### 色彩
- 支配色（暖色 / 寒色 / モノトーン）
- パレット（具体的な色の組み合わせ）
- 彩度・明度の傾向

#### ライティング
- 光源の種類（自然光 / 人工光 / ミックス）
- 光の方向（順光 / 逆光 / 側光）
- 時間帯（朝 / 昼 / ゴールデンアワー / 夜）
- コントラスト

#### スタイル・画風
- 写実 / イラスト / 抽象
- アーティスト系統（例: 浮世絵風、印象派風、ピクサー風）
- 時代感（レトロ / モダン / 未来的）

#### 質感・ディテール
- フィルム / デジタル
- テクスチャ（粗い / 滑らか）
- ノイズ・グレイン

### 2. スタイル要素の言語化

観察結果を構造化:

```markdown
## スタイル分析

### 被写体
- 主題: 若い女性のポートレート
- 副題: 背景の森

### 構図
- ミディアムクローズアップ
- 三分割法、被写体は右寄り
- 浅い被写界深度

### 色彩
- 支配色: 暖色系（オレンジ、ゴールド）
- 補色: 深い緑（背景）
- 彩度: やや抑えめ、ノスタルジック

### ライティング
- ゴールデンアワー（日没前30分）
- 側光、被写体の輪郭が光る
- 柔らかい影

### 画風
- 写実的
- フィルム風のトーン（Kodak Portra を思わせる）
- 映画的な雰囲気

### 質感
- 適度なフィルムグレイン
- 肌のトーンが柔らかい
```

### 3. プロンプトへの変換

分析結果をプロンプトに落とし込む:

#### 基本プロンプト
```
portrait of a young woman in a forest, golden hour, side lighting, warm tones, shallow depth of field, cinematic, film grain, Kodak Portra 400 aesthetic
```

#### 対象AI別に調整
対象AIが Midjourney なら `--ar 3:4 --s 250 --v 6` を追加、SD なら重み付け、DALL-E なら自然言語など。

### 4. 調整ポイントの提示

```markdown
## 生成のコツ

- ゴールデンアワーの雰囲気: `golden hour, warm tones, soft light` が効く
- フィルム感: `film grain, Kodak Portra` や `analog photography`
- 浅い被写界深度: `shallow depth of field, bokeh, 85mm lens`
- 映画的: `cinematic, film still, moody`

### うまくいかなかった場合の修正案
- 明るすぎる → `overexposed` を避け、`soft light` 強調
- 暗すぎる → `bright` `well-lit` 追加
- ボケが足りない → `f/1.4` `85mm lens` など具体的に
```

## 参照の権利別の対応

### ユーザー自作・権利処理済み
- 完全にスタイル分析してOK

### ストック画像・パブリックドメイン
- 元画像の商用ライセンスを確認するよう促す
- スタイルの影響を受けるのはOK

### 他者の著作物（明らかな商用作品等）
- スタイルの影響を受ける程度のプロンプト生成は可
- 完全再現を狙うプロンプトは避ける
- 「このアーティスト風」の大量生産を助長しない

### 判断が難しい場合
- ユーザーに確認してから進める
- 不安があれば中止

## やってはいけないこと

- 完全複製を狙うプロンプト
- 特定アーティストのサイン・透かしを再現
- 実在人物の顔を再現するプロンプト
- 有名キャラクターを完全に再現するプロンプト
